# 판타지 소설 스킬

한국어 판타지의 세계관 설계, 집필, 인물 갈등, 장면 묘사, 문장 퇴고와 정전 감사를 위한 개인 스킬 저장소입니다. **기본 6개 + 세계관 분야별 선택형 8개**, 창작 예시 216개를 제공합니다. 작품별 설정과 원고는 별도로 관리하세요.

처음에는 기본 6개 중 필요한 것만 설치하세요. 세계관 통합형과 분야별 8개는 **대체 구성**이므로 모두 동시에 설치할 필요가 없습니다. 플랫폼별 ZIP은 `dist`에 있으며, ChatGPT는 스킬 업로드 메뉴가 제공되는 계정에서 직접 등록하거나 프로젝트 지침·자료 방식으로 사용합니다. MCP 서버는 포함하지 않습니다.
