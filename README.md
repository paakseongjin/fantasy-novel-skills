# 판타지 소설 스킬

한국어 판타지 소설을 만들 때 **세계관 설계부터 장면 집필, 문장 퇴고, 설정 검증까지** 돕는 창작 스킬 모음입니다. ChatGPT, Claude, Gemini에서 활용할 수 있도록 플랫폼별 파일과 사용 안내를 제공합니다.

이 저장소의 스킬은 작가 대신 작품을 완성하거나 설정을 자동으로 기억하는 프로그램이 아닙니다. 작가가 전달한 세계관과 원고를 바탕으로 필요한 작업을 돕는 **재사용 가능한 창작 지침**입니다. 작품의 확정 설정과 최종 결정은 작가가 관리합니다.

- **기본 스킬 13개:** 세계관·집필·퇴고·감사와 장편 플롯, 성장, 복선, 회차, 전투, 대사, 원고 진단
- **세계관 분야별 선택형 8개:** 세계관 통합 스킬 대신 필요한 분야를 골라 사용할 수 있는 독립형 스킬
- **창작 예시 216개:** 명칭 48개와 분야별 설정·검토 예시 168개. 완성된 세계관 216개를 뜻하지 않습니다.
- **추가 자료:** 장르 프리셋 7종, 서로 연결된 세계관 예제, 설정집과 회차 인계 양식

## 어떤 스킬을 사용하면 되나요?

| 하고 싶은 작업 | 사용할 스킬 | 제공하면 좋은 자료 |
|---|---|---|
| 세계의 지리·마법·국가·종교를 함께 설계 | `build-fantasy-world` | 장르, 분위기, 이야기 범위, 이미 확정한 설정 |
| 장면이나 회차의 본문을 집필 | `write-fantasy-prose` | 앞 장면, 인물 상태, 시점, 장면 목표와 분량 |
| 인물의 심리와 관계 갈등을 개선 | `write-character-conflict` | 인물별 목표, 관계, 서로 아는 사실, 원고 |
| 독자가 장면을 떠올릴 수 있도록 묘사 개선 | `write-immersive-scenes` | 공간 구조, 인물 위치, 동선, 시점, 원고 |
| 자연스러운 한국어로 문장 다듬기 | `refine-natural-korean` | 원고, 원하는 문체, 수정 범위 |
| 기존 설정과 원고의 모순 확인 | `audit-fantasy-canon` | 확정 설정집, 관련 회차, 자료 버전과 검토 범위 |

처음에는 필요한 기본 스킬만 골라 설치하세요. 세계관을 폭넓게 만들 때는 **통합형 `build-fantasy-world` 하나**로 시작하고, 특정 분야만 따로 쓰고 싶다면 아래의 분야별 선택형을 사용하면 됩니다. 두 구성을 모두 활성화할 필요는 없습니다.

## 기본 스킬 13개

### 1. 세계관 통합 설계 — `build-fantasy-world`

**목적:** 판타지 세계의 개별 설정을 나열하는 데서 그치지 않고, 지리·역사·마법·계급·국가·종족·종교가 서로 어떤 영향을 주는지 연결합니다. 그 설정이 주민의 생활과 인물의 선택, 이야기의 갈등에 어떻게 드러나는지도 설계합니다.

**이럴 때 사용하세요.** 새로운 세계의 뼈대를 만들 때, 기존 세계관에 부족한 마법이나 국가를 보완할 때, 분야별 설정이 서로 모순되는지 살펴볼 때 유용합니다. 필요한 분야의 지침과 예시를 선택해 활용합니다.

```text
build-fantasy-world를 사용해 판타지 세계관을 설계해 줘.
분위기: 정치적 긴장과 모험이 있지만 일상적인 온기도 있는 세계
범위: 도시 1곳, 주변 국가 2곳, 마법 체계 1개, 종교 2개
주인공: 지방 출신 수리 기술자

각 설정의 작동 원리와 주민의 생활, 권력 갈등을 연결해 줘.
아직 확정된 설정은 없으니 서로 다른 방향 3개를 제안해 줘.
각 제안과 내가 나중에 채택할 확정 설정을 구분해 줘.
```

[세계관 스킬팩 자세히 보기](docs/worldbuilding.md)

### 2. 판타지 본문 집필 — `write-fantasy-prose`

**목적:** 확정된 세계관과 인물 상태를 지키면서 장면과 회차의 본문을 작성하거나 이어 씁니다. 장면에서 인물이 무엇을 원하고 어떤 장애를 만나며, 어떤 선택과 결과에 이르는지 고려합니다.

**이럴 때 사용하세요.** 설정과 줄거리는 있지만 실제 본문을 쓰기 어려울 때, 앞 회차에 이어 다음 장면을 작성할 때, 정해진 시점과 문체를 유지하며 장면을 수정할 때 사용합니다.

```text
write-fantasy-prose를 사용해 아래 장면을 써 줘.
시점: 주인공의 3인칭 제한 시점
장면 목표: 주인공이 스승의 배신을 의심하지만 확신하지 못한다.
조건: 첨부한 확정 설정과 앞 장면을 따르고, 대화와 행동으로 불신을 드러내 줘.
분량: 약 1,500자. 새로운 설정이 필요하면 본문 뒤에 제안으로 구분해 줘.
[확정 설정 / 앞 장면 / 인물 상태]
```

[집필 스킬 자세히 보기](docs/write-fantasy-prose.md)

### 3. 인물 심리와 관계 갈등 — `write-character-conflict`

**목적:** 인물의 욕구와 두려움, 숨기는 사실, 관계의 힘의 차이, 대사의 속뜻을 바탕으로 설득력 있는 갈등을 만듭니다. 감정 이름을 반복하기보다 상황에 맞는 행동과 선택을 구체화합니다.

**이럴 때 사용하세요.** 인물이 왜 대립하는지 납득하기 어렵거나, 대화가 설명처럼 느껴지거나, 사랑과 원망처럼 상반된 감정이 함께 드러나야 할 때 사용합니다.

```text
write-character-conflict로 아래 장면을 수정해 줘.
언니의 목표: 동생이 내일 자수하도록 설득하기
동생의 목표: 언니에게 여행비를 받아 오늘 떠나기
언니만 아는 비밀: 동생을 구하는 과정에서 다른 동료가 처벌받았다.

동생의 3인칭 제한 시점을 지켜 줘. 비밀을 직접 알려 주지 말고
대화와 선택에 긴장을 담아 줘. 결말은 동생이 돈을 받지 못하고
나가는 것으로 유지해 줘.
[원고]
```

[심리·갈등 스킬 자세히 보기](docs/write-character-conflict.md)

### 4. 장면 묘사와 몰입감 — `write-immersive-scenes`

**목적:** 인물의 위치와 이동, 주변 사물, 감각 정보, 시간의 흐름을 시점에 맞춰 연결해 독자가 장면을 따라가도록 돕습니다. 모든 감각을 나열하거나 수식어를 무작정 늘리는 방식은 지양합니다.

**이럴 때 사용하세요.** 추격·전투의 동선이 헷갈릴 때, 배경이 인물 행동과 따로 노는 느낌일 때, 장면에 필요한 시각·소리·촉감 등을 선별하고 싶을 때 사용합니다.

```text
write-immersive-scenes로 아래 추격 장면을 다듬어 줘.
주인공 1인칭 시점이고, 시장 입구에서 동쪽 우물까지 이동한다.
골목은 두 사람이 겨우 지나갈 너비이며, 뒤에는 추격자가 한 명 있다.
주인공은 왼발을 다쳤고 무기는 없다.

최종 결과는 우물 옆 창고에 숨는 것으로 유지해 줘.
위치와 소리의 방향은 명확하게 하되 새 도구나 마법은 추가하지 마.
[원고]
```

[장면 묘사 스킬 자세히 보기](docs/write-immersive-scenes.md)

### 5. 자연스러운 한국어 퇴고 — `refine-natural-korean`

**목적:** 어휘 선택, 문장 호응, 번역투, 불필요한 반복과 대사를 점검하면서 원문의 의미와 서술자의 목소리를 보존합니다. 모든 문장을 짧게 만들거나 한자어·부사를 일괄 삭제하지 않습니다.

**이럴 때 사용하세요.** 문장이 기계적으로 반복되거나 어색한 번역투가 느껴질 때, 말투와 사건은 유지하면서 읽기 쉽게 다듬고 싶을 때 사용합니다. 맞춤법 교정, 문장 다듬기, 문체 개선, 재작성 중 원하는 범위를 지정하세요.

```text
refine-natural-korean으로 다음 원고의 문장만 다듬어 줘.
사건, 정보, 시점, 시제와 인물의 말투는 유지해 줘.
번역투와 불필요한 반복은 줄이되 새 감각이나 과거사를 만들지 마.
잘 작동하는 긴 문장과 의도적인 반복은 살려 줘.
수정 본문을 보여 주고, 의미가 갈리는 부분만 짧게 설명해 줘.
[원고]
```

예를 들어 **“문을 열 수 있었다”**는 가능성을 뜻할 수 있으므로, 근거 없이 **“문을 열었다”**로 바꾸면 사건 자체가 달라집니다. 이 스킬은 AI 탐지기 판정이나 특정 작가의 문체 재현을 보장하지 않습니다.

[한국어 퇴고 스킬 자세히 보기](docs/refine-natural-korean.md)

### 6. 정전·연속성 감사 — `audit-fantasy-canon`

**목적:** 작가가 확정한 세계관과 원고를 대조해 시간, 인물의 지식, 능력의 조건, 이동, 소지품, 복선 등의 충돌을 근거와 함께 확인합니다. 여기서 **정전**은 해당 작품에서 작가가 공식적으로 확정한 설정과 사건을 말합니다.

**이럴 때 사용하세요.** 연재가 길어져 앞뒤 설정이 헷갈릴 때, 특정 회차가 마법 규칙을 어기지 않았는지 확인할 때, 설정을 바꾸기 전에 영향을 받는 부분을 검토할 때 사용합니다.

```text
audit-fantasy-canon으로 첨부한 확정 설정과 12화를 검토해 줘.
인물의 지식, 마법 사용 비용, 이동 시간에 집중해 줘.
문제가 있다면 충돌하는 양쪽 근거, 적용 시점, 확실성,
최소 수정안을 제시해 줘. 의도된 비밀은 오류로 단정하지 말고
새로운 예외를 임의로 확정하거나 원고를 직접 수정하지 마.
[설정집과 원고 / 버전]
```

[정전 감사 스킬 자세히 보기](docs/audit-fantasy-canon.md)

### 7~13. 장편 창작을 위한 추가 스킬

작품 전체의 인과, 인물 변화, 복선과 회차의 흐름을 별도로 계획하고 필요한 부분만 검토합니다. 각 스킬은 4개의 독립 예시와 작업 기록 양식을 포함합니다.

| 스킬 | 목적 | 상세 문서 |
|---|---|---|
| `plan-fantasy-longform` | 작품 전체의 인과, 이야기 단위와 결말을 설계합니다. | [장편 구성·플롯 설계](docs/plan-fantasy-longform.md) |
| `design-character-arcs` | 장기적인 신념 변화와 관계의 계기·대가를 설계합니다. | [인물 성장·관계 변화](docs/design-character-arcs.md) |
| `manage-fantasy-foreshadowing` | 실제 단서와 계획을 구분하고 정보 공개와 반전의 근거를 살핍니다. | [복선·비밀·회수 관리](docs/manage-fantasy-foreshadowing.md) |
| `structure-serial-chapters` | 회차별 목표, 변화와 독자 경험의 리듬을 검토합니다. | [회차 구성·연재 리듬](docs/structure-serial-chapters.md) |
| `design-fantasy-action` | 능력과 공간의 조건, 목표와 승패의 인과를 설계합니다. | [판타지 전투·액션 설계](docs/design-fantasy-action.md) |
| `craft-character-dialogue` | 인물의 관계, 존대, 지식과 상황에 맞는 대화를 다듬습니다. | [대사·인물별 말투 설계](docs/craft-character-dialogue.md) |
| `review-fantasy-manuscript` | 원고의 인과·독자 이해·장면 기능을 근거 중심으로 진단합니다. | [판타지 원고 편집·진단](docs/review-fantasy-manuscript.md) |

전투·대사는 특정 분야에 집중할 때 선택적으로 사용합니다. 제공된 원고에서 확인되지 않은 설정이나 미작성 복선을 이미 확정된 사실로 처리하지 않습니다.

## 세계관 분야별 선택형 8개

아래 스킬은 통합형 `build-fantasy-world`의 분야별 대안입니다. 필요한 스킬만 설치할 수 있고, 각 패키지에 해당 분야의 참고 자료가 포함되어 있습니다. 통합형이 이 8개를 자동으로 설치하는 것은 아닙니다.

| 스킬 | 목적과 사용 예 | 예시 수 |
|---|---|---:|
| `design-fantasy-world` | 세계의 전제, 지리·기후·역사·자원과 생활의 관계 설계 | 24개 |
| `name-fantasy-world` | 문화권별 인명·지명·조직·직위·유물 등의 명칭과 조어 규칙 설계 | 48개 |
| `design-fantasy-magic` | 마법의 원리·조건·제약·능력과 사회적 영향 설계 | 24개 |
| `design-fantasy-institutions` | 신분·귀족 작위·관직·군 계급·면허와 권한 구분 | 24개 |
| `design-fantasy-nations` | 국가·도시·경제·교역·외교·군수와 이해관계 설계 | 24개 |
| `design-fantasy-peoples` | 종족의 생리·수명과 다양한 공동체의 문화·생활 설계 | 24개 |
| `design-fantasy-religions` | 신·교리·의례·분파·성직 조직과 정치·생활의 관계 설계 | 24개 |
| `audit-fantasy-worldbuilding` | 설정 분야 간 연결과 모순 후보, 설정을 장면에 반영하는 방식 검토 | 24개 |

`audit-fantasy-worldbuilding`은 세계관 요소의 인과관계와 장면 반영에 초점을 맞춥니다. `audit-fantasy-canon`은 제공된 작품 자료의 정전·연속성을 근거 중심으로 검증합니다. 같은 충돌을 두 스킬로 반복 검사할 필요는 없습니다.

```text
design-fantasy-magic을 사용해 마법 체계 3개를 제안해 줘.
각 체계마다 사용 조건, 가능한 일과 불가능한 일, 악용 가능성,
평민의 일상과 국가 권력에 미치는 영향을 설명해 줘.
세 체계는 별개의 후보로 제시하고, 아직 정본으로 확정하지 마.
```

[8개 분야와 216개 예시 자세히 보기](docs/worldbuilding.md) · [스킬별 다운로드](docs/catalog.md)

**신규 장편 스킬 7개 한 번에 받기:** [장편 스킬 묶음 다운로드](downloads/fantasy-longform-seven-skills.zip). 묶음을 먼저 풀고 서비스별 개별 ZIP을 등록하세요.

## 설치 및 시작하기

> 계정, 요금제, 워크스페이스 설정, 앱 버전에 따라 스킬 메뉴와 사용 가능 여부가 달라질 수 있습니다. 이 저장소의 패키지는 구조를 검증했지만 각 사용자의 실제 서비스 계정에서 설치·실행한 결과는 아닙니다.

### 1. 설치 파일 내려받기

1. GitHub에 로그인하고 이 저장소의 **Code → Download ZIP**을 선택합니다.
2. 내려받은 **저장소 전체 ZIP**을 압축 해제합니다.
3. 아래에서 사용할 서비스의 `dist` 폴더를 열고 필요한 **개별 스킬 ZIP**을 찾습니다. 저장소 전체 ZIP 자체를 스킬로 업로드하지 않습니다.
4. [전체 목록과 다운로드](docs/catalog.md)에서 개별 ZIP 링크를 열고 다운로드할 수도 있습니다. 비공개 저장소라면 접근 권한이 필요합니다.

| 서비스 | 사용할 파일 | 참고 사항 |
|---|---|---|
| ChatGPT 스킬 업로드 | [dist/chatgpt](dist/chatgpt) | 업로드 메뉴가 제공되는 계정에서 사용. 실제 ZIP 수용 여부는 화면에서 확인 |
| ChatGPT 프로젝트 | [프로젝트 지침](platforms/chatgpt/project-instructions.md) + [프로젝트용 문서](dist/chatgpt-project) | 스킬 메뉴가 없을 때 사용하는 별도 방식 |
| Claude | [dist/claude](dist/claude) | 개별 ZIP의 최상위에 스킬명 폴더가 있음 |
| Gemini | [dist/gemini](dist/gemini) | 개별 ZIP의 최상위에 `SKILL.md`가 있음 |

### 2. 서비스별 등록

**ChatGPT:** 스킬 업로드 메뉴가 보인다면 `Plugins → Skills → Create → Upload from your computer`에서 ChatGPT용 개별 ZIP을 선택합니다. 공식 안내의 제공 대상과 실제 계정 메뉴를 확인하세요. ZIP 등록이 불가능하거나 스킬 메뉴가 없다면 프로젝트를 만들고, [프로젝트 지침](platforms/chatgpt/project-instructions.md)을 복사한 다음 필요한 [프로젝트용 문서](dist/chatgpt-project)를 자료로 추가합니다. 프로젝트 방식은 네이티브 스킬 설치와 별개입니다.

**Claude:** 설정의 코드 실행·파일 생성 기능을 활성화한 뒤 `Customize → Skills`에서 Claude용 개별 ZIP을 업로드하고 활성화합니다. 앱에서 등록 메뉴가 보이지 않으면 웹에서 설정한 뒤 사용할 앱에서 적용 여부를 확인하세요.

**Gemini:** 웹에서 `Customize → Skills → Create → Upload`로 이동해 Gemini용 개별 ZIP을 올리고 등록합니다. 이후 대화에서 `/` 또는 지원되는 화면의 `@`로 스킬을 선택하거나 이름을 지정해 요청할 수 있습니다. 참고 파일을 바꾸면 전체 스킬을 다시 업로드해야 합니다.

메뉴별 상세 절차와 제한 사항은 **[ChatGPT·Claude·Gemini 설치 안내](docs/installation.md)**에서 확인하세요. 서비스 화면이 바뀌었거나 메뉴가 보이지 않으면 해당 문서에 연결된 공식 안내를 함께 확인합니다.

### 3. 설치 후 첫 요청

스킬을 등록했다고 가정하고 이름만 언급하는 것보다, 실제로 등록되어 있는지 확인한 뒤 **작업 목적과 필요한 자료를 함께 제공**하세요. ChatGPT 프로젝트 방식에서는 `build-fantasy-world 자료를 적용해`처럼 업로드한 문서 이름을 지정할 수 있습니다.

```text
refine-natural-korean을 적용해 다음 문장을 다듬어 줘.
“그는 문을 열 수 있었다. 그러나 끝내 손잡이에 손을 대지 않았다.”
가능성을 실제 행동으로 바꾸지 말고 수정한 본문만 출력해 줘.
```

설치된 스킬은 GitHub 파일을 수정해도 자동 갱신된다고 가정하지 마세요. 최신 파일로 서비스의 갱신 절차를 따르고, 프로젝트 방식에서는 기존 자료를 교체합니다.

## 작품을 만드는 순서와 요청 예시

작품 전체를 처음부터 끝까지 한 번에 요청하기보다 필요한 단계별로 진행하면 설정과 결과를 검토하기 쉽습니다. 매번 모든 스킬을 사용할 필요는 없습니다.

1. **세계관 설계:** `build-fantasy-world`에 장르·분위기·범위를 알려 주고 후보를 받습니다.
2. **정본 결정:** 작가가 채택한 국가·마법·인물 설정을 별도 설정집에 기록합니다.
3. **본문 집필:** `write-fantasy-prose`에 정본, 이전 장면, 인물 목표와 시점을 제공해 초안을 씁니다.
4. **장면 보완:** 필요한 경우 심리·갈등 또는 장면 묘사 스킬로 특정 부분을 수정합니다.
5. **문장 퇴고:** `refine-natural-korean`으로 수정 범위와 유지할 문체를 지정합니다.
6. **정전 확인:** `audit-fantasy-canon`에 설정집과 관련 원고를 함께 제공해 충돌 후보를 검토합니다.

여러 스킬이 실제로 등록되어 있다면 하나의 요청에서 역할을 나눌 수도 있습니다.

```text
첨부한 확정 설정과 이전 회차를 기준으로 다음 장면을 작성해 줘.

1. write-fantasy-prose로 장면을 구성한다.
2. write-character-conflict로 인물의 선택과 대사의 긴장을 살핀다.
3. write-immersive-scenes로 공간과 동선을 점검한다.
4. refine-natural-korean으로 원래 의미를 지키며 문장을 다듬는다.

시점: [시점 인물과 인칭]
장면 목표: [인물이 이루려는 일]
갈등: [막는 사람이나 상황]
결말: [유지해야 할 장면의 결과]
분량과 문체: [원하는 분량과 문체]

분석 과정을 길게 출력하지 말고 최종 원고를 보여 줘.
새 설정이 필요하면 원고 뒤에 미확정 제안으로 구분해 줘.
```

## 설정과 원고 관리

- **확정 설정·제안·미정 사항을 구분하세요.** 스킬의 예시는 참고용이며 내 작품에 자동으로 채택되지 않습니다.
- **작품별 설정집과 원고를 따로 관리하세요.** 스킬은 대화 간 영구 기억이나 설정의 자동 동기화를 보장하지 않습니다.
- **검토할 자료와 범위를 직접 제공하세요.** AI가 읽지 못한 회차나 설정까지 확인했다고 가정하지 않습니다.
- **수정 범위를 구체적으로 지정하세요.** 단순 문장 교정인지, 장면 재작성인지에 따라 새로운 사건과 세부를 추가할 수 있는 범위가 달라집니다.
- **창작 결과를 작가가 최종 검토하세요.** 예시의 명칭은 실제 사용 여부나 상표·출판 권리를 검증한 목록이 아닙니다.
