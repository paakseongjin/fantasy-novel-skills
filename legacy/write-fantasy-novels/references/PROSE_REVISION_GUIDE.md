# 소설 원고 퇴고 가이드

## 1차 — 이야기의 기능
- 이 장면에서 주인공이 원하거나 피하려는 것은 명확한가?
- 장애는 그 인물의 능력·결핍·환경에서 자연스럽게 발생하는가?
- 선택에 비용이 있고 장면 종료 시 무언가 달라지는가?
- 앞선 복선이 뒷부분에서 회수되며 독자가 받은 약속을 지키는가?

## 2차 — 장면의 구체성
- 중요한 감정을 행동, 지연, 반응, 주저함, 결과로 표현할 수 있는가?
- 감각 묘사는 실제 시점 인물이 알아차릴 만한 것인가?
- 배경 설명은 결정과 갈등에 필요한 순간에 등장하는가?
- 액션은 위치, 거리, 사용 가능한 능력, 결과를 파악할 수 있는가?

## 3차 — 한국어 문체
- 동일한 의미를 하는 문장·비유·수식어를 연달아 쓰지 않았는가?
- 주어·동작 주체·대화 화자를 독자가 혼동하지 않는가?
- 등장인물들이 서로 다른 목소리로 말하는가?
- 지나친 직역투, 추상적인 정서 요약, 설교조 독백이 있는가?
- 긴 문장과 짧은 문장을 장면의 감정에 맞춰 조절했는가?
- 감각과 감정을 무조건 과장하지 않았는가?

## 4차 — 세계관 연속성
- 지명·호칭·관직·계급·능력 단계의 표기가 일치하는가?
- 사건의 날짜와 이동에 필요한 시간은 맞는가?
- 인물의 지식 범위를 넘어선 발언이나 행동이 있는가?
- 부상·피로·소모품·돈·무기 상태가 앞뒤 회차와 연결되는가?
- 정전의 불변 규칙에 없는 편의적 능력이 등장하지 않는가?

## 최소 수정의 예시
**개선 전(설명만 나열):** "그는 아버지를 두려워했고, 아무 말도 할 수 없을 만큼 불안했다."

**개선 후(행동으로 일부 표현):** "아버지가 이름을 부르자 그는 대답 대신 소매 끝을 움켜쥐었다."

이 예시는 상황에 따른 선택지를 보여줄 뿐입니다. 모든 감정 설명을 행동 묘사로 바꾸라는 뜻은 아닙니다. 중요한 것은 장면 전체의 리듬과 의미입니다.
