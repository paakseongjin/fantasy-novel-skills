# 패키지 생성과 검증

[가이드 홈](index.md) · [다운로드](catalog.md) · [변경 이력](versions.md)

이 문서는 저장소의 원본을 수정하거나 배포 파일을 재생성하는 사람을 위한 안내입니다. 스킬을 사용하는 데 아래 명령을 실행할 필요는 없습니다.

## 원본 위치

| 위치 | 역할 | 변경 후 처리 |
|---|---|---|
| `README.md`, `docs/` | 사용자를 위한 설명서 | 링크·수량·지침 일치 확인 |
| `skills/스킬명/` | 기본 창작 17개와 라우터의 지침·참고 자료 | 배포물 재생성 |
| `skills/build-fantasy-world/references/` | 세계관 공통 원본 | 통합형·영향받는 선택형 재생성 |
| `config/worldbuilding-modules.json` | 선택형 8개 본문과 포함 파일 목록 | 배포물 재생성 |
| `platforms/chatgpt/project-instructions.md` | 프로젝트용 공통 지침 | 이 파일을 포함하는 묶음 재생성 |
| `scripts/build_packages.py` | ZIP·단일 문서·manifest 생성 | 생성과 검사 모두 실행 |
| `scripts/validate_repository.py` | 구조·수량·참조·생성물 검사 | 검사 실행 |
| `dist/`, `downloads/` | 배포용 생성물 | 직접 편집하지 않고 원본에서 재생성 |

`core_skills`라는 manifest 필드는 기본 창작 17개와 라우터 1개를 합친 18개를 뜻합니다. 선택형 세계관 8개와 더하면 총 26개입니다.

## 생성과 확인

Python 3.9 이상과 표준 라이브러리를 사용합니다. 저장소 최상위에서 실행하세요.

```bash
python scripts/build_packages.py
python scripts/build_packages.py --check
python scripts/validate_repository.py
```

문서만 바꿨다면 먼저 아래 확인 명령으로 기존 배포물과의 일치를 살펴볼 수 있습니다.

```bash
python scripts/build_packages.py --check
python scripts/validate_repository.py
```

성공 시 현재 구성은 26개 스킬, 78개 ZIP, 18개 프로젝트 문서로 표시됩니다. 문서 링크나 생성물 불일치가 보고되면 해당 원본과 배포 경로를 확인한 뒤 다시 검사합니다. 예상 밖의 파일을 검사기가 자동 삭제하지는 않습니다.

## 재현 가능한 배포물

빌더는 Markdown을 UTF-8로 읽고 줄바꿈을 LF로 통일합니다. ZIP의 파일 순서·타임스탬프도 고정합니다. 같은 원본과 Python/zlib 환경에서는 같은 바이트를 생성합니다.

압축 라이브러리 버전이 다르면 ZIP 바이트와 SHA-256이 달라질 수 있습니다. 검사는 여러 환경에서 ZIP 구조와 압축을 푼 파일을 대조하고, manifest는 저장된 ZIP의 실제 크기와 SHA-256에 맞는지 확인합니다. 생성된 프로젝트 문서와 manifest는 체크아웃 시에도 LF 줄바꿈을 사용합니다.

## 자동 검사의 범위

| 검사 | 확인하는 것 |
|---|---|
| 메타데이터 | 이름 형식·길이, 설명, 필수 값과 폴더명 일치 |
| 패키지 참조 | 개별 패키지 안에서 참조 파일이 존재하는지 |
| ZIP | 압축 무결성, 원본 내용 일치, 서비스별 최상위 구조 |
| 배포 구성 | 총 26개 스킬·78개 ZIP·18개 프로젝트 문서 |
| 라우터 | 대상 25개 이름과 실제 목록 일치, 세계관 대체 자료 존재 |
| 예시 | 세계관 216개 번호의 누락·중복·순서 |
| 문서 | Markdown 상대 링크의 대상 파일 존재 |
| 생성물 | 원본과 배포 파일의 내용·구조 일치, 저장된 ZIP의 manifest 크기·SHA-256 |

현재 저장소 검사기는 문서의 모든 제목 앵커, 외부 URL의 접속 상태나 설명의 사실성을 자동 판정하지 않습니다. 이 항목은 문서 변경 시 별도로 확인해야 합니다. 장편 예시 28개와 연재 예시 16개는 세계관 216개와 별도 집계이며, 세계관 ID 검사로 함께 검사되는 수량은 아닙니다.

## 실제 서비스 검증

`dist/manifest.json`의 `live_platform_installation_tested`는 `false`입니다. 배포 형식 검사는 특정 사용자의 등록·활성화나 모델의 작업 품질을 보증하지 않습니다.

등록 후에는 [빠른 시작](quickstart.md)의 작은 요청을 실행하고, 라우터는 [행동 확인 시나리오](route-fantasy-writing.md#실행-시-확인할-사례)를 사용합니다. 이름을 호출한 사실과 결과가 요청 조건을 지킨 사실을 구분해 기록하세요.

## 지침 길이 측정

개편 전 커밋 `635091e`와 개편본을 같은 `o200k_base` 토크나이저로 비교했습니다. 기본·라우터·선택형의 `SKILL.md` 26개 합계는 28,037 → 8,784 토큰, 한국어 퇴고 지침 한 개는 2,244 → 467 토큰입니다. 이 수치는 지침 텍스트를 센 값입니다. 실제 요청에는 원고·대화·참고 자료와 서비스별 토크나이저가 반영됩니다.

## 변경을 마무리할 때

원본 변경 범위, 필요한 생성물, 설명서와 다운로드 링크를 함께 검토합니다. 버전 이력에는 사용자에게 달라지는 점과 기존 파일의 교체 필요 여부를 적습니다. 변경 후 서비스별 스킬 등록은 사용 중인 계정에서 별도로 갱신해야 합니다.
