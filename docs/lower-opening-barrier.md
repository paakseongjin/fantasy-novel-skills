# 초반 진입장벽 낮추기

`lower-opening-barrier`은 프롤로그·초반 수 회차의 설정 과부하와 첫인상 이탈을 점검하고 진입장벽을 낮춥니다.

## 설치

[서비스별 설치 안내](installation.md) · [스킬별 다운로드](catalog.md) · [스킬 원본](../skills/lower-opening-barrier/SKILL.md)

## 사용 순서

1. 초반 범위(예: 프롤로그~3화)와 반드시 남겨야 할 정보를 정합니다.
2. 해당 원고·개요와 버전을 제공합니다.
3. 의도된 높은 장벽인지, 이해·흥미 문제인지 구분해 달라고 요청합니다.
4. 채택한 재배치만 정본·원고에 반영합니다.

## 요청 예시

```text
lower-opening-barrier 스킬을 적용해 줘.
1~2화에서 설정 설명이 사건을 막고 있는지 찾고, 최소 재배치안을 제안해 줘.

확정 설정과 새 제안을 구분하고, 제공하지 않은 자료는 확인했다고 말하지 마.
[관련 자료 및 확정 설정]
```

## 예시와 작업 양식

스킬에 포함된 [예시와 작업 양식](../skills/lower-opening-barrier/references/examples-and-template.md)에는 네 가지 독립적인 창작·검토 예시와 기록 항목이 있습니다. 예시는 다른 작품의 정본이 아니며, 필요한 항목만 참고합니다.

## 다른 스킬과 함께 사용

회차 전체 리듬은 회차 구성, 원고 전반 진단은 원고 진단, 하차 신호 종합은 하차 위험 점검을 사용합니다. 세계관 자체를 새로 만들 때는 세계관 스킬을 사용합니다. [작업 순서](workflow.md) 참고.
