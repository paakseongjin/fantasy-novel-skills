# 초반 진입장벽 낮추기

[가이드 홈](index.md) · [스킬 목록](catalog.md) · [설치 안내](installation.md)

`lower-opening-barrier` — 프롤로그와 초반 회차에서 독자가 사건을 이해하고 관심을 가질 수 있는지 점검합니다. 고유명·설정 설명이 많거나 주인공의 목적이 늦게 보일 때 사용하세요.

## 준비할 자료

| 항목 | 전달할 내용 |
|---|---|
| 초반 원고 | 검토할 프롤로그·회차와 버전 |
| 필수 정보 | 첫 사건을 이해하는 데 반드시 필요한 설정 |
| 유보할 정보 | 의도적으로 숨긴 비밀과 나중에 설명할 내용 |
| 작품 의도 | 장르·시작 정서·허용하는 낯섦 |

## 요청 예시

```text
lower-opening-barrier로 프롤로그와 1~2화를 검토해 줘.
사건을 이해하는 데 필요한 정보와 뒤로 미룰 정보를 나눠 줘.
주인공의 당장 목표와 위험이 언제 드러나는지 근거를 적어 줘.
의도된 미스터리는 유지하고 최소 재배치안을 제안해 줘.
세계관을 단순화하거나 본문을 다시 쓰지는 마.
[원고 / 반드시 남길 정보 / 숨길 비밀]
```

## 받게 되는 결과

정보의 필요 시점, 첫 장면의 이해와 관심을 막는 지점, 설명·사건의 최소 재배치안을 받습니다.

## 결과 확인

- 비밀의 정답을 몰라도 현재 행동과 위험을 이해할 수 있는가?
- 설명이 필요한 시점보다 너무 빠르거나 늦지 않은가?
- 독특한 분위기를 모두 평범하게 만드는 수정은 아닌가?

## 작업 경계

설명 문장이나 고유명을 무조건 줄이지 않습니다. 의도된 높은 진입장벽과 전달 실패를 구분합니다.
