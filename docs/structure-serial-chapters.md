# 회차 구성·연재 리듬

[가이드 홈](index.md) · [스킬 목록](catalog.md) · [설치 안내](installation.md)

`structure-serial-chapters` — 한 회차가 무엇을 바꾸는지 정하고 장면과 정보를 배치합니다. 다음 화 기획, 회차 분할, 반복 전개와 연결부를 검토할 때 사용하세요.

## 준비할 자료

| 항목 | 전달할 내용 |
|---|---|
| 전후 상황 | 작가가 지정한 직전 원고의 회차·판본·종료 상태와 이후 확정 사건. 비축본에서 이어 쓸 때는 마지막 공개 회차도 따로 표시 |
| 이번 회차 목표 | 인물이 얻거나 잃을 것, 선택과 결과 |
| 연재 조건 | 작가가 정한 분량·독자층·플랫폼, 분할·병합 시 수정 가능한 범위 |
| 구성 제한 | 고정 시점·결말, 반드시 포함하거나 미룰 정보 |

## 요청 예시

```text
structure-serial-chapters로 다음 회차를 구성해 줘.
시작: 주인공 일행은 성문 밖에서 입장을 거절당했다.
끝: 주인공은 들어가지만 동료 한 명은 남는다.
장면 3개 안팎으로 목표, 장애, 선택과 변화를 연결해 줘.
설명해야 할 정보와 뒤로 미룰 정보를 구분해 줘.
본문은 아직 쓰지 마.
[직전 원고 / 확정 설정 / 분량 목표]
```

## 받게 되는 결과

회차 시작 상태에서 끝 상태까지 이어지는 장면 구성과 정보 배치를 받습니다. 필요하면 각 회차의 작은 만족과 다음 회차를 읽을 동기도 함께 검토합니다.

## 결과 확인

- 회차가 끝나도 목표·관계·상황이 그대로인 반복은 없는가?
- 필수 정보가 행동을 이해해야 할 시점에 제시되는가?
- 다음 회차 연결이 사건의 자연스러운 결과에서 나오는가?

## 작업 경계

매번 충격적인 절단형 결말을 만들거나 정해진 글자 수를 강제하지 않습니다. 플랫폼 이름만으로 분량 기준을 확정하지 않습니다.
