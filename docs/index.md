# 사용 가이드

[제품 소개](../README.md) · [다운로드](catalog.md)

처음 등록하는 단계부터 한 회차를 완성하고 다음 작업에 넘기는 단계까지, 필요한 안내를 찾아볼 수 있습니다.

## 시작과 운영

| 상황 | 읽을 문서 | 확인할 내용 |
|---|---|---|
| 처음 써 봅니다 | [빠른 시작](quickstart.md) | 첫 스킬 선택, 등록, 작은 요청으로 결과 확인 |
| 서비스에 등록하려고 합니다 | [설치 안내](installation.md) | Gemini·Claude·ChatGPT의 등록 방법 |
| 어떤 파일을 받을지 찾습니다 | [스킬 목록과 다운로드](catalog.md) | 전체 26개 역할, 플랫폼별 ZIP |
| 여러 스킬을 함께 쓰고 싶습니다 | [조합·라우팅](route-fantasy-writing.md) | 요청 해석, 선택 순서, 단계 간 인계 |
| 실제 집필에 적용하려고 합니다 | [실전 작업 가이드](workflow.md) | 기획·집필·퇴고·연재 점검 흐름 |
| 설정과 이전 회차가 자꾸 누락됩니다 | [작품 자료 관리](project-data.md) | 상태·출처·지식·버전 관리와 인계 |
| 등록이나 결과에 문제가 있습니다 | [문제 해결](troubleshooting.md) | 증상별 확인·해결·재확인 방법 |
| 새 파일로 교체하려고 합니다 | [업데이트와 변경 이력](versions.md) | 중복 방지, 교체, 복구 기준 |

## 근거와 유지 관리

- [공식 문서와 창작 참고 자료](sources.md): 서비스 기능의 근거, 창작 원리의 적용 범위
- [패키지 생성과 검증](maintenance.md): 원본 위치, 재생성 명령, 검사하는 항목

스킬 지침 원본은 `skills/`, 선택형 세계관 구성은 `config/`, 배포 파일은 `dist/`에 있습니다. 사용하는 서비스에 맞는 개별 파일이나 프로젝트 문서를 고르세요. [설치 안내](installation.md)
