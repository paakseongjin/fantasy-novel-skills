# 작품 자료 관리와 회차 인계

[가이드 홈](index.md) · [실전 작업](workflow.md) · [정전 검토](audit-fantasy-canon.md)

스킬은 작업 방법을 제공하고, 작품 자료는 무엇이 사실인지 알려 줍니다. 설정집·원고·인계 기록을 구분하면 같은 작업 지침을 여러 작품에 사용할 수 있습니다. 파일 형식이나 저장 위치는 현재 작업 환경에 맞춰 선택하세요.

## 한 회차를 시작할 때 준비할 자료

| 자료 | 담을 내용 | 주의할 구분 |
|---|---|---|
| 확정 설정 | 이번 회차와 관련된 인물·장소·능력·규칙 | 채택한 설정과 후보 |
| 직전 원고 | 이어지는 장면과 실제 종료 상태 | 작업 중 초고, 작가 확정본, 실제 공개본 |
| 인물 상태 | 위치·부상·소지품·관계·당장의 목표 | 인물이 아는 사실과 작가가 아는 사실 |
| 회차 목표 | 이번 화의 선택·변화·끝 상태 | 반드시 일어날 사건과 선택 가능한 방향 |
| 집필 조건 | 시점·[작품별 문체 카드](../skills/write-fantasy-prose/references/VOICE_CARD.md)·분량·허용할 수정 범위 | 희망 사항과 고정 조건 |

전체 설정집을 항상 다시 설명할 필요는 없습니다. 이번 작업과 연결된 항목을 제공하고, 생략한 부분이 있음을 알려 주세요. 원고가 없으면 요약만으로 작업하는 한계를 함께 기록합니다.

## 자료의 상태를 표시하세요

| 상태 | 의미 | 예시 |
|---|---|---|
| 확정 | 작가가 채택한 사실·규칙 | 능력 사용 뒤에는 손을 움직일 수 없다 |
| 초안 | 작성됐지만 변경 가능한 원고 | 10화 초고 v0.2 |
| 제안 | 아직 채택하지 않은 후보 | 능력의 대가를 피로로 바꾸는 안 |
| 미정 | 결정하지 않은 사항 | 회복에 필요한 시간 |
| 작중 주장 | 인물이 믿거나 말한 내용 | 스승은 “그 능력에는 대가가 없다”고 말함 |
| 폐기·대체 | 이후 사용하지 않을 이전 안 | 옛 규칙을 새 규칙으로 대체한 기록 |

“새 문서”와 “확정 문서”는 같은 뜻이 아닙니다. 버전이 충돌하면 어느 시점부터 어떤 규칙을 적용할지 작가의 결정을 기록합니다. 원고의 거짓말이나 소문을 세계의 객관적 사실로 바꾸지 않습니다.

### 공개본과 정정 이력

공개 여부는 위 자료 상태와 별도로 관리합니다. 회차별로 `작가 확정 버전 / 실제 공개 버전·위치 / 정정 시점·변경 사항`을 남깁니다. 예를 들어 12화 작가 확정본 v1.2와 공개본 v1.3이 다르면, 다음 화에서 독자가 알고 있다고 전제할 수 있는 정보는 실제 공개본에서 확인합니다. 작가만 아는 확정 사실은 정전에 남기고, 두 버전의 사건이 모순되면 작가가 이후 처리 방식을 결정합니다.

정정본에만 있는 단서가 다음 화 이해에 필수라면, 최초 공개본을 읽은 독자도 따라올 수 있게 후속 장면에서 필요한 만큼 다시 보여 줄지 검토합니다. 공개본을 확인하지 못한 항목에는 `확인 필요`를 표시합니다.

## 정보 공개를 따로 기록하세요

비밀 하나라도 **실제 진실 / 독자 공개 상태 / 인물별 지식 / 향후 공개 계획**을 구분합니다.

| 항목 | 실제 진실 | 독자가 아는 것 | 주인공이 아는 것 | 공개 계획 |
|---|---|---|---|---|
| 예시: 스승의 과거 | 작가 확정 내용 | 5화의 공개 장면 | 아직 모름 | 후보이며 미확정 |

이 표는 기록 방식의 예시입니다. 사용 중인 작품의 설정을 뜻하지 않습니다. 계획에 적힌 복선은 원고 속 실제 단서가 아니므로 관련 문장·회차가 확인되기 전에는 “배치 완료”로 표시하지 않습니다.

## 다음 대화에 넘길 기록

```text
작품 / 대상 회차 / 작업·확정·공개 버전 / 정정 이력:
실제로 확인한 원고와 설정:
이번 작업에서 확정한 내용:
회차 종료 상태: 위치 / 시간 / 부상 / 소지품 / 관계
독자에게 공개한 정보 / 초고에서 삭제된 단서와 영향:
인물별 새로 알게 된 사실:
실제 배치·회수한 단서와 원고 위치:
미채택 제안 / 미정 사항:
다음 회차 목표와 금지할 변경:
문체 카드 또는 기준 문단 / 다음 마감·수정 가능 범위 (필요할 때):
저장 여부와 저장 위치:
```

읽은 범위와 저장 여부는 실제 작업 결과에 맞춰 기록합니다. 대화에서 초안을 작성한 것만으로 외부 파일 저장이나 발행이 완료된 것은 아닙니다.
