# 인물 성장·관계 변화

[가이드 홈](index.md) · [스킬 목록](catalog.md) · [설치 안내](installation.md)

`design-character-arcs` — 여러 사건에 걸친 신념과 관계의 변화를 설계합니다. 성장뿐 아니라 타락·정체·변화를 거부하는 선택도 다룰 수 있습니다.

[Gemini ZIP](../dist/gemini/design-character-arcs.zip) · [Claude ZIP](../dist/claude/design-character-arcs.zip) · [ChatGPT ZIP](../dist/chatgpt/design-character-arcs.zip) · [지침 원본](../skills/design-character-arcs/SKILL.md)

## 준비할 자료

| 항목 | 전달할 내용 |
|---|---|
| 출발 상태 | 현재 신념·욕구·두려움과 중요한 관계 |
| 변화 방향 | 도달할 상태 또는 열어 둘 후보 |
| 사건 근거 | 이미 겪은 사건과 앞으로 확정된 사건 |
| 보존 조건 | 바꾸지 않을 성격·관계·결말 |

## 요청 예시

```text
design-character-arcs를 적용해 주인공의 변화 과정을 설계해 줘.
출발: 실패의 책임을 피하려고 모든 결정을 혼자 내린다.
도착: 중요한 임무의 결정을 동료에게 맡긴다.
5단계로 나누되 각 단계마다 사건, 선택, 잃는 것과 관계 변화를 적어 줘.
한 번의 설득으로 성격이 바뀌지 않게 하고, 기존 사건은 유지해 줘.
[인물 기록과 확정 사건]
```

## 받게 되는 결과

행동과 관계에서 확인할 수 있는 변화의 계기, 선택과 대가를 정리한 설계안을 받습니다. “더 성숙해진다”처럼 추상적인 표현은 어떤 선택이 달라지는지까지 확인하세요.

## 결과 확인

- 인물의 변화가 경험과 선택에서 비롯되는가?
- 실패·저항·퇴행이 필요한 지점이 설득력 있게 연결되는가?
- 관계 변화가 주인공뿐 아니라 상대 인물의 선택도 반영하는가?

## 작업 경계

모든 인물이 좋은 사람으로 성장할 필요는 없습니다. 특정 장면의 감정 표현만 문제라면 장기 성장선을 다시 설계하지 않아도 됩니다.
