# 개편 후 동작 확인

[빠른 시작](quickstart.md) · [라우터](route-fantasy-writing.md)

실제 워크스페이스에 필요한 개별 스킬을 등록한 뒤, 스킬명이 없는 요청은 해당 모델이 선택할 수 있는 환경에서 시험합니다. 프로젝트 모드는 필요한 문서만 추가합니다. 각 사례에서 결과와 관찰 가능한 자료 접근을 함께 확인합니다.

| 요청과 입력 | 통과 조건 |
|---|---|
| “번역투만. 수정문만.” 원문: “그는 문을 열 수 있었지만 열지 않았다.” | 퇴고만 적용한다. 가능성·부정을 살리고 수정문만 준다. 예시 파일과 설정집이 필요 없다. |
| “다음 화를 구성하고 본문만 줘.” 직전 종료: 라엔은 부러진 오른손으로 새 열쇠를 숨겼다. 제한 시점은 추적자 유나. | 회차 구조를 내부 작업으로 쓰고 본문으로 끝낸다. 유나가 열쇠를 발견하기 전에는 그 존재를 안다고 쓰지 않는다. |
| “12화에 이어 13화 써 줘.” 12화와 종료 상태가 제공되지 않았다. | 12화 끝 발췌 또는 종료 상태를 짧게 요청한다. 12화 사건을 추정해 이어 붙이지 않는다. |
| “추격전 동선만 고쳐 줘. 승패는 유지.” | 공간 묘사로 시작 위치·경로·도착 위치를 연결한다. 새 능력이나 별도의 전술 설계를 추가하지 않는다. |
| “30화 반전이 회수인지 확인.” 작가 메모에는 7화 단서가 있지만 7화 원고는 없고, 30화에 진실이 공개된다. | 30화의 공개와 7화 단서의 존재를 따로 판단한다. 7화 근거는 확인 필요로 둔다. |
| “정전에 어긋나?” 6화 마법은 일반적으로 사용 후 실명. 승인 개정으로 10화부터 특정 부적 사용 시 예외. 11화에 그 부적을 쓰고 시력이 남는다. | 적용 시점과 조건을 확인한다. 11화의 부적은 승인된 예외로 판정한다. |
| “프롤로그가 어렵대. 개선점만.” 첫 선택의 이후에만 필요한 설정 설명이 앞에 길게 나온다. | 현재 선택에 필요한 정보와 나중에 쓸 정보를 구분해 재배치 위치를 제안한다. 수정 본문과 하차율 수치는 없다. |
| “95~100화에서 실제 하차율 알려 줘.” 누적 조회수만 있다. | 같은 독자의 회차별 이동을 확인할 자료가 필요하다고 짚는다. 누적 조회수 비율은 집계값으로만 설명한다. |
| “다음 화 아이디어 세 개. 스킬은 라우터만 설치했어.” | 회차 구성 지침을 적용했다고 보고하지 않는다. 주어진 자료로 비교 가능한 세 안을 내고 본문을 쓰지 않는다. |
| “수도 이름 세 개만.” 통합형과 선택형 작명 스킬이 모두 있다. | 한 스킬만 적용해서 이름 세 개를 출력한다. 세계 전체와 관련 예시집을 읽을 필요가 없다. |

도구 로그를 볼 수 있다면 같은 지침·원고의 재열람, 선택과 무관한 참고 자료 열람, 중복 검토를 확인합니다. 서비스가 첨부 자료를 내부적으로 어떻게 읽는지는 모델 출력만으로 확인할 수 없습니다.
