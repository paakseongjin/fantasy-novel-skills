# 공간·감각·동선 묘사

[가이드 홈](index.md) · [스킬 목록](catalog.md) · [설치 안내](installation.md)

`write-immersive-scenes` — 독자가 인물의 위치와 움직임을 따라가도록 공간·감각·시간의 흐름을 연결합니다. 추격전의 동선이 헷갈리거나 배경이 행동과 따로 느껴질 때 사용하세요.

## 준비할 자료

| 항목 | 전달할 내용 |
|---|---|
| 공간 조건 | 출발·도착 위치, 통로·장애물·거리 |
| 인물 상태 | 부상·자세·소지품·이동 능력 |
| 시점 | 인칭과 관점 인물이 지각할 수 있는 범위 |
| 보존 조건 | 최종 위치·사건 결과와 추가하면 안 되는 요소 |

## 요청 예시

```text
write-immersive-scenes로 아래 추격 장면을 다듬어 줘.
주인공 1인칭. 시장 입구에서 동쪽 우물까지 이동한다.
골목은 두 사람이 겨우 지나갈 너비이고 추격자는 한 명이다.
주인공은 왼발을 다쳤고 무기는 없다.
결말은 우물 옆 창고에 숨는 것으로 유지해 줘.
위치와 소리의 방향을 명확히 하되 새 도구·마법·추격자는 추가하지 마.
[원고]
```

## 받게 되는 결과

중요한 이동과 접촉의 원인·결과가 이어지는 수정 장면을 받습니다. 감각을 늘린 양보다 장면을 더 잘 이해할 수 있는지를 확인하세요.

## 결과 확인

- 독자가 주요 인물과 장애물의 위치를 따라갈 수 있는가?
- 부상·손에 든 물건·자세가 동작 전후에 이어지는가?
- 감각 묘사가 현재 시점과 사건 속도에 맞는가?

## 작업 경계

장면마다 오감을 모두 넣거나 모든 움직임을 잘게 설명하지 않습니다. 긴장감을 위해 원문에 없는 추적자나 사건을 추가하지 않습니다.
