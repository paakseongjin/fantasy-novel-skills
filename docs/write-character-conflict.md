# 인물 심리와 관계 갈등

[가이드 홈](index.md) · [스킬 목록](catalog.md) · [설치 안내](installation.md)

`write-character-conflict` — 한 장면에서 인물의 욕구와 두려움, 숨기는 사실, 선택의 대가를 연결합니다. 다툼이 억지스럽거나 감정을 설명만 하고 있을 때 사용하세요.

[Gemini ZIP](../dist/gemini/write-character-conflict.zip) · [Claude ZIP](../dist/claude/write-character-conflict.zip) · [ChatGPT ZIP](../dist/chatgpt/write-character-conflict.zip) · [지침 원본](../skills/write-character-conflict/SKILL.md)

## 준비할 자료

| 항목 | 전달할 내용 |
|---|---|
| 각자의 목표 | 상대에게 얻으려는 것과 피하려는 결과 |
| 관계와 힘의 차이 | 의존·권한·빚·죄책감 등 장면에 작용하는 조건 |
| 정보 차이 | 각 인물이 알고 숨기는 사실 |
| 수정 범위 | 원고·시점·고정 결말과 새 사건 허용 여부 |

## 요청 예시

```text
write-character-conflict로 아래 다툼 장면을 수정해 줘.
언니의 목표: 동생이 내일 자수하도록 설득하기.
동생의 목표: 여행비를 받아 오늘 떠나기.
비밀: 동생 대신 다른 동료가 처벌받았다는 사실은 언니만 안다.
동생 3인칭 제한 시점이며 비밀은 직접 공개하지 마.
결말은 동생이 돈을 받지 못하고 나가는 것으로 유지해 줘.
[원고]
```

## 받게 되는 결과

행동과 대사의 이유가 연결된 장면을 받습니다. 진단만 요청했다면 동기·선택·관계 변화에서 부족한 지점과 보완 방향을 확인합니다.

## 결과 확인

- 양쪽 인물이 왜 쉽게 양보하지 못하는지 이해되는가?
- 감정의 이름을 반복하지 않아도 행동의 이유가 드러나는가?
- 관계의 긴장을 만들려고 새 비밀이나 과거사를 임의 추가하지 않았는가?

## 작업 경계

모든 감정을 행동으로만 바꾸거나 모든 대사를 속뜻으로 채우지 않습니다. 단순 교정 요청에서 원문에 없던 사건을 만들지 않습니다.
