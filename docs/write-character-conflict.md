# 인물 심리와 관계 갈등

`write-character-conflict`는 인물의 상반된 욕구, 숨기는 사실, 선택의 대가를 통해 관계의 긴장을 설계하고 원고를 수정합니다. 감정 이름을 많이 붙이는 것보다 행동과 대사의 이유를 구체화합니다.

## 설치

[플랫폼별 설치](installation.md) · [ZIP 다운로드](catalog.md) · [스킬 원본](../skills/write-character-conflict/SKILL.md)

## 사용 순서

1. 인물 관계, 각자가 원하는 것과 알고 있는 사실을 제공합니다.
2. 시점·문체·분량, 바꾸면 안 되는 사건의 결과를 정합니다.
3. 창작인지 기존 장면 수정인지 구분합니다.
4. 대립하는 양쪽 모두에게 이해 가능한 동기가 있는지, 선택 뒤 관계가 달라지는지 확인합니다.

```text
write-character-conflict를 적용해 아래 장면을 수정해 줘.
언니는 동생의 탈영을 숨겼고, 동생은 자신을 구하려고 동료가 처벌받았다는 사실을 모른다.
언니의 목표: 동생이 내일 자수하게 만들기.
동생의 목표: 언니에게서 여행비를 받아 오늘 떠나기.
동생 3인칭 제한 시점. 동생에게 비밀을 직접 알려 주지 마.
결말은 동생이 돈을 받지 못하고 나가는 것으로 유지해 줘.
[원고]
```

## 예시와 점검

단순 진술: “그녀는 동생이 원망스러웠지만 사랑했다.”

새 장면 창작 예시: “언니는 동전을 세다가 두 닢을 도로 넣었다. ‘이걸로는 국경까지 못 가.’ 동생이 손을 내밀자, 그녀는 돈주머니를 식탁 안쪽으로 밀었다.”

이 예시는 사랑과 원망을 특정 행동으로 해석한 **별도의 창작안**입니다. 교정만 요청받았을 때 새 돈주머니·국경 설정을 추가해도 된다는 뜻이 아닙니다. 맥락에 따라 직접적인 감정 서술도 적절하며, 모든 대사를 숨은 뜻으로만 구성하지 않습니다.

## 참고와 경계

헤밍웨이의 생략, 체호프의 절제된 표현을 일반 원리로 참고합니다. 특정 작가의 문체를 그대로 재현하는 기능은 아닙니다. [근거와 적용 범위](sources.md)를 참고하세요. 문장 교정만 필요하면 [한국어 퇴고](refine-natural-korean.md)를 사용합니다.
