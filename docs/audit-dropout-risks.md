## 준비할 자료

| 항목 | 전달할 내용 |
|---|---|
| 작품 약속 | 장르·주요 정서·로맨스나 감정 소모의 허용 범위 |
| 검토 범위 | 회차·원고·개요와 버전 |
| 독자 반응 | 실제로 받은 반응. 없으면 없다고 명시 |
| 수정 여력 | 수정할 수 있는 장면·시간과 고정 조건 |

## 요청 예시

```text
audit-dropout-risks로 제공한 1~10화를 점검해 줘.
독자 약속: 탐험과 관계 변화 중심의 모험 판타지.
독자 반응: 아직 공개하지 않아 없음.
수정 여력: 초반 두 장면만 보완할 수 있음.
위험·양호·자료 부족을 근거와 함께 구분하고 우선 조치 3개 이내를 제안해 줘.
후속 담당 스킬을 안내하되 상세 재설계나 수정 본문은 쓰지 마.
[원고 / 개요 / 유지할 설정]
```

## 받게 되는 결과

근거가 있는 위험과 우선 조치를 받습니다. 예시처럼 후속 스킬 안내를 요청하면 어느 작업부터 할지 함께 제시합니다. 실제 이탈률을 확인하려면 같은 독자 집단의 회차 간 이동 자료가 필요합니다.

## 결과 확인

- 위험 판단에 실제 원고나 독자 반응의 근거가 있는가?
- 취향 불일치와 구조 결함을 구분하는가?
- 우선 조치가 수정 여력에 맞고 없는 이탈률을 만들어 내지 않는가?

## 작업 경계

독자 후기의 경향은 성공 공식이나 이탈률 예측 모델이 아닙니다. 반응 건수만으로 작품의 실패를 판단하지 않습니다.
