# 하차 위험 점검

`audit-dropout-risks`은 웹소설 하차 위험 신호를 독자 불만 경향의 축에 맞춰 종합 점검합니다.

## 설치

[서비스별 설치 안내](installation.md) · [스킬별 다운로드](catalog.md) · [스킬 원본](../skills/audit-dropout-risks/SKILL.md)

## 사용 순서

1. 장르·독자 약속과 검토 범위를 알려 줍니다.
2. 원고·개요와 이미 받은 독자 반응(있으면)을 제공합니다.
3. 원하는 진단 깊이와 수정 여력을 명시합니다.
4. 우선 조치만 채택해 후속 스킬로 넘깁니다.

## 요청 예시

```text
audit-dropout-risks 스킬을 적용해 줘.
1~30화 기준으로 하차 위험 축을 점검하고, 우선 조치 3개만 제안해 줘.

확정 설정과 새 제안을 구분하고, 제공하지 않은 자료는 확인했다고 말하지 마.
[관련 자료 및 확정 설정]
```

## 예시와 작업 양식

스킬에 포함된 [예시와 작업 양식](../skills/audit-dropout-risks/references/examples-and-template.md)에는 네 가지 독립적인 창작·검토 예시와 기록 항목이 있습니다. 예시는 다른 작품의 정본이 아니며, 필요한 항목만 참고합니다.

## 다른 스킬과 함께 사용

상세 수정은 초반 진입장벽·늘어짐 방지·애착 설계·원고 진단 등 담당 스킬로 넘깁니다. 이 스킬은 우선순위 판정과 누락 점검에 집중합니다. [작업 순서](workflow.md) 참고.
