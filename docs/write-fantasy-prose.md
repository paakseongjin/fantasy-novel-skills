# 판타지 집필 스킬

`write-fantasy-prose`는 인물의 욕망과 갈등, 장면의 목적과 인과를 바탕으로 원고를 집필하고 수정합니다. 확정 세계관은 제공된 자료를 따르며 새 설정은 제안으로 구분합니다.

## 설치

[서비스별 설치 안내](installation.md)를 따라 서비스에 맞는 개별 ZIP을 등록하세요. ChatGPT 스킬 메뉴가 없으면 프로젝트 지침·자료 방식을 사용하세요. [다운로드 목록](catalog.md)에서 파일을 선택할 수 있습니다. 등록 후 적용 여부를 확인하세요.

## 사용 순서

1. 장르, 독자층, 시점, 문체, 목표 분량과 앞 장면 요약을 전달합니다.
2. 승인된 세계관과 인물 정보, 현재 장면에서 인물이 아는 사실을 제공합니다.
3. 장면 목표와 갈등을 명시하고 초안 또는 수정 범위를 요청합니다.
4. 결과를 검토한 뒤 정전 변경 후보와 이어지는 장면 정보를 확인합니다.

```text
write-fantasy-prose 스킬을 사용해 주세요.
장르: 동양 판타지 / 시점: 주인공 3인칭 제한
장면: 주인공이 스승의 배신을 의심하지만 확신하지 못한다.
목표: 대화와 행동으로 불신을 드러낸다. 설정 자료와 앞 장면을 확인하고 원고를 작성해 주세요. 새로운 설정은 별도 제안으로 구분해 주세요.
```

`references/SCENE_CARD_TEMPLATE.md`는 장면 설계, `CHAPTER_HANDOFF_TEMPLATE.md`는 다음 회차 인계, `PROSE_CHECK_TEMPLATE.md`는 원고 점검에 활용합니다. 제공하지 않은 자료를 알고 있다고 가정해서는 안 됩니다.
