# 독자 애착·관계 설계

[가이드 홈](index.md) · [스킬 목록](catalog.md) · [설치 안내](installation.md)

`design-reader-attachment` — 독자가 인물과 관계를 계속 보고 싶어 할 만한 계기를 설계합니다. 인물의 장점은 있지만 장면에서 매력이 드러나지 않거나 관계가 기능적으로만 느껴질 때 사용하세요.

## 준비할 자료

| 항목 | 전달할 내용 |
|---|---|
| 인물과 관계 | 핵심 인물의 행동·욕구·서로의 역할 |
| 독자 약속 | 장르, 기대하는 정서와 관계 비중 |
| 원고 근거 | 첫 등장과 중요한 관계 장면 |
| 보존 조건 | 고정 사건·결말과 추가할 수 있는 장면 범위 |

## 요청 예시

```text
design-reader-attachment로 주인공과 동료 둘의 관계를 점검해 줘.
독자 약속: 서로를 알아 가는 모험담. 로맨스는 추가하지 않는다.
각 인물의 매력이 실제 행동에서 드러나는 장면과 부족한 장면을 구분해 줘.
거슬릴 수 있는 언행은 원문 근거로 설명하고 최소 보강안만 제안해 줘.
기존 승패와 사건 결말은 유지해 줘.
[인물 기록 / 첫 등장과 관계 장면]
```

## 받게 되는 결과

인물의 매력과 관계를 보여 주는 행동, 재등장을 기대할 계기, 거슬림 후보와 보강 방향을 받습니다.

## 결과 확인

- 매력을 주변 인물의 칭찬으로만 증명하지 않는가?
- 작가가 원한 장르·관계의 방향을 유지하는가?
- 독자 취향 가설을 확정적인 독자 반응으로 표현하지 않는가?

## 작업 경계

모든 독자가 같은 인물을 좋아할 수는 없습니다. 애착을 위해 인물을 무결하게 미화하거나 원치 않는 로맨스를 추가하지 않습니다.
