# 판타지 원고 편집·진단

`review-fantasy-manuscript`은 원고의 인과·독자 이해·장면 기능을 근거 중심으로 진단합니다.

## 설치

[서비스별 설치 안내](installation.md) · [스킬별 다운로드](catalog.md) · [스킬 원본](../skills/review-fantasy-manuscript/SKILL.md)

## 사용 순서

1. 작품의 장르와 작업 목표, 원하는 결과의 깊이를 알려 줍니다.
2. 관련 원고·확정 설정·이전 회차와 버전을 필요한 범위만 제공합니다.
3. 새 제안이 허용되는지, 기존 사건·인물·결말 중 반드시 유지할 부분이 무엇인지 명시합니다.
4. 결과를 검토하고 채택한 내용만 작품의 설정집에 기록합니다. 확인하지 못한 자료는 검토 범위에서 제외합니다.

## 요청 예시

```text
review-fantasy-manuscript 스킬을 적용해 줘.
첨부한 1~5화의 인물 목표, 인과와 장면 중복을 검토해 줘. 문제 위치와 독자 영향, 수정 방향을 제시하고 원고는 변경하지 마.

확정 설정과 새 제안을 구분하고, 제공하지 않은 자료는 확인했다고 말하지 마.
[관련 자료 및 확정 설정]
```

## 예시와 작업 양식

스킬에 포함된 [예시와 작업 양식](../skills/review-fantasy-manuscript/references/examples-and-template.md)에는 네 가지 독립적인 창작·검토 예시와 기록 항목이 있습니다. 예시는 다른 작품의 정본이 아니며, 필요한 항목만 참고합니다.

## 다른 스킬과 함께 사용

장편 플롯은 전체 인과, 인물 변화는 장기 성장, 복선은 정보 배치, 회차 구성은 연재 리듬을 담당합니다. 전투는 목표와 전술, 대사는 발화 방식, 원고 진단은 독자 이해를 점검합니다. 기존 집필·심리·장면·퇴고·정전 감사 스킬과 겹치는 부분은 요청 범위에 맞춰 한 번만 검토합니다. [작업 순서](workflow.md) 참고.
