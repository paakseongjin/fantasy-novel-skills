# 판타지 세계관 스킬팩

`build-fantasy-world`는 세계의 규칙을 생활·권력·인물의 선택에 연결합니다. 단순한 명칭 목록뿐 아니라 왜 그 사회가 성립하는지, 어떤 갈등을 만들 수 있는지 설계합니다.

## 설치와 선택

[설치 안내](installation.md)와 [다운로드 목록](catalog.md)을 참고하세요. 통합형 1개 또는 분야별 선택형을 설치합니다. 각 개별형도 참고 자료를 포함해 독립적으로 작동합니다. 스크립트·API 키·MCP가 필요하지 않습니다.

통합형이 8개 스킬을 자동 설치하는 것은 아닙니다. 하나의 스킬에서 요청한 분야의 참고 문서를 선택해 읽습니다. 여러 개별 스킬 사이에 작품 정전이 자동 저장·동기화되는 것도 아닙니다.

## 구성과 예시 수
| 분야 | 개별형 이름 | 주요 내용 | 번호가 있는 예시 |
|---|---|---|---:|
| 세계관 | design-fantasy-world | 전제·지리·역사·달력·자원 | 24 |
| 명칭 | name-fantasy-world | 6개 문화권의 인명·국가·도시·조직·마법·직위·유물·신앙 | 48 |
| 마법 | design-fantasy-magic | 원리·한계·비용·보급·유물·사회 파급 | 24 |
| 계급·조직 | design-fantasy-institutions | 신분·작위·관직·군 계급·성직·자격 | 24 |
| 국가 | design-fantasy-nations | 국가·도시·경제·교역·외교·물류 | 24 |
| 종족·문화 | design-fantasy-peoples | 생리·수명·감각·생활·문화 분화 | 24 |
| 종교 | design-fantasy-religions | 신·교리·의례·재정·분파·정치 | 24 |
| 정합성·장면화 | audit-fantasy-worldbuilding | 모순 유형·최소 수정·정본 대장·장면 반영 | 24 |
| 합계 | | | 216 |

216개는 같은 깊이의 완성 세계관 216개를 뜻하지 않는다. 문화권별 명칭 48개와 분야별 설계·검토 카드 168개다.
별도로 장르 프리셋 7종, 하나의 연결 세계관 예제, 설정집 템플릿이 있다. 이 추가 자료는 216개에 중복 합산하지 않았다.
각 예시는 새로 작성한 허구 사례이며 이름의 전 세계적 미사용을 보장하지 않는다.

## 자료를 읽는 순서

1. [공통 규칙](../skills/build-fantasy-world/references/common.md)으로 정본·제안·미정을 구분합니다.
2. 필요한 분야의 지침과 예시만 참고합니다. 예시를 작품의 확정 설정으로 자동 편입하지 않습니다.
3. [장르 프리셋](../skills/build-fantasy-world/references/genre-presets.md)은 서클·원소·오러·정령·사령술·신성력·귀족 체계를 구체화할 때 사용합니다.
4. 분야의 연결은 [연결 세계관](../skills/build-fantasy-world/references/connected-world.md), 다음 대화 인계는 [설정집 양식](../skills/build-fantasy-world/references/world-bible-template.md)을 참고합니다.
5. 최종적으로 확정 모순·설명 누락·의도된 미스터리를 구분합니다. 실제 작품의 장기 연속성 검토는 [정전 감사](audit-fantasy-canon.md)를 사용해도 됩니다.

## 처음 세계를 만들 때
스킬을 선택한 뒤 다음 요청을 보낸다.

```text
한국어 판타지 소설의 세계관을 설계해줘.
분위기: 정치적 긴장과 모험이 있지만 일상의 온기도 있는 세계.
마법: 사회에 알려져 있으나 모든 사람이 사용할 수는 없음.
주인공: 지방 출신 수리 기술자.
이번 범위: 본편 도시 하나, 주변 국가 두 곳, 마법 체계 하나,
권한이 겹치는 조직 두 곳, 종교 두 갈래.

확정 설정은 아직 없어. 필요한 가정은 최대 세 가지로 밝히고 진행해줘.
처음에는 서로 다른 세계관 방향 3개를 비교하고 추천 이유를 알려줘.
예시 이름을 그대로 가져오지 말고 작동 원리와 이해관계를 새로 구성해줘.
제안은 확정 설정과 구분해줘.
```

## 많은 예시를 활용하되 반복을 막는 요청
```text
마법과 종교 참고 예시에서 서로 다른 원리의 사례를 참고해
새로운 체계 6개를 만들어줘.
이름만 바꾼 변형은 피하고 접근 조건, 비용, 사회적 역할이 실제로 달라야 해.
각 안은 작동 원리, 할 수 없는 일, 평민의 생활, 권력 갈등,
소설 속 사용 장면을 포함해줘.
이번에는 기억·수명 소모를 비용으로 쓰지 마.
각 체계는 별개의 후보이며 아직 같은 세계에 합치지 마.
```

## 명칭을 설계할 때
```text
기존 명칭은 아래와 같아. 발음과 조어 규칙을 먼저 분석해줘.
[기존 명칭]

같은 문화권에 어울리는 인명 8개, 도시명 5개, 조직명 3개를 만들어줘.
한글 표기를 우선하고 설정상의 뜻과 부르는 상황을 설명해줘.
실제 고대어에서 유래한 것처럼 주장하지 마.
등장인물이 서로 헷갈릴 만큼 비슷한 이름은 피하고,
후보와 채택된 이름을 구분해줘.
```

## 마법·계급·국가를 연결할 때
```text
다음 마법 규칙은 확정이야.
[확정 규칙]

이 마법이 식량, 교역, 전쟁, 재판, 종교에 미칠 영향을 검토해줘.
마법 능력, 작업면허, 귀족 작위, 관직, 군 지휘권을 구분해줘.
규칙의 빈틈을 이용한 악용 사례와 이를 막는 제도도 제안해줘.
새 한계를 임의로 확정하지 말고 기존 규칙 안에서 가능한 대응을 먼저 찾아줘.
```

## 기존 설정을 검토할 때
```text
아래 설정집과 원고만 근거로 정합성을 검토해줘.
[설정집과 원고]

확정 모순, 설명 누락, 의도된 수수께끼, 취향 차이를 구분해줘.
문제마다 근거 위치와 서사에 미치는 영향, 최소 수정안을 제시해줘.
추측으로 새로운 과거사나 능력을 추가하지 마.
전체 자료를 읽은 것처럼 주장하지 말고 이번 검토 범위를 밝혀줘.
```

## 설정을 장면으로 옮길 때
```text
다음 확정 설정으로 약 1,200자의 장면을 써줘.
[확정 설정]
주인공의 목표: 오늘 안에 다리를 건너 약을 전달하는 것.
장면의 장애: 통행 허가와 안전 점검이 서로 다른 기관의 권한인 것.

국가·종교·종족의 설명을 한꺼번에 강의하지 마.
서류, 호칭, 가격, 대기, 몸의 움직임으로 필요한 설정부터 보여줘.
이 장면을 해결하려고 새 마법이나 권한을 추가하지 마.
```

## 집필과 연결

세계관 설계 → 작가가 채택한 정본 제공 → 장면 집필 → 필요한 심리·묘사 수정 → 한국어 퇴고 → 정전 검토 순서로 진행할 수 있습니다. 매 단계에서 전체 세계를 새로 만들지 않습니다. 구체적인 요청은 [작업 순서](workflow.md)를 참고하세요.

## 설치 확인

```text
마법 예시 M01과 계급 예시 H07을 참고해 학교 난방 시설을 수리하는 장면의 설정을 제안해 줘.
두 예시의 핵심 규칙과 새 제안을 구분해 줘.
참조 파일을 읽지 못하면 그 사실을 밝혀 줘.
```

열을 옮기는 능력을 열 생성으로 바꾸지 않는지, 면허와 정치 신분을 혼동하지 않는지, 예시를 확정 정본이라고 단정하지 않는지 확인합니다. 이 시험만으로 전체 상황의 성능을 보장하지 않습니다.

작품의 확정 설정·미채택 후보·작가만 아는 진실은 예시집과 별도 문서로 관리하세요. [출처](sources.md)와 [검증 범위](maintenance.md)도 참고할 수 있습니다.
