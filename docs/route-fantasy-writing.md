# 자연어 요청에 따른 스킬 조합·라우팅

[가이드 홈](index.md) · [다운로드](catalog.md) · [실전 작업](workflow.md)

`route-fantasy-writing`은 담당 스킬이 불명확하거나 “다음 화를 구성해서 써 줘”처럼 여러 결과물을 이어야 할 때 사용합니다. 대사만 고치는 작업이라면 [대사 스킬](craft-character-dialogue.md)을 바로 사용할 수 있습니다.

## 설치

[Gemini ZIP](../dist/gemini/route-fantasy-writing.zip) · [Claude ZIP](../dist/claude/route-fantasy-writing.zip) · [ChatGPT ZIP](../dist/chatgpt/route-fantasy-writing.zip) · [프로젝트용 문서](../dist/chatgpt-project/route-fantasy-writing.md) · [편집 원본](../skills/route-fantasy-writing/SKILL.md)

라우터와 해당 요청에 필요한 전문 스킬을 준비합니다. ChatGPT 프로젝트에서는 라우터 문서와 필요한 전문 문서를 소스로 추가합니다. 설치와 버전 교체는 [서비스별 안내](installation.md)를 따릅니다.

라우터 ZIP에는 라우팅 지침과 선택표·조합 예시가 들어 있습니다. 다른 25개 전문 스킬 본문을 포함하거나 자동 설치하지 않습니다. 분야별 선택형 8개가 없어도 등록된 `build-fantasy-world`의 관련 지침을 활용합니다. 요청에 필요한 전문 스킬이 실제로 읽히지 않으면 적용 여부를 구분해 알립니다.

## 준비할 자료

원하는 최종 결과, 대상 회차·장면, 확정 설정과 원고, 보존할 조건을 전달합니다. “기획만”, “본문까지”, “진단만”을 구분하면 작업 범위가 분명해집니다.

## 선택과 인계 방식

라우터는 최종 결과를 기준으로 선택표의 한 행부터 사용합니다. 별도 산출물이나 선행 판단이 필요한 경우에만 추가 스킬을 적용합니다. 이미 확인한 자료와 근거를 재사용하고, 다음 단계는 보존 조건과 필요한 상태 변화만 이어받습니다. 연재 인계에는 확인한 공개본 버전과 정정 전후 차이를 함께 남깁니다.

| 단계 | 전달하는 정보 |
|---|---|
| 요청 해석 | 작업 범위, 필요한 결과, 보존 조건 |
| 스킬 선택 | 실제 사용할 수 있는 지침, 부족한 자료 |
| 단계 인계 | 앞 단계의 결과, 확정·제안 구분, 인물별 지식 |
| 마무리 | 요청한 산출물, 결과에 영향을 주는 미확인 사항 |

라우팅만 요청하면 경로를 제시하고, 집필까지 요청하면 실제 결과물까지 진행하는 구조입니다. 자동 적용과 결과의 적절성은 사용 중인 서비스에서 확인해야 합니다.

## 사용 예시

```text
route-fantasy-writing을 적용해 다음 요청에 필요한 스킬을 골라 진행해 줘.
아래 9화에 이어 10화의 장면 구성과 초고를 써 줘.
주인공 시점, 이미 정해 둔 결말과 공개하지 않을 비밀은 유지해 줘.
[직전 원고 / 확정 설정 / 10화 목표 / 분량]
```

Gemini Apps는 `/` 또는 화면에 표시된 `@`, ChatGPT Skills는 `@`로 라우터를 선택합니다. Claude에서는 이름과 작업을 함께 적거나 통합 Plugins 화면이 적용된 경우 대화의 **+** 또는 `/`로 고릅니다. 프로젝트에서는 업로드한 `route-fantasy-writing.md`와 필요한 전문 문서를 명시합니다. [서비스별 안내](installation.md)

| 요청 | 의도한 작동 |
|---|---|
| “다음 화 방향만 세 가지, 본문은 쓰지 마” | 회차 기획만 수행 |
| “대사와 두 사람의 갈등을 함께 고쳐 줘” | 갈등 원인을 정리한 뒤 대사에 반영 |
| “내용을 바꾸지 말고 번역투만 없애 줘” | 한국어 퇴고만 수행 |
| “설정집과 원고가 충돌하는지 확인해 줘” | 정전 감사, 양쪽 근거 대조 |

## 서비스별 조합 범위

- Gemini Apps는 스킬 지침에서 다른 스킬을 참조할 수 있습니다. [Gemini 공식 도움말](https://support.google.com/gemini/answer/17094296?hl=en)
- Claude는 요청에 맞는 여러 스킬을 함께 선택할 수 있습니다. 개별 스킬 지침에 적힌 다른 스킬 이름은 Claude의 명시적 호출로 동작하지 않습니다. [Claude 공식 도움말](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills)
- ChatGPT는 설치된 스킬을 요청에 맞춰 하나 이상 선택할 수 있습니다. 프로젝트 방식에서는 소스로 추가한 문서를 사용합니다. [ChatGPT Skills](https://help.openai.com/en/articles/20001066-skills-in-chatgpt) · [ChatGPT 프로젝트](https://help.openai.com/en/articles/10169521-projects-in-chatgpt)

라우터는 창작 작업의 선택 기준과 순서를 안내합니다. 배포 검사는 파일과 참조를 확인하며, 서비스 계정에서 전문 지침이 실제로 적용되는지는 아래 사례로 점검할 수 있습니다. [공식 자료와 형식 근거](sources.md)

## 실행 시 확인할 사례

아래 사례로 사용하는 서비스에서 동작을 직접 확인할 수 있습니다. 새 대화에 필요한 원고와 설정을 제공하고, 요청 범위·보존 조건·결과를 확인합니다.

| 입력 상황 | 기대 행동 | 실패 신호 |
|---|---|---|
| 직전 원고와 설정을 주고 다음 회차 기획·집필 요청 | 회차 목표·변화를 본문으로 연결 | 라우팅 표만 내고 집필하지 않음 |
| “방향 세 가지만, 본문은 쓰지 마” | 서로 다른 기획안으로 종료 | 하나를 확정하거나 초고 작성 |
| “가능성을 유지해: 그는 문을 열 수 있었다. 끝내 손잡이를 잡지 않았다” | 가능성과 미실행 보존 | 실제로 문을 연 사건으로 변경 |
| 고정된 승패·부상 조건의 추격전 수정 | 동선과 인과 개선, 결말 유지 | 새 마법·무기로 문제 해결 |
| 독자만 아는 비밀이 있는 갈등 장면 수정 | 인물 지식 범위 안의 행동·대사 | 당사자가 비밀을 이미 아는 대사 |
| 실제 단서 없이 반전 계획만 제공 | 계획과 원고 속 단서 구분 | 과거에 단서를 심었다고 주장 |
| 세계관 선택형 없이 통합형만 등록 | 통합형의 해당 자료 적용 | 미설치 분야별 스킬 호출 완료 주장 |
| 라우터만 있고 전문 스킬 지침은 접근 불가 | 선택·자료 안내와 일반 작업 구분 | 이름만 나열하고 전문 지침 열람 주장 |
| 설정집 없이 원고 모순 검사 요청 | 원고 내부 모순으로 범위 제한 | 설정집까지 대조했다고 보고 |
| “진단만”이라는 원고 검토 요청 | 근거·문제·수정 방향으로 종료 | 원고를 재작성·저장 |
| 이미 해결한 문제를 다른 스킬이 다시 라우터로 보냄 | 결과 재사용, 필요한 추가 작업만 | 무한 재선택·반복 감사 |
| 소설과 무관한 날씨 질문 | 소설 스킬 라우팅 생략 | 창작 스킬을 억지로 조합 |

짧은 한국어 교정, 확정 예외, 자료 부족 등은 [개편 후 동작 확인](behavior-checks.md)에 입력 예시와 함께 정리했습니다. 자동 검사는 대상 25개와 세계관 대체 자료, 패키지 구조와 원본 일치를 확인합니다.

조합이 기대와 다르게 작동하면 [문제 해결](troubleshooting.md)을, 회차 자료가 부족하다면 [작품 자료 관리](project-data.md)를 확인하세요.
