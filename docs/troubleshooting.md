# 문제 해결

[가이드 홈](index.md) · [설치 안내](installation.md) · [업데이트](versions.md)

먼저 **등록 문제 / 스킬 선택 문제 / 원고 결과 문제** 중 어디에 해당하는지 확인하세요. 파일을 다시 올리는 것만으로 모든 문제가 해결되지는 않습니다.

## 등록과 파일

| 증상 | 먼저 확인할 것 | 조치와 재확인 |
|---|---|---|
| GitHub 다운로드가 열리지 않음 | 링크가 파일 화면인지, 해당 브랜치에 파일이 있는지 | [다운로드 목록](catalog.md)에서 서비스별 ZIP을 열고 다운로드 버튼을 사용 |
| ZIP 업로드 실패 | 개별 스킬 ZIP인지, 업로드 형식이 지원되는지 | 바깥 묶음은 압축을 풉니다. ChatGPT는 업로드 화면의 지원 형식을 확인합니다. [설치 안내](installation.md) |
| SKILL.md를 찾을 수 없다고 나옴 | 다른 서비스용 ZIP을 받았는지 | Gemini는 루트 파일, Claude는 스킬명 폴더 구조 확인 |
| Skills 메뉴가 없음 | 계정·앱·워크스페이스의 기능 제공 여부 | [서비스별 안내](installation.md) 확인. ChatGPT는 프로젝트 자료 방식도 검토 |
| Claude에서 Customize가 사라짐 | 통합 Plugins 화면 적용 여부 | 사이드바 **Plugins**에서 스킬을 찾고, **+** 또는 `/`로 호출 가능 여부 확인. [Claude 설치 안내](installation.md#3-claude) |
| Claude 스킬이 비활성으로 보임 | 코드 실행·파일 생성과 조직 설정 | 설정을 확인한 뒤 스킬 활성화 상태 재확인 |
| ChatGPT 업로드가 검토 필요·차단 상태 | 화면에 표시된 검사 사유 | 해당 항목을 검토. 성공한 것으로 간주하거나 우회하지 않음 |
| 새 참고 자료가 반영되지 않음 | 기존 등록 파일과 새 ZIP의 버전 | Gemini는 참고 파일을 포함한 전체 스킬 교체. 새 대화에서 재확인 |

서비스 설정 관련 항목은 [Gemini 공식 도움말](https://support.google.com/gemini/answer/17094296?hl=en), [Claude 공식 도움말](https://support.claude.com/en/articles/12512180-use-skills-in-claude), [ChatGPT 공식 도움말](https://help.openai.com/en/articles/20001066-skills-in-chatgpt)을 기준으로 합니다.

## 선택과 조합

| 증상 | 가능한 원인 | 다음 요청 |
|---|---|---|
| 자동으로 스킬을 쓰지 않음 | 비활성 상태 또는 모호한 요청 | 활성화 상태와 [서비스별 선택 방식](installation.md)을 확인하고 정확한 이름과 작업을 명시 |
| 라우터가 스킬 이름만 나열함 | 결과물보다 경로 제안으로 해석 | “선택한 스킬을 적용해 초고까지 작성해 줘”처럼 완료 범위 명시 |
| 라우터가 전문 지침을 읽지 못함 | 전문 스킬이 없거나 접근되지 않음 | 필요한 스킬 선택·활성화 또는 지침 제공. 이름 목록은 실제 지침의 대체물이 아님 |
| 같은 검토가 반복됨 | 통합형·개별형 또는 여러 진단의 범위 중복 | “이미 확인한 근거는 재사용하고 미해결 문제만 검토해 줘” |
| 프로젝트에서 참고 파일을 찾으려 함 | 네이티브 스킬 방식으로 오해 | “업로드한 단일 문서 안의 자료 절을 읽어 줘” |

스킬 이름을 답변에 썼다고 실제 지침을 적용한 것이 확인되는 것은 아닙니다. 공개된 적용 표시나 읽은 자료를 확인할 수 있다면 참고하고, 최종 결과가 조건을 지켰는지도 함께 봅니다.

## 원고와 설정

| 증상 | 조정할 입력 | 결과 확인 |
|---|---|---|
| 교정 중 사건이나 결말이 바뀜 | “문장만”과 보존할 사건을 명시하고 원문 재제공 | 부정·가능성·행동 순서 대조 |
| 인물이 모를 비밀을 말함 | 독자 공개와 인물별 지식 기록을 분리 | 해당 대사와 정보 획득 시점 대조 |
| 없는 과거 회차를 근거로 듦 | 실제 제공 자료와 누락 범위 명시 | 근거 문장을 원문에서 확인 |
| 초고에서 뺀 단서가 다시 등장함 | 작가 확정본·공개본·정정본과 삭제 이력을 명시 | 독자와 인물이 어느 버전에서 단서를 확인할 수 있는지 대조. [연재 실습](serial-writing-example.md) |
| 감사가 새 예외로 충돌을 덮음 | “진단만, 설정 확정 금지” 명시 | 양쪽 근거와 수정 후보가 구분되는지 확인 |
| 장면이 모두 비슷해짐 | 현재 장면의 목표와 [작품별 문체 카드](../skills/write-fantasy-prose/references/VOICE_CARD.md) 제공 | 시점 인물의 감각·판단과 그 장면에 필요한 호흡 확인 |
| 결과가 너무 길거나 표가 많음 | 원하는 출력 형태 지정 | “수정 본문만” 또는 “우선 문제 3개” 준수 |

## 문제가 반복되면 남길 정보

사용 서비스, 등록한 스킬 이름, 받은 파일의 커밋·날짜, 정확한 요청, 실제 결과와 기대 결과를 함께 기록하세요. 원고는 문제를 재현할 수 있는 짧은 부분으로 줄여도 됩니다. 비공개 작품 자료는 공유할 범위를 직접 선택합니다.

[짧은 확인 예제](quickstart.md)로 기본 작업을 다시 확인하고, 라우터 문제라면 [검증 시나리오](route-fantasy-writing.md#실행-시-확인할-사례) 중 해당 상황을 시험하세요.
