# 작업 순서와 실전 프롬프트

[스킬 목록](catalog.md)에서 필요한 것만 등록하고 [설치 안내](installation.md)에 따라 확인하세요. 이름을 적는 것만으로 미설치 스킬이 생기지는 않습니다. ChatGPT 프로젝트 방식에서는 같은 이름의 업로드 문서를 지정합니다.

## 작품을 시작하는 순서

| 단계 | 사용할 지침 | 작가가 제공할 것 | 확인할 결과 |
|---|---|---|---|
| 세계 설계 | build-fantasy-world 또는 개별형 | 분위기·이야기 범위·확정 전제 | 작동 조건·사회 파급·미정 |
| 장면 집필 | write-fantasy-prose | 채택한 정본·시점·장면 목표 | 선택과 결과가 있는 원고 |
| 갈등 보완 | write-character-conflict | 관계·욕구·인물별 지식 | 동기·대사의 속뜻·관계 변화 |
| 묘사 보완 | write-immersive-scenes | 위치·동선·장애·감각 범위 | 따라갈 수 있는 장면 |
| 문장 퇴고 | refine-natural-korean | 원고·문체·수정 수준 | 의미를 보존한 한국어 |
| 정전 검사 | audit-fantasy-canon | 확정 자료·관련 원고·버전 | 근거·충돌 후보·최소 수정안 |

매번 6단계를 모두 실행하는 의무 절차는 아닙니다. 문장만 고칠 때는 퇴고만, 국가를 만들 때는 세계관 지침만 사용하세요. 모순은 설계·집필 중에도 발견 즉시 확인합니다.

## 여러 지침을 한 번에 요청

```text
첨부한 확정 세계관과 이전 회차를 기준으로 다음 장면을 써 줘.
write-fantasy-prose로 초안을 구성하고,
write-character-conflict로 인물의 선택과 대사의 긴장을 확인한 뒤,
write-immersive-scenes로 위치와 동선을 점검하고,
refine-natural-korean으로 문장을 다듬어 줘.
모든 단계에서 확정 설정과 사건의 결말을 유지해 줘.
각 단계의 분석을 길게 출력하지 말고 최종 원고만 보여 줘.
새 설정이 꼭 필요하면 원고 뒤에 미확정 제안으로 구분해 줘.
[장면 목표 / 시점 / 인물 관계 / 분량 / 결말]
```

## 감사와 수정의 분리

```text
audit-fantasy-canon으로 아래 자료만 감사해 줘.
검토 범위: 1~3화, 인물 지식과 이동 시간.
확정 설정: [자료명·버전]
원고: [자료명·버전]
문제마다 양쪽 근거와 시점·조건을 밝혀 줘.
의도된 비밀과 실제 모순을 구분하고 수정은 아직 하지 마.
```

감사에서 제안한 변경을 채택하면 대상 설정·적용 시점·바뀌는 회차를 명확히 전달합니다. 작품 상태는 별도 정전 문서에 모아 다음 대화에도 제공합니다. 스킬 파일과 예시집을 작품 정전 대신 사용하지 않습니다.

## 장편 설계와 회차 연재 확장

작품 전체의 인과는 [장편 플롯](plan-fantasy-longform.md), 장기 인물 변화는 [인물 성장](design-character-arcs.md), 복선과 반전은 [복선 관리](manage-fantasy-foreshadowing.md), 회차 간 리듬은 [회차 구성](structure-serial-chapters.md)을 적용합니다. 필요하면 [전투](design-fantasy-action.md)와 [대사](craft-character-dialogue.md)를 집중 설계하고 [원고 진단](review-fantasy-manuscript.md)으로 독자의 이해와 구조를 점검합니다. 정전 충돌의 근거 확인은 기존 감사와 나누어 중복을 피합니다.

## 웹소설 연재 점검

독자 애착은 [애착 설계](design-reader-attachment.md), 초반 이탈은 [진입장벽](lower-opening-barrier.md), 중후반 정체·연재 피로는 [늘어짐 방지](prevent-serial-drag.md), 종합 우선순위는 [하차 위험 점검](audit-dropout-risks.md)을 적용합니다. 떡밥 회수는 기존 복선 관리로 충분하므로 새 스킬을 만들지 않았습니다. 같은 구간을 여러 스킬로 반복 진단하지 않습니다.
