# 실전 작업 가이드

[가이드 홈](index.md) · [스킬 조합·라우팅](route-fantasy-writing.md) · [작품 자료 관리](project-data.md)

한 번의 요청에는 원하는 결과와 바꾸지 않을 조건을 함께 적습니다. 아래 흐름은 작업 예시이며, 모든 회차에 모든 스킬을 적용해야 한다는 뜻은 아닙니다.

## 요청을 구성하는 네 가지 정보

| 정보 | 예시 |
|---|---|
| 작업 | 다음 화 기획 / 초고 작성 / 대사 수정 / 오류 진단 |
| 근거 자료 | 확정 설정 v2, 9화 확정본, 인물 상태 기록 |
| 보존 조건 | 주인공 시점, 공개하지 않을 비밀, 고정된 결말 |
| 결과 형태 | 기획안 3개 / 본문만 / 근거와 최소 수정안 |

자료가 많으면 전체 분량보다 관련 범위를 지정하세요. “자료를 모두 읽었지?” 대신 어떤 자료의 어느 부분을 근거로 삼았는지 확인하는 편이 도움이 됩니다.

## 1. 세계관과 장편의 방향 잡기

먼저 [세계관 설계](worldbuilding.md)로 이야기의 조건을 정합니다. 작품 전체 사건은 [장편 플롯](plan-fantasy-longform.md), 인물의 장기 변화는 [인물 성장](design-character-arcs.md)으로 연결할 수 있습니다.

```text
route-fantasy-writing을 적용해 필요한 기획 스킬을 골라 줘.
목표: 지방 수리공이 왕국의 금지된 역사를 찾는 장편 기획.
확정 전제: 마법은 열을 옮길 수 있지만 새로 만들 수는 없다.
이번 범위: 시작 도시와 첫 이야기 단위의 사건 인과.
결과: 서로 다른 방향 3개와 각 안의 장단점.
아직 하나를 확정하거나 본문을 쓰지 마.
```

작가가 채택한 내용만 설정집에 남깁니다. 다른 후보의 규칙이 선택한 세계관에 섞이지 않았는지 확인하세요.

## 2. 다음 회차 구성하고 쓰기

[회차 구성](structure-serial-chapters.md)에서 목표와 변화를 정하고 [본문 집필](write-fantasy-prose.md)로 이어 갑니다. 비밀 공개가 핵심이면 [복선 관리](manage-fantasy-foreshadowing.md)를 추가합니다.

```text
route-fantasy-writing으로 다음 화를 구성하고 초고까지 써 줘.
자료: 아래 확정 설정, 직전 원고, 인물 상태를 기준으로 해.
이번 목표: 주인공이 도시로 들어갈 방법을 찾아 실행한다.
시점: 주인공 3인칭 제한.
고정 결말: 입성에는 성공하지만 동료와 헤어진다.
비밀: 주인공은 동료의 과거를 아직 모른다.
분량: [작가가 정한 목표].
출력: 초고와 새로 제안한 설정만 짧게 구분해 줘.
[확정 자료와 직전 원고]
```

문피아 등 플랫폼을 정했다면 작가가 정한 목표 분량·독자 약속을 함께 전달하세요. 플랫폼 이름만으로 정책이나 모든 독자의 취향을 단정하지 않습니다. 발행 요건 확인은 집필과 별도로 해당 플랫폼의 최신 공식 안내를 살핍니다.

## 3. 원고의 한 문제만 고치기

| 눈에 띄는 문제 | 먼저 사용할 스킬 | 보존할 조건 |
|---|---|---|
| 갈등의 동기가 납득되지 않음 | [관계 갈등](write-character-conflict.md) | 인물 목표·지식·장면 결말 |
| 누가 어디에 있는지 헷갈림 | [공간·감각 묘사](write-immersive-scenes.md) | 위치·부상·소지품·최종 동선 |
| 전투 승패의 이유가 약함 | [액션 설계](design-fantasy-action.md) | 능력의 한계·승패·대가 |
| 인물들의 대사가 비슷함 | [대사 설계](craft-character-dialogue.md) | 발언 의미·호칭·관계 |
| 번역투와 반복이 거슬림 | [한국어 퇴고](refine-natural-korean.md) | 사건·시제·시점·목소리 |
| 문제를 특정하기 어려움 | [원고 진단](review-fantasy-manuscript.md) | 우선 진단할 범위 |

```text
craft-character-dialogue로 아래 대사만 다듬어 줘.
대장과 신입의 존대 관계, 발언의 정보, 다툼의 결말은 유지해 줘.
대장에게 새 과거사나 비밀을 추가하지 마.
수정 대사와 의미가 달라질 수 있는 지점만 보여 줘.
[인물 관계 / 대사 원문]
```

## 4. 설정과 연속성 확인하기

[정전 감사](audit-fantasy-canon.md)에 비교할 자료를 함께 제공합니다. 오류 검토와 실제 수정은 구분합니다.

```text
audit-fantasy-canon으로 아래 자료만 검토해 줘.
범위: 8~10화의 인물 지식과 이동 시간.
기준: 확정 설정 v2와 각 회차 확정본.
문제마다 충돌하는 양쪽 근거, 적용 시점, 확실성과 최소 수정안을 제시해 줘.
독자만 아는 비밀과 인물의 거짓말을 오류로 단정하지 마.
이번에는 원고나 설정을 직접 수정하지 마.
[자료]
```

변경을 채택하면 대상 항목, 적용 시작 시점, 영향받는 회차를 함께 기록합니다. “앞으로만 적용”과 “이전 원고에도 소급 적용”은 다른 결정입니다.

## 5. 연재 구간 점검하기

초반은 [진입장벽](lower-opening-barrier.md), 중후반은 [늘어짐](prevent-serial-drag.md), 인물·관계의 관심은 [독자 애착](design-reader-attachment.md)을 살핍니다. 여러 문제가 섞였거나 수정 여력이 적다면 [하차 위험](audit-dropout-risks.md)으로 우선순위부터 정합니다.

```text
audit-dropout-risks로 제공한 1~10화의 위험 신호를 정리해 줘.
독자 약속: 관계의 변화와 탐험이 중심인 모험 판타지.
독자 반응: 아직 공개하지 않아 없음.
수정 여력: 초반 두 장면만 보완할 수 있음.
근거와 우선 조치 3개 이내, 다음에 쓸 스킬만 알려 줘.
상세 재설계나 수정 본문은 아직 쓰지 마.
[원고와 개요]
```

독자 반응이 없다면 실제 반응이나 이탈률을 만들어 내지 않습니다. 원고에서 관찰한 위험과 독자 취향에 대한 가설을 나누어 검토하세요.

## 6. 다음 작업에 넘기기

최종 검토 후 확정한 변경, 회차 종료 상태, 인물별 새 정보, 미정 사항을 기록합니다. [회차 인계 양식](../skills/write-fantasy-prose/references/CHAPTER_HANDOFF_TEMPLATE.md)을 사용하거나 [간단한 인계 항목](project-data.md)만 작성해도 됩니다.

다음 대화에는 인계 기록과 관련 원고를 다시 제공하세요. 스킬의 지침과 작품의 기억은 서로 다른 자료입니다.
