# 중후반 늘어짐·연재 피로 점검

[가이드 홈](index.md) · [스킬 목록](catalog.md) · [설치 안내](installation.md)

`prevent-serial-drag` — 연재가 길어지면서 목표가 정체되거나 비슷한 장애·결과가 반복되는 구간을 살핍니다. 단순히 사건을 더 넣기 전에 기존 회차가 어떤 기능을 하는지 확인합니다.

[Gemini ZIP](../dist/gemini/prevent-serial-drag.zip) · [Claude ZIP](../dist/claude/prevent-serial-drag.zip) · [ChatGPT ZIP](../dist/chatgpt/prevent-serial-drag.zip) · [지침 원본](../skills/prevent-serial-drag/SKILL.md)

## 준비할 자료

| 항목 | 전달할 내용 |
|---|---|
| 구간 자료 | 검토할 여러 회차의 원고·개요 |
| 장기 목표 | 독자에게 제시한 목표와 현재 진척 |
| 유지할 요소 | 관계·정서·일상 장면 중 삭제하면 안 되는 부분 |
| 작업 조건 | 마지막 공개 회차, 수정 가능한 비축분, 다음 마감까지의 작업량, 고정 결말 |

## 요청 예시

```text
prevent-serial-drag로 20~27화의 목표 진척을 점검해 줘.
같은 장애와 결과가 반복되는 구간을 근거로 보여 줘.
휴식 회차는 인물 관계가 바뀌는지 먼저 확인하고 삭제 대상으로 단정하지 마.
공개본을 이어받아 답이나 선택을 보강하는 안을 먼저 제안해 줘.
20~24화는 공개돼 유지해야 하고, 25~27화 중 장면 하나만 손볼 수 있어.
[구간 원고·개요 / 장기 목표 / 보존 조건]
```

## 받게 되는 결과

회차의 반복 기능과 목표 정체 지점, 중간 성취·축약·병합 등 완화 후보를 받습니다. 바뀐 구성이 후속 사건에 미칠 영향도 함께 검토하세요.

## 결과 확인

- 느린 호흡과 진척 없는 반복을 구분하는가?
- 관계·정서가 달라지는 회차를 사건이 적다는 이유만으로 삭제하지 않는가?
- 제안이 작가의 수정 여력과 고정된 사건에 맞는가?

## 작업 경계

분량을 줄이는 것만이 해결책은 아닙니다. 연재 주기나 독자 반응을 제공받지 않았다면 임의로 판단하지 않습니다.
