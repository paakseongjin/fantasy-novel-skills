# 자연스러운 한국어 서사 퇴고

`refine-natural-korean`은 어휘의 결합, 문장 호응, 번역투, 반복과 대사를 점검합니다. 원문의 사건과 확신 정도, 인물의 말투를 보존합니다. AI 탐지 회피나 사람이 썼다는 판정 보장을 목적으로 하지 않습니다.

## 설치

[플랫폼별 설치](installation.md) · [ZIP 다운로드](catalog.md) · [스킬 원본](../skills/refine-natural-korean/SKILL.md)

## 사용 순서

1. 원고와 원하는 수정 수준을 제공합니다: 맞춤법 / 문장 다듬기 / 문체 개선 / 재작성.
2. 유지할 시점·시제·고풍스러운 어조·인물 말투 등을 명시합니다.
3. 기본 결과는 수정 본문이며, 필요할 때만 변경 이유를 요청합니다.
4. 부정·가능성·인과·행동 순서가 바뀌지 않았는지 비교합니다.

```text
refine-natural-korean으로 다음 원고의 문장만 다듬어 줘.
사건·정보·시점·시제와 인물의 말투를 유지해 줘.
번역투와 불필요한 반복은 줄이되 새로운 감각·비유·과거사를 만들지 마.
잘 작동하는 긴 문장과 의도적인 반복은 그대로 둬.
수정 본문을 먼저 제시하고 의미가 갈리는 부분만 짧게 알려 줘.
[원고]
```

## 의미 보존 예시

| 원문 | 처리 | 이유 |
|---|---|---|
| 그는 대답을 하는 대신에 자신의 시선을 창문 쪽으로 이동시켰다. | 그는 대답 대신 창문 쪽으로 시선을 돌렸다. | 행동을 유지하면서 우회 표현을 줄입니다. |
| 그는 문을 열 수 있었다. | 실제로 열었다는 근거가 없으면 가능성 표현을 유지합니다. | “문을 열었다”로 바꾸면 사건이 달라집니다. |
| 어머니는 오지 않았다. 오지 않을 것이다. | 반복이 체념과 시간 변화를 만든다면 보존합니다. | 반복 자체는 오류가 아닙니다. |
| 나는 그가 거짓말을 했다고 생각했다. | 추측의 범위를 보존합니다. | “그는 거짓말했다”는 사실 단정입니다. |

한자어·부사·피동·‘그’·‘그녀’ 등을 금지어로 일괄 삭제하지 않습니다. 문장 끝이 ‘다’로 반복된다는 이유만으로 어미를 억지로 바꾸지 않습니다. [출처와 적용 범위](sources.md)를 참고하세요.
