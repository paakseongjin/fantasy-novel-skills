## 준비할 자료

| 항목 | 전달할 내용 |
|---|---|
| 수정 수준 | 맞춤법 / 문장 다듬기 / 문체 개선 / 재작성 |
| 원문 | 수정할 범위와 앞뒤 맥락 |
| 보존할 요소 | 시점·시제·사건·고풍스러운 어조·인물 말투. 작품별 기준이 반복되면 [문체 카드](../skills/write-fantasy-prose/references/VOICE_CARD.md)나 대표 문단 첨부 |
| 출력 방식 | 수정 본문만 또는 주요 변경 이유 포함 |

```text
refine-natural-korean으로 아래 원고의 문장만 다듬어 줘.

가능성을 실제 행동으로, 추측을 확정으로 바꾸지 마.
잘 작동하는 긴 문장과 의도적인 반복은 살려 줘.
수정 본문을 먼저 보여 주고 의미가 갈리는 부분만 짧게 설명해 줘.
[원고]
```

## 받게 되는 결과

지정한 수준의 수정 본문을 받습니다. “문을 열 수 있었다”가 “문을 열었다”로 바뀌면 사건의 의미가 달라지므로 자연스러움만으로 채택하지 마세요.

## 결과 확인

- 부정·가능성·확신의 정도와 사건 순서가 유지되는가?
- 인물별 말투와 서술자의 어조가 평준화되지 않았는가?
- 새 감각·물건·과거사를 추가해 사실을 바꾸지 않았는가?

## 작업 경계

모든 부사·한자어·긴 문장을 일괄 삭제하지 않습니다. AI 탐지기 결과나 특정 작가의 문체 재현을 보장하는 기능이 아닙니다.
