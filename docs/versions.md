# 업데이트와 변경 이력

[가이드 홈](index.md) · [다운로드](catalog.md) · [문제 해결](troubleshooting.md)

GitHub의 변경은 등록된 스킬에 자동으로 반영되지 않습니다. 사용하는 서비스에서 해당 스킬을 새 파일로 교체해야 합니다. 문서만 수정된 변경이라면 스킬을 다시 등록할 필요가 없습니다.

## 파일 교체 순서

1. 아래 변경 이력에서 달라진 스킬과 사용 중인 파일을 확인합니다.
2. 현재 사용 중인 ZIP과 받은 시점의 커밋을 보관합니다. 서비스에서 따로 수정한 지침이 있다면 함께 남깁니다.
3. [다운로드 목록](catalog.md)에서 같은 서비스용 최신 개별 ZIP을 받습니다.
4. 서비스의 교체·갱신 메뉴로 적용합니다. 새 항목으로 등록했다면 같은 이름의 이전 항목이 중복 활성화되지 않게 확인합니다.
5. 새 대화에서 [확인 예제](quickstart.md)와 실제 작업의 짧은 예시를 시험합니다.

Gemini는 참고 자료를 포함한 전체 스킬을 다시 업로드합니다. ChatGPT 프로젝트 자료 방식은 이전 문서와 새 문서가 함께 남아 혼동되지 않도록 관리하세요. 자세한 메뉴는 [설치 안내](installation.md)를 따릅니다.

## 이전 파일로 돌아가려면

보관한 ZIP 또는 원하는 GitHub 커밋의 배포 파일을 받아 같은 방법으로 교체합니다. 설정·원고는 스킬과 별도의 자료이므로, 스킬 버전을 바꾼다고 작품의 설정 변경이 자동으로 되돌아가지는 않습니다.

## 중복을 피하는 기준

| 항목 | 사용 기준 |
|---|---|
| 라우터 | 전문 스킬을 대신 설치하는 도구가 아니라 선택과 인계를 담당 |
| 세계관 통합형 / 선택형 8개 | 같은 분야의 대체 구성. 중복 설계하지 않음 |
| 본문 / 갈등 / 묘사 / 대사 / 문장 퇴고 | 원고 전체 작성과 특정 문제 보완을 구분 |
| 세계관 감사 / 정전 감사 | 설정의 인과 연결과 실제 작품 자료의 충돌 대조를 구분 |
| `legacy/write-fantasy-novels` | 이전 통합형 보관 자료. 현재 구성과 중복 등록하지 않음 |

## 2026-11-17 — 창작 지침과 자료 읽기 순서 개편

- 기본·라우터·선택형 26개 지침을 작업별 판단과 출력 기준 중심으로 줄였습니다. 단일 작업은 바로 처리하고 복합 작업은 관련 근거와 상태 변화만 이어 줍니다.
- 초반의 기대와 첫 사건, 회차별 보상과 다음 행동, 중후반 반복, 복선의 실제 근거, 정전 적용 시점을 구체화했습니다. 양식과 예시는 필요한 작업에서만 엽니다.
- 새 개별 ZIP 또는 프로젝트 문서와 지침으로 교체할 수 있습니다. [동작 확인 사례](behavior-checks.md)에서 작업 범위와 결과를 검증하세요.

## 2026-11-15 — 제품 사용 가이드 개편

- README를 첫 사용의 시작점으로 정리하고 가이드 홈, 빠른 시작, 작품 자료 관리, 문제 해결 문서를 추가했습니다.
- 서비스별 설치 절차를 공식 문서와 대조하고, 스킬별 준비 자료·요청 예시·결과 확인 기준을 정리했습니다.
- 다운로드 목록, 라우터 안내, 업데이트·검증 범위를 현재 26개 구성에 맞췄습니다.
- 사용 설명서 변경입니다. 스킬 지침과 기존 설치 ZIP의 재등록은 필요하지 않습니다.

## 2026-11-15 — 자연어 스킬 라우터 추가

- `route-fantasy-writing`이 요청 범위에 맞는 전문 스킬을 선택하고 단계별 결과를 연결합니다.
- 특정 작품·외부 저장 공간과 무관하게 사용하며, 기본 창작 17개와 선택형 8개를 대상으로 합니다.
- 현재 구성은 기본 창작 17개 + 라우터 1개 + 선택형 8개, 총 26개입니다. 서비스별 ZIP 78개와 프로젝트 문서 18개를 제공합니다.
- 기존 창작 스킬을 등록했다면 라우터만 추가하면 됩니다. 새 라우터의 실제 서비스 실행은 별도 확인 대상입니다.

## 2026-11-15 — 웹소설 연재 점검 스킬 4개 추가

- 캐릭터·관계 애착, 초반 진입장벽, 중후반 늘어짐·연재 피로, 하차 위험 점검 스킬 4개를 추가했습니다. 각 스킬에 네 가지 예시와 작업 양식을 포함합니다.
- 공개 후기에서 관찰한 경향을 점검 관점으로 활용합니다. 무작위 표본·교차 검증을 거친 성과 예측으로 해석하지 않습니다.
- 떡밥·반전 회수는 기존 `manage-fantasy-foreshadowing`과 겹쳐 새 스킬을 만들지 않았습니다.
- 이 추가 시점의 구성은 기본 17개·선택형 8개, 총 25개였습니다. 이후 라우터가 추가되어 현재 수량은 달라졌습니다.
- 웹소설 연재 스킬 묶음 ZIP을 추가했습니다. 실제 서비스 계정 설치·모델 실행은 수행하지 않았습니다.
