# 버전과 중복 정리

기본 스킬은 집필과 감사의 책임을 분리한 두 스킬입니다. 감사 스킬의 `SKILL.md`는 별도 저장된 최신 수정본을 사용하며, 참고 양식은 두 스킬 묶음의 원본을 유지합니다.

`legacy/write-fantasy-novels`는 이전 통합 스킬로 집필과 정전 검토가 기본 스킬과 겹칩니다. 참고·복구용이며 기본 두 스킬과 동시에 설치하지 않는 것을 권장합니다. 초기 압축파일 두 개는 같은 구성과 본문을 포함하므로 한 벌만 보관했습니다. 원본별 압축파일은 중복 저장하지 않았습니다.

최근 별도 대화에서 요청한 심리·갈등, 장면 묘사, 한국어 문체, 세계관 설정 스킬팩은 접근 가능한 오늘 생성 파일에서 별도 산출물로 확인되지 않았습니다. 이 저장소에 포함되었다고 간주하지 마세요.

`dist/gemini`는 ZIP 루트에 `SKILL.md`를, `dist/claude`는 ZIP 루트에 스킬 폴더를 둡니다. 두 패키지는 동일한 기본 스킬과 참고 파일을 담으며 서비스별 설치 형태만 다릅니다. ChatGPT 프로젝트 지침은 `platforms/chatgpt`에 있습니다. 이들은 서로 다른 작품 데이터를 보관하지 않습니다.
