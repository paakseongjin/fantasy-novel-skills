# 세계관 정전·설정 감사 스킬

`audit-fantasy-canon`은 확정 설정과 원고를 대조해 시간, 인물 지식, 능력, 소지품, 복선 등의 충돌을 근거와 함께 검토합니다. 승인 없는 정전 변경은 수행하지 않습니다.

## 설치

[공통 설치 안내](installation.md)에 따라 `skills/audit-fantasy-canon` 폴더 전체를 `.agents/skills/audit-fantasy-canon`으로 복사하고 `/skills`에서 인식을 확인하세요.

## 사용 순서

1. 최신 승인 세계관 문서, 관련 회차와 인물 상태를 제공합니다.
2. 각 자료의 버전, 확정 여부와 검토할 범위를 지정합니다.
3. 충돌의 양쪽 근거와 심각도·확실성 및 수정 대안을 요청합니다.
4. 의도된 거짓말이나 정보 비대칭이 오류로 오인되지 않았는지 검토합니다.
5. 변경안을 채택할 때 적용 시점과 영향을 명시하고 작가가 승인합니다.

```text
audit-fantasy-canon 스킬로 제공한 세계관과 12화를 검증해 주세요.
인물의 지식, 마법 사용 비용, 이동 시간에 집중하고 충돌마다 양쪽 근거와 해결안을 제시해 주세요. 원고와 정전은 수정하지 마세요.
```

`references`의 세계관·연속성 기록 양식과 감사 보고서·변경 요청서 양식을 활용하세요. 누락된 자료가 있으면 결과는 제공된 범위에 한정됩니다.
