# 빠른 시작

[가이드 홈](index.md) · [설치 안내](installation.md) · [다운로드](catalog.md)

첫 사용의 목표는 **작은 작업 하나를 요청하고, 원하는 조건이 지켜졌는지 확인하는 것**입니다. 처음부터 모든 스킬을 등록할 필요는 없습니다.

## 1. 첫 작업을 고르세요

| 하고 싶은 일 | 먼저 등록할 스킬 | 준비 자료 |
|---|---|---|
| 문장을 자연스럽게 다듬기 | `refine-natural-korean` | 짧은 원고와 수정 수준 |
| 세계관 방향 만들기 | `build-fantasy-world` | 장르·분위기·설계할 범위 |
| 장면 본문 쓰기 | `write-fantasy-prose` | 시점·목표·결말·관련 설정 |
| 원고와 설정 대조하기 | `audit-fantasy-canon` | 확정 설정과 관련 원고 |

이미 전문 스킬을 등록했고 여러 작업을 연결하고 싶다면 [라우터](route-fantasy-writing.md)를 추가하세요. 라우터만 등록해도 다른 스킬이 함께 설치되는 것은 아닙니다.

## 2. 서비스에 맞는 파일을 받으세요

[다운로드 목록](catalog.md)에서 선택한 스킬의 Gemini·Claude·ChatGPT ZIP을 엽니다. GitHub 파일 화면의 다운로드 버튼으로 저장합니다. 비공개 저장소라면 접근 권한이 있는 계정으로 로그인해야 합니다.

저장소 전체를 받았다면 먼저 압축을 풀고 `dist/사용할 서비스/스킬명.zip`을 찾으세요. 등록할 파일은 이 **개별 ZIP**입니다. 서비스별 절차는 [설치 안내](installation.md)에 있습니다.

ChatGPT에 Skills 메뉴가 없으면 프로젝트에 [프로젝트 지침](../platforms/chatgpt/project-instructions.md)과 해당 [단일 문서](../dist/chatgpt-project)를 추가할 수 있습니다.

## 3. 첫 요청을 보내세요

한국어 퇴고를 선택했다면 아래 예제를 그대로 사용할 수 있습니다.

```text
refine-natural-korean을 적용해 아래 문장을 다듬어 줘.
수정 범위: 번역투와 문장 호응.
유지할 것: 문을 열 수 있었지만 실제로는 열지 않았다는 의미.
출력: 수정 본문만.

그는 문을 열 수 있었다. 그러나 끝내 손잡이에 손을 대지 않았다.
```

프로젝트 자료 방식에서는 첫 문장을 “업로드한 refine-natural-korean.md 자료를 적용해”로 바꾸세요.

## 4. 결과를 확인하세요

문장이 이미 자연스럽다면 그대로 유지하는 결과도 적절합니다. 반드시 표현을 바꾸는지가 아니라 요청한 의미를 보존했는지 봅니다.

| 확인할 점 | 적절한 결과 | 다시 요청해야 할 결과 |
|---|---|---|
| 사건 | 문을 실제로 열지 않음 | “문을 열었다”로 바뀜 |
| 수정 범위 | 주어진 문장 안에서 퇴고 | 새 인물·과거사·행동 추가 |
| 출력 | 수정 본문 | 요청하지 않은 긴 분석 |

이 예제의 성공만으로 전체 원고의 품질이나 스킬 자동 선택을 검증한 것은 아닙니다. 자신의 짧은 원고로 한 번 더 확인한 뒤 작업 범위를 넓히세요.
