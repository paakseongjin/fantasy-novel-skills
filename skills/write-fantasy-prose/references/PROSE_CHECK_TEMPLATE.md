# PROSE_CHECK_TEMPLATE — 집필·퇴고 확인 양식

> 검토 요청이 있을 때만 출력합니다. 원고만 요청받으면 내부 검토용으로만 사용합니다.

| 평가 축 | 확인 사항 | 결과 / 근거 |
|---|---|---|
| 사건 동력 | 인물이 무엇을 원하는가, 무엇이 방해하는가 | |
| 장면 변화 | 초반과 말미가 어떻게 달라졌는가 | |
| 시점 | 머릿속 접근·관찰 가능한 정보의 범위를 지켰는가 | |
| 대화 | 서로 다른 의도·말투가 드러나는가 | |
| 감각·동작 | 장소·시선·손동작과 대화의 연결이 명확한가 | |
| 연속성 | 날짜·거리·부상·물건·능력 제약이 유지되는가 | |
| 문장 | 상투어·중복·호흡의 단조로움이 있는가 | |
| 작가 의도 | 장르 톤, 독자 경험, 장면 목표를 충족하는가 | |

교정 우선순위: 사실 충돌 > 시점 오류 > 인물/인과 오류 > 장면 리듬 > 단순 취향 차이.
