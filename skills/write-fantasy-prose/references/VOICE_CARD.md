# 작품별 문체 카드

작가가 이 작품에서 채택한 대표 문단과 짧은 판단 기준을 담습니다. 평상시 장면 하나에 전투·친밀한 대화처럼 호흡이 달라지는 장면 하나를 짝지으면 직전 회차의 분위기를 모든 장면에 적용하는 실수를 줄일 수 있습니다. 샘플이 하나뿐이면 관찰한 특징을 잠정 기준으로 둡니다.

- 작품 / 기준 버전 / 대표 문단 위치
- 시점·시제·서술 거리와 전환 조건
- 평소 문장과 문단의 호흡, 호흡을 바꾸는 장면
- 인물별 호칭·존대·어휘, 공개석상과 사석의 차이
- 작가가 유지하고 싶은 반복·생략·비유, 의도한 예외

**채운 예.** 리아다 2화 초고에 적용하는 기준. 리아벨의 제한 시점으로 쓰고, 불안은 계기판을 읽거나 공구를 쥐는 행동에 먼저 드러낸다. 평소에는 작업과 판단이 한 문단 안에서 이어지고, 장치 이상이 생길 때만 문장을 짧게 끊는다. 관리관을 여러 사람 앞에서는 “관리관님”, 단둘이 있을 때도 위임 전까지는 같은 호칭으로 부른다. 기준 문단은 작가가 제공한 작업 장면과 회의 장면에서 고른다.

퇴고에서는 원고에서 의도한 예외와 이번 수정 범위를 확인합니다. 카드의 기준과 원문이 어긋나는 곳이 있어도 표기 교정이라면 어투를 다시 쓰지 않습니다. 원문의 의미가 달라질 수 있는 수정은 비교 검토자가 볼 수 있도록 해당 부분만 표시합니다.
