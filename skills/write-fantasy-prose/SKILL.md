# 판타지 본문 집필

1. **원고 조건.** 사용자가 준 장르·분량 단위·수위·시점과 보존 조건을 적용한다. 이어쓰기는 직전 장면의 관점·시제·서술 거리·인물 어투를 잇는다. 새로 쓰며 시점이 비어 있으면 3인칭 제한을 기본으로 삼는다. 표면 교정만 요청되면 해당 표현만 고친다.
2. **필요한 연속성만 확보.** 직전 종료 상태와 이번 장면에 쓰이는 정전만 확인한다. 인물의 위치·지식·물건·부상이나 능력 비용 중 행동을 제약하는 항목을 가져온다. 명시적으로 승인된 변경은 적용 시점을 따른다. 같은 시점의 확정 근거가 충돌하면 해당 장면에 영향이 있을 때만 어느 쪽을 따를지 묻는다. 직전 결말에 의존하는데 자료가 없으면 해당 발췌나 종료 상태를 요청한다. 가벼운 감각·몸짓은 창작하고, 능력 예외·혈통·사망처럼 후속 전개를 바꾸는 결정을 임의로 고정하지 않는다.
3. **회차를 진행시킨다.** 장면의 목표 → 저항 → 인물의 선택 → 남은 결과를 연결한다. 휴식 장면의 변화는 관계·정보·결심으로 만들 수 있다. 제한 시점에서는 관찰·추론과 사실을 구분한다. 대사는 상대가 무엇을 알며 어떻게 반응하는지에 맞추고, 묘사는 인물이 지금 할 수 있는 행동을 선명하게 한다. 설명은 선택이나 결과를 이해할 때 필요한 곳에 짧게 둔다.
4. **장면을 닫는다.** 이번 회차에서 약속한 성취·발견·대가 중 해당하는 것을 원고에서 보여 주고 다음 행동을 열어 둔다. 긴 분량은 장면 단위로 쓰되 각 장면의 끝 상태를 다음 장면에 이어 준다. 마지막에 시점 이탈, 공개 범위, 비용·소지품 변화, 고정된 결과와 분량 조건을 한 번 확인한다. 분량이 미지정이면 요청한 장면의 변화가 성립하는 만큼 쓴다.

기본 출력은 완성 원고다. 제목은 요청에 따른다. 부분 수정은 요청 구간의 수정본을 준다. 장면이 많아서 배치가 필요한 경우에만 [장면 카드](references/SCENE_CARD_TEMPLATE.md), 상세 자체 검수가 요청된 경우에만 [원고 점검 양식](references/PROSE_CHECK_TEMPLATE.md)을 쓴다. 별도 인계를 요청하면 [회차 기록](references/CHAPTER_HANDOFF_TEMPLATE.md)에 새 사실 후보와 다음 회차의 시작 상태를 적는다.
