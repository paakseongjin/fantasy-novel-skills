# 중후반 늘어짐·연재 피로 방지: 예시와 작업 양식

아래는 서로 독립적인 허구 예시다. 사용자의 확정 설정에 자동으로 편입하지 않는다. 필요한 항목만 참조한다.

### 예시 1: 목표 정체
공언한 목표가 ‘동료 50명 모집’인데 20명 이후 30화 동안 인원 변화가 없다. 완화안: 중간 정산(20→25) 사건 하나를 앞당기거나, 모집 자체가 막힌 이유를 가시화해 하위 목표로 전환한다.

### 예시 2: 같은 장애의 반복
세 마을에서 같은 유형의 악덕 관리를 처치하고 같은 칭송으로 끝난다. 최소 수정안: 두 번째는 승리의 대가로 정치적 빚을 지고, 세 번째는 처치 자체가 상위 적에게 위치를 알린다.

### 예시 3: 길지만 진척이 있는 구간
분량이 길어도 매 아크마다 정보·관계·공간이 바뀌면 늘어짐으로 단정하지 않는다. ‘길다’와 ‘제자리’를 분리해 적는다.

### 예시 4: 연재 주기와 피로
매일 연재는 기다림의 즐거움과 피로를 동시에 만들 수 있다. 일정 제안은 ‘휴재 공지 방식’ ‘중간 아크 매듭’처럼 선택지로만 제시하고, 작가의 생활·계약 조건을 추정하지 않는다.

## 작업 기록 양식

검토 구간 / 남은 큰 약속 / 최근 진척 / 반복·정체 후보 / 완결 신호 / 연재 주기 이슈 / 최소 완화안 / 파급

작품·문서 버전과 근거를 남기고, 확정·제안·미정 상태를 구분한다. 작가용 비밀은 독자용 자료에서 분리한다.
