# 정전·회차 연속성 감사

## 근거를 맞춘다

- 이번 요청의 회차·버전·대상을 고른다. 해당 인물·규칙·사건의 원문 위치만 찾는다. 전체 감사를 요청한 경우 해당 범위를 시간·이동·인물·능력·물건·제도·공개 정보로 나눠 검토한 범위를 기록한다.
- 명시 승인된 개정과 그 적용 시점이 우선한다. 승인된 설정집과 확정 원고가 같은 조건에서 어긋나고 개정 근거가 없으면 둘을 충돌 후보로 남긴다. 파일 수정일만으로 우선순위를 정하지 않는다. 초안·개요의 제안, 작중 주장, 서술로 확인된 사건은 근거 수준을 구분한다.
- 독자가 알 수 있었는지는 회차별 공개본·확인된 정정본과 적용 시점을 근거로 삼는다. 구본 독자에게도 필요한 정보라면 후속 회차에서 보강할지 검토한다. 공개본과 작가 확정본의 사건이 충돌하면 양쪽 근거와 영향 회차를 남기고 작가의 조정을 받는다.
- 한 쌍의 명제를 같은 인물·시간·장소·조건에 놓고 비교한다. 시점 차이·승인된 예외·거짓말·제한 시점으로 양립하는지 먼저 본다. 예를 들어 부상 장면과 전력 질주 사이에 회복할 시간이 있었는지 확인한다.

## 결과를 낸다

- **감사:** 문제마다 `위치 A + 위치 B → 양립 불가 조건 → 영향 → 최소 수정안`을 한 번만 적는다. 양쪽 근거가 있고 양립이 불가능할 때 확정 충돌, 예외·시점에 따라 갈릴 때 조건부, 한쪽 근거가 없을 때 확인 필요로 표시한다. 심각도는 결말·핵심 규칙 파손(P0), 주요 전개·행동 불능(P1), 국소 공백(P2), 표기·호칭(P3)으로 구분한다. 발견이 없으면 확인한 범위만 명시한다. 검증만 요청된 경우 수정 원고는 제공하지 않는다. 내보내기 양식이 필요하면 [감사 보고서](references/AUDIT_REPORT_TEMPLATE.md)를 쓴다.
- **기록:** 실제 근거가 있는 사실을 하나의 명제씩 `기존 ID 또는 신규 ID / 명제 / 유효 시점·예외 / 출처 / 승인 상태`로 기록한다. 요청 형식에 따라 [정전 설정집](references/WORLD_BIBLE_TEMPLATE.md) 또는 [연속성 대장](references/CONTINUITY_LEDGER_TEMPLATE.md)을 사용한다.
- **개정:** [개정 양식](references/CHANGE_REQUEST_TEMPLATE.md)에 전후 규칙, 적용 시점(이후 또는 소급), 영향 받는 기존 회차와 후속 행동을 적는다. 원고 한 곳으로 해결되면 먼저 그 방안을 제시한다. 승인된 범위만 반영하며, 제안 상태·채택·실제 저장을 각각 구분한다.
