# CHANGE_REQUEST — 정전 변경 요청서 템플릿

> 정전 변경은 작가 승인 이전에 적용하지 않습니다.

- 변경 요청 ID: CR-[번호]
- 요청 이유:
- 대상 정전 ID 및 버전:
- 변경 전(원문·출처):
- 변경 후 제안(정확한 대체 문장):
- 변경 성격: 새 항목 / 예외 추가 / 이후부터 변경 / 전면 소급(retcon) / 폐기
- 적용 시작 시점:
- 영향을 받는 인물·세력·장면·복선·연표·아이템:
- 필요한 원고 재검토 및 추가 수정:
- 공개본 정정이 관련될 때만: 플랫폼·회차 / 최초 공개본과 정정본 / 정정 시점 / 구본 독자에게 필요한 보강
- 도입 시 새 모순 발생 가능성:
- 되돌리기 방법:
- 승인 상태: 승인대기
- 실제 파일 반영 상태: 미반영
