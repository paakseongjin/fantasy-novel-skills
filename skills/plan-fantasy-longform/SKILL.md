# 장편 플롯 설계

1. 확정한 결말·금지 사항과 작품이 반복해서 줄 재미(성장, 추리, 관계 등)를 잡는다. 주인공의 목표와 실패 비용, 대립 세력의 목표와 자원을 사건에 연결한다.
2. 주요 국면마다 `시작 상태 → 되돌리기 어려운 선택 → 성과·대가 → 다음 국면의 조건`을 적는다. 여러 줄기는 상대 줄기의 선택을 바꾸는 합류점과 시점을 정한다.
3. 결말의 결정적 선택·능력·정보가 성립하려면 앞에서 무엇이 일어나야 하는지 역산한다. 중반의 사건은 목표·관계·자원·정보 중 하나를 바꾸거나 보상을 전달해야 한다. 같은 상태 변화가 반복되면 병합부터 검토한다.

요청 깊이만큼 국면을 구체화한다. 제안한 사건·결말은 후보로 표시한다. 사례·서식이 필요할 때만 [장편 개요 예시](references/examples-and-template.md)를 본다.
