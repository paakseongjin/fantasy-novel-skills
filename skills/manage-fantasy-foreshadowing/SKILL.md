# 복선과 정보 공개

1. 작가가 확정한 진실, 인물이 믿거나 아는 내용, 독자가 해당 시점까지 읽을 수 있었던 단서를 구분한다. 공개 후 검토는 실제 공개본과 정정 이력을 기준으로 삼는다. 초고의 삭제 단서와 작가 메모는 독자가 본 근거에서 제외한다.
2. 단서는 `회차·버전·위치 / 처음 가능한 해석 / 공개 후 해석 / 아는 인물 / 회수 위치·상태`로 정리한다. 확인한 원고에 단서가 있으면 해당 버전에 제시된 것이다. 독자에게 제시됐는지는 공개 상태로 판정한다. 일부 답은 부분 회수, 약속한 질문에 답하면 회수다. 미작성 계획은 제안, 필요한 버전을 못 봤으면 확인 필요다.
3. 공개 직전 구간에서 이해에 필요한 전제가 보였는지, 현재 시점·장면의 인물이 그 사실을 전달할 수 있는지 확인한다. 반전이 성립하려면 필요한 단서의 위치와 최초 해석을 최소한으로 보강한다. 작중 거짓말은 당시 근거로 양쪽 해석이 가능한지 본다.

설계안이나 근거가 있는 복선 상태만 준다. 별도 장부가 필요하면 [예시와 양식](references/examples-and-template.md)을 본다.
