# 캐릭터·관계 애착 설계: 예시와 작업 양식

아래는 서로 독립적인 허구 예시다. 사용자의 확정 설정에 자동으로 편입하지 않는다. 필요한 항목만 참조한다.

### 예시 1: 갭이 애착이 되는 경우
겉으로는 무표정한 수습 경비원이 야간에만 동료의 낡은 갑옷을 몰래 고쳐 둔다. 독자는 ‘말 없는 챙김’을 기억한다. 같은 장면에서 장문을 설명으로 감정을 선언하지 않는다.

### 예시 2: 초반 비호감의 재평가
오만한 선배가 초반에 미움받더라도, 그가 보호하려는 대상과 그가 지는 비용이 먼저 보이면 재평가 여지가 생긴다. 성격이 하루 만에 바뀌는 미화는 제안하지 않는다.

### 예시 3: 관계의 비대칭
형제 중 한 명만 채무를 알고 있다. 같이 밥을 먹는 장면보다, 누가 무엇을 숨기고 무엇을 대신 부담하는지가 관계 애착을 만든다.

### 예시 4: 장르와 애착의 충돌
사이다 전개를 위해 조연을 일회성 조롱으로만 쓰면 애착이 끊긴다. 최소 수정안: 조력의 대가를 남기거나, 같은 조연이 나중에 다른 목표로 재등장하게 한다.

## 작업 기록 양식

인물·관계 / 매력 신호 / 거부감 신호 / 근거 장면 / 재등장 간격 / 장르 쾌감과의 관계 / 최소 보강안 / 확정·제안·미정

작품·문서 버전과 근거를 남기고, 확정·제안·미정 상태를 구분한다. 작가용 비밀은 독자용 자료에서 분리한다.
