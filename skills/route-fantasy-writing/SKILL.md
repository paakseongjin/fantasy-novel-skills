# 판타지 집필 라우터

1. **범위 고정.** 최종 산출물, 대상 구간, 보존할 사실·시점·말투와 출력 제한을 확보한다. 명시된 단일 스킬은 바로 사용한다. 그 외에는 최종 산출물을 기준으로 [선택표](references/skill-catalog.md)의 해당 행을 찾는다. 스킬 추천만 요청했다면 선택·순서·필수 자료를 안내하고 끝낸다.
2. **최소 경로.** 담당 스킬 하나로 시작한다. 다른 지침은 사용자가 별도 산출물을 원하거나 담당 스킬이 해결할 수 없는 선행 문제가 있을 때만 읽는다. 예: 회차 구성 후 집필을 요청하면 장면 구성 → 원고. 승패가 정해진 추격의 동선만 고치면 공간 묘사. 선택이 애매할 때만 [경계 사례](references/composition-recipes.md)를 참고한다.
3. **실제 접근 확인.** 제공된 지침과 스킬 기능으로 적용한다. 이미 읽은 지침·원고는 내용이 바뀌었거나 새 근거가 필요할 때만 다시 연다. 핵심 근거를 볼 수 없으면 필요한 문서 제목·회차·인물·규칙을 특정해 발췌를 요청한다. 스킬 지침에 접근할 수 없으면 제공된 자료로 가능한 부분을 진행하고 적용 범위를 밝힌다.
4. **한 번에 연결.** 내부 인계는 `보존 조건 / 근거 위치 / 다음 단계에 필요한 상태 변화·미정`만 남긴다. 독자가 아는 사실과 인물이 아는 사실은 공개에 영향을 줄 때 따로 적는다. 같은 문제는 한 담당이 처리하고 수정본 하나로 반영한다. 설정 충돌이나 선택 미정으로 결과가 실질적으로 갈릴 때만 해당 결정 하나를 묻고 독립된 부분은 진행한다.
5. **범위에서 종료.** 선택지 요청은 선택지에서, 진단은 근거와 수정 방향에서, 본문 요청은 완성 원고에서 닫는다. 확정 설정과 제안을 구분하고 결과에 영향을 주는 한계만 보고한다. 본문만 요청하면 접근 한계가 작업을 막는 경우를 제외하고 제목·본문 외의 해설과 스킬 로그를 생략한다.
