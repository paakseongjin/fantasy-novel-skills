# 조합 절차와 인계 규칙

요청과 관련된 예시만 읽는다. 화살표는 결과 의존 순서이며 모든 스킬의 의무 호출을 뜻하지 않는다. 각 단계에서 사용자가 보존하라고 한 조건을 유지한다.

| 자연어 요청 | 기본 선택·순서 | 필요한 경우만 추가 | 넘길 결과와 멈출 지점 |
|---|---|---|---|
| “다음 화를 구성해서 써 줘” | `structure-serial-chapters` → `write-fantasy-prose` | 복선 공개가 있으면 `manage-fantasy-foreshadowing`, 연속성 검토까지 요청하면 `audit-fantasy-canon` | 목표·장면 변화·끝 상태를 본문에 반영. 작성 후 종료 |
| “다음 화 방향만 세 가지, 아직 쓰지 마” | `structure-serial-chapters` | 작품 전체 분기가 달라질 때 `plan-fantasy-longform` | 비교 가능한 기획안만. 본문 작성·안 확정 금지 |
| “장편 줄거리와 주인공 성장을 함께 짜 줘” | `plan-fantasy-longform` → `design-character-arcs` | 비밀과 회수를 요청하면 `manage-fantasy-foreshadowing` | 사건 계기와 선택·대가를 연결한 설계안. 새 원고는 쓰지 않음 |
| “추격전이 헷갈려. 승패는 그대로 다듬어 줘” | `write-immersive-scenes` | 전술 인과도 문제라면 먼저 `design-fantasy-action` | 위치·동선·능력 제약을 유지한 해당 장면 수정. 새 무기로 해결 금지 |
| “둘의 싸움이 억지스럽고 대사도 똑같아” | `write-character-conflict` → `craft-character-dialogue` | 장기 관계 변화를 요청한 경우만 `design-character-arcs` | 욕구·힘의 차이·서로 아는 사실을 대사에 전달. 결말 유지 |
| “내용은 그대로, 번역투만 없애 줘” | `refine-natural-korean` | 없음 | 사건 발생 여부·말투·시점 유지. 기획·세계관·재집필 단계 생략 |
| “프롤로그가 어렵고 주인공에게 정이 안 가” | `lower-opening-barrier` → `design-reader-attachment` | 재작성 요청이 있으면 마지막에 `write-fantasy-prose` | 정보 노출 순서와 관계 행동을 통합. 진단 요청이면 진단에서 종료 |
| “80화 이후 반복돼. 이탈 위험도 봐 줘” | `audit-dropout-risks` → `prevent-serial-drag` | 회차 재배치까지 요청하면 `structure-serial-chapters` | 한 번 수집한 근거를 공유해 반복 기능과 개선 우선순위 제시 |
| “이 반전을 지금 공개해도 설정이 안 깨질까?” | `manage-fantasy-foreshadowing` → `audit-fantasy-canon` | 없음 | 실제 단서·독자/인물 지식·공개 시점 대조. 새 단서를 과거 원고에 있었다고 하지 않음 |
| “마법이 귀족 제도를 만든 세계를 설계해 줘” | `build-fantasy-world`의 마법·계급 지침 | 개별형을 쓰면 `design-fantasy-magic` → `design-fantasy-institutions`로 대체 | 힘의 조건 → 자원·권한 배분 → 생활·갈등. 통합형과 개별형 중 하나만 사용 |
| “이 원고 어디가 문제야? 고치지는 마” | `review-fantasy-manuscript` | 구체적 정전 충돌을 별도 확인할 필요가 있을 때만 `audit-fantasy-canon` | 원문 근거·문제·최소 수정 방향. 원고 덮어쓰기 금지 |

## 작업 중 경로를 바꿀 때

앞 단계에서 새 문제가 확인되면 관련 단계 하나를 조정한다. 예컨대 대사 수정 중 인물이 아직 모를 사실을 말하고 있다면 지식 근거를 확인한 뒤 그 대사만 고친다. 이를 이유로 작품 전체를 재기획하지 않는다.

스킬 지침이 서로 다르면 먼저 적용 범위를 나눈다. “정보 공개를 늦춘다”와 “초반 이해를 돕는다”가 동시에 필요할 때는 비밀 자체와 당장 이해해야 할 목표·위험을 구분한다. 중요한 양립 불가능한 결정은 작가에게 확인하고 다른 독립 작업을 진행한다.

## 짧은 인계 예시

요청: “스승과 제자의 다툼을 다듬어 줘. 둘이 헤어지는 결말은 유지해.”

- 주 작업: `write-character-conflict`. 욕구·오해·선택의 인과를 정리한다.
- 보조 작업: 말투 문제도 드러난 경우 `craft-character-dialogue`.
- 인계: 제자는 스승의 비밀을 모름 / 독자는 알고 있음 / 제자가 떠나는 결말 고정 / 새 폭로 금지 / 호칭 유지.
- 결과: 수정 장면 하나. 두 스킬의 별도 수정본을 경쟁시키지 않고 같은 장면에 통합한다.

## 자료 또는 스킬이 없을 때

- “9화에 이어 10화 작성”인데 9화가 없으면 직전 원고나 종료 상태를 요청한다. 내용을 추정해 읽은 것처럼 이어 쓰지 않는다.
- 확정 설정 없이 “오류를 찾아 줘”라면 원고 내부 모순만 확인하고 설정집 대조는 미실시로 표시한다.
- 선택한 스킬을 적용할 수 없으면 가능한 대체 스킬의 실제 지침을 사용한다. 대체도 없으면 일반 제안이라는 점을 밝히고 진행 가능한 범위만 처리한다.
- 외부 계정 로그인·저장 공간 연결을 기본 준비 단계로 요구하지 않는다. 사용자가 대화에 제공한 원고와 설정으로 작업할 수 있다.
