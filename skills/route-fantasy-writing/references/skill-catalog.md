# 산출물별 스킬 선택표

요청이 걸리는 행만 사용한다. 문제의 범위와 최종 결과를 기준으로 고른다.

| 미리 정할 것 또는 최종 결과 | 담당 |
|---|---|
| 세계관 여러 분야의 연결이나 선택형이 없는 분야 설계 | `build-fantasy-world` |
| 장편의 주요 국면·전체 인과·결말 | `plan-fantasy-longform` |
| 여러 회차에 걸친 인물 신념·관계의 변화 | `design-character-arcs` |
| 독자에게 제시된 단서·정보 공개·회수 | `manage-fantasy-foreshadowing` |
| 한 화 또는 인접 화의 목표·장면·끝 상태 | `structure-serial-chapters` |
| 새 원고·이어쓰기·장면 재작성, 작품별 문체 카드 작성 또는 회차 인계 | `write-fantasy-prose` |
| 한 장면의 욕구·관계 갈등·감정과 선택 | `write-character-conflict` |
| 위치·동선·시야·감각이 선명한 묘사 | `write-immersive-scenes` |
| 전투·추격의 선택·비용·승패 인과 | `design-fantasy-action` |
| 대사·호칭·존대·인물 말투 | `craft-character-dialogue` |
| 의미를 보존한 문장·오탈자·번역투 수정 | `refine-natural-korean` |
| 원고의 문제 위치·원인·수정 우선순위 | `review-fantasy-manuscript` |
| 확정 자료와 원고의 충돌·회차 연속성·개정 영향 | `audit-fantasy-canon` |
| 기억에 남을 인물 행동·애착을 쌓는 관계 장면 | `design-reader-attachment` |
| 프롤로그·초반의 정보 부담·기대 지연 개선 | `lower-opening-barrier` |
| 중후반의 기능 반복·보상 지연 개선 | `prevent-serial-drag` |
| 여러 축의 하차 위험과 첫 조치 | `audit-dropout-risks` |

## 세계관 단일 분야

설치된 선택형이 있으면 해당 지침을 사용한다. 통합형을 쓰는 경우 `build-fantasy-world` 내부의 해당 지침만 확인한다. 두 형태가 모두 있어도 하나를 선택한다.

| 분야 | 선택형 | 통합형 상세 지침 |
|---|---|---|
| 지리·기후·역사 | `design-fantasy-world` | `references/world-guide.md` |
| 명칭·조어 | `name-fantasy-world` | `references/names-guide.md` |
| 마법·능력·유물 | `design-fantasy-magic` | `references/magic-guide.md` |
| 작위·관직·권한 | `design-fantasy-institutions` | `references/ranks-guide.md` |
| 국가·도시·교역 | `design-fantasy-nations` | `references/nations-guide.md` |
| 종족·문화·생활 | `design-fantasy-peoples` | `references/peoples-guide.md` |
| 신·교리·의례 | `design-fantasy-religions` | `references/religions-guide.md` |
| 설정 분야 간 인과·장면화 | `audit-fantasy-worldbuilding` | `references/canon-guide.md` |
