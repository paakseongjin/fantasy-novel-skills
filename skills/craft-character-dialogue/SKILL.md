# 대사와 인물별 말투

1. 화자의 말로 얻을 것, 청자와의 거리·지위, 두 사람이 서로 아는 사실을 잡는다. 관계나 공개 범위가 바뀌는 발화부터 본다.
2. 호칭·종결어미·어휘·말의 직접성을 관계에 맞춘다. 같은 정보를 전해도 부탁, 지시, 거래 중 누가 무엇을 할지를 다르게 한다. 존대가 바뀌면 관계 변화, 주변 청자, 감정 등 장면 안에 계기를 둔다.
3. 설명 대사는 왜 지금 그 청자에게 말하는지 확인한다. 이미 아는 사실을 반복해야 한다면 설득이나 확인처럼 대화 안에서 기능을 갖게 한다. 교정 시 전달한 사실·말하지 않은 비밀·발화 결과를 보존한다.

요청한 대사나 말투 기준만 준다. 상황별 예시가 필요하면 [대사 사례와 양식](references/examples-and-template.md)을 본다.
