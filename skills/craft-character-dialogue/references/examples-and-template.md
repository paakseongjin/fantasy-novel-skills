# 대사·인물별 말투 설계: 예시와 작업 양식

아래는 서로 독립적인 허구 예시다. 사용자의 확정 설정에 자동으로 편입하지 않는다. 필요한 항목만 참조한다.

### 예시 1: 같은 거절
기사: “명령서가 없으면 문을 열 수 없습니다.” 친구: “지금 나가면 잡혀. 날이 밝을 때까지 기다려.” 상인: “열어 드릴 수는 있죠. 그 뒤의 일은 제 책임이 아닙니다.” 관계·상황에 따라 실제 표현은 달라질 수 있다.

### 예시 2: 권력과 친밀도
공식 회의의 후계자는 스승에게 “확인해 주시겠습니까?”라고 묻지만 단둘이서는 “정말 괜찮아?”라고 묻는다. 전환은 인물 관계와 설정이 뒷받침해야 한다.

### 예시 3: 설명 대사 다듬기
두 전문가가 서로 아는 마법 이론을 길게 설명한다면, 한 사람이 지금 필요한 판정을 묻고 상대가 불확실한 부분만 답하게 제안한다. 독자가 알아야 할 조건은 남긴다.

### 예시 4: 원문 의미 보존
“그가 왔을지도 몰라요”를 “그가 왔어요”로 바꾸면 추측이 사실이 된다. 자연스러움을 이유로 확실성의 정도를 바꾸지 않는다.

## 작업 기록 양식

화자 / 상대·관계 / 목표 / 호칭·존대 / 아는 정보 / 직접 표현·숨긴 뜻 / 대화 중 변화 / 원문 의미 유지 여부

작품·문서 버전과 근거를 남기고, 확정·제안·미정 상태를 구분한다. 작가용 비밀은 독자용 자료에서 분리한다.
