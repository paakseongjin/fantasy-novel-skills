# 명칭·조어·호칭
## 설계 순서
1. 대상, 문화권, 사용 언어, 독자에게 보여줄 표기, 기존 명칭을 확인한다.
2. 음운·어근·결합 규칙과 사회적 명명 관습을 따로 정한다. 음운 규칙만으로 문화 전체를 설명하지 않는다.
3. 한글 표기를 먼저 읽어 발음과 구별 가능성을 확인한다. 로마자는 필요할 때만 병기한다.
4. 어근 조합형, 생활어 번역형, 사건 유래형, 외부인이 붙인 이름 등 서로 다른 방식의 후보를 제시한다.
5. 정식명·약칭·자칭·타칭·멸칭·옛 이름을 구분한다. 모든 대상에 이 전부를 만들 필요는 없다.
6. 비슷한 등장인물 이름, 같은 약칭, 의미 중복, 호칭 혼용을 찾아 대안을 제시한다.
7. 채택한 이름만 명칭 대장에 올린다. 후보를 정본으로 기록하지 않는다.

## 명명 규칙
- 접두·접미사는 정한 기능을 유지한다. ‘도시’를 뜻하는 접미사를 아무 설명 없이 왕조 이름의 어근으로 쓰지 않는다.
- 음운 변화는 규칙으로 설명할 수 있을 때만 넣는다. 불필요한 아포스트로피나 긴 자음 나열을 이국적 분위기의 대체물로 삼지 않는다.
- 국가명은 정체, 왕조, 지명, 주민 자칭과 일치할 수도 다를 수도 있다. 왕실 이름과 나라 이름을 무조건 동일하게 만들지 않는다.
- 인명은 개인명, 가문명, 후원자명, 출신지명, 성인명 등의 실제 사용 조건을 정한다. 모든 사람에게 귀족식 풀네임을 주지 않는다.
- 공식 석상과 친밀한 대화의 호칭을 구분한다. 한국어 ‘폐하·전하·각하·성하’ 등을 쓰면 이 세계에서 누구에게 왜 쓰는지 정한다.
- 현대 한국어 독자가 뜻을 아는 번역명도 유효하다. 모든 명칭을 가짜 외국어로 바꾸지 않는다.
- 어원은 ‘이 세계에서 정한 뜻’이라고 밝힌다. 실제 라틴어·고대어·외국어라고 검증 없이 주장하지 않는다.
- 이미 알려진 작품과 우연히 겹칠 수 있다. 독창성이나 상업적 권리 검증 완료를 보장하지 않는다.

## 명칭 대장
| ID | 대상 종류 | 문화권 | 표준 한글명 | 선택적 로마자 | 어근·유래 | 정식명/통칭 | 사용 상황 | 상태 |
|---|---|---|---|---|---|---|---|---|

## 요청별 출력
- 소량 작명: 후보, 읽히는 인상, 설정상 뜻, 사용 예. 사용자가 숫자를 지정하면 따른다.
- 문화권 설계: 음절 규칙 + 작은 어근 사전 + 명명 관습 + 서로 구별되는 샘플.
- 기존 이름 점검: 충돌 목록과 최소 수정안. 전체 이름을 교체하지 않는다.
- 검증: 같은 문화권 이름의 일관성, 서로 다른 문화권의 식별성, 본문에서 부르기 쉬운지 확인한다.
예시 탐색: names-examples.md. N01~N48은 여섯 문화권의 서로 연결된 여덟 종류 이름이다. 그 안의 어근은 모두 가상이다.
