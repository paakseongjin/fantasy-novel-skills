# 신분·작위·관직·조직
## 먼저 분리할 축
- 신분: 출생·법적 지위 등으로 정해지는 권리와 의무.
- 작위: 명예, 영지 또는 지배 관계와 연결되는 칭호.
- 관직: 특정 업무를 맡은 임명·선출 직위.
- 군 계급: 지휘 및 복무 관계.
- 성직: 종교 공동체의 직무와 권위.
- 자격: 학위, 면허, 길드 등급.
- 재산·명망·실력: 위 축과 항상 일치하지 않는 영향력.
황제와 대마법사 중 누가 ‘높은지’를 하나의 서열로 결정하지 말고 상황별 권한을 정한다.

## 설계 순서
1. 조직이 해결하려는 실제 문제를 정한다.
2. 자원과 권한의 근거를 정한다. 세습, 토지, 세금, 선거, 전문지식, 신성성 등.
3. 들어오는 방법, 승진, 임기, 퇴직, 박탈, 상속을 설계한다.
4. 명령 범위와 한계를 정한다. 명령 거부·이의 제기·감사·재판 경로를 둔다.
5. 급여·재산·특권과 납세·복무·책임을 함께 정한다.
6. 다른 기관과 권한이 겹치는 상황을 시험한다.
7. 공식 제도와 실제 관행의 차이를 명시한다. 모든 차이가 부패일 필요는 없다.
8. 하층 인물이 제도에 접근하는 일상 절차를 하나 작성한다.

## 권한 카드
칭호 / 분류 축 / 임명·승계 / 임기 /
공식 권한 / 권한이 없는 영역 / 재원 /
의무 / 감독·파면 / 사회적 대우 /
공식 호칭 / 사적 호칭 / 다른 지위와 겸직 / 분쟁 사례

## 제도 점검
- 세습 지위와 공무 직위의 승계를 섞지 않는다.
- 법적 우위와 실제 강제력, 의전상 좌석 순서를 구별한다.
- 공작·후작·백작·자작·남작을 역사 전체의 보편적 체계로 소개하지 않는다. 사용 시 이 세계의 자체 규칙으로 정의한다.
- 여성, 이주민, 비인간, 혼혈, 입양, 귀환자 등의 지위가 이야기와 관련되면 동일한 법적 기준으로 정한다. 모두를 차별 대상으로 만들 필요는 없다.
- 모든 계층을 악인/피해자로 고정하지 않는다. 협력, 타협, 내부 분화도 만든다.
- 승진 조건은 ‘강해지면 승급’ 외에 시험, 근속, 추천, 자산, 시민 신임, 책임 수행 등을 검토한다.
- 실제 화폐·인구 기준이 없다면 봉급을 근거 없이 정밀하게 산정하지 않는다.

## 출력
요청한 조직의 표와 대표 분쟁 한 건을 우선한다.
검토에서는 모순이 있는 권한만 최소 수정한다.
예시 탐색: ranks-examples.md의 H01~H24. 서로 다른 제도 예시이며 하나의 보편 서열표가 아니다.
