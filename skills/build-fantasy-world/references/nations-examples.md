# 국가·정치체 예시 24개
독립적인 설계 카드이며 실제 국가의 역사 설명이 아니다. 각 사례에도 표에 생략된 여러 산업과 개인차가 존재한다.
탐색: C01~C06 교통·자원 / C07~C12 통치 / C13~C18 전환·협력 / C19~C24 도시·생활.

| ID·국가 | 생존 기반·정체 | 병목·내부 차이·외교 | 생활과 사건 |
|---|---|---|---|
| C01 세르리아 연맹 | 하천 농업과 수운, 여러 도시의 협약 정치 | 상류는 수문 관리, 하류는 항만에 강점. 물과 통행을 공동 조정한다. | 학교 급식용 곡물 배가 수문 점검으로 늦어진다. |
| C02 카르둔 공화국 | 산간 농업·석재 가공·구조 기술, 선출 의회 | 목재와 일부 식량을 수입한다. 광업 도시와 목축 지방의 우선순위가 다르다. | 공공건물 공사에 외국 목재 사용을 허용할지 논쟁한다. |
| C03 아오루 연합 | 어업·항로 중개·섬별 자치 | 폭풍기에 고립되므로 비축과 구조 협약이 중요하다. | 멀리 있는 수도보다 이웃 외국 섬이 먼저 구조한다. |
| C04 염분지 왕국 | 염업·관개 농업·가공업, 수로 기반 왕정 | 소금 수출만으로 살지 않으며 곡물과 도구의 공급망이 있다. | 담수 시설 고장으로 왕실 의례보다 수리가 시급해진다. |
| C05 문턱 도시연맹 | 산길 숙박·수리·운송, 거점 간 연맹 | 통행료가 높으면 우회로가 생긴다. 중앙과 외곽 마을의 수입이 다르다. | 눈으로 길이 막혀 손님을 무료로 머물게 할지 결정한다. |
| C06 회색목장 연방 | 이동 목축과 계절 시장, 경로별 대표제 | 정착 농민과 토지 사용 시기를 협상한다. | 출산기의 가축을 지키느라 회의 대표가 제시간에 못 온다. |
| C07 세문헌 동맹 | 기록·교육·제조·농업을 묶은 도시권 | 문헌 해석기관과 집행기관을 분리한다. | 같은 조항의 옛 판본이 새 정책의 정당성을 흔든다. |
| C08 순환왕국 | 지방 가문들이 정해진 절차로 군주를 선출 | 왕실 사유지와 국가 재정을 분리하지 않으면 갈등이 커진다. | 퇴임한 왕이 궁전의 물건 중 자기 것을 가려내야 한다. |
| C09 공동수도국 | 행정·종교·상업 중심을 서로 다른 도시에 둔다. | 이동 비용과 지역 균형 사이에서 타협한다. | 외교 사절이 잘못된 수도에 도착한다. |
| C10 성역 자치령 | 종교적 중심이지만 상업과 농업도 운영 | 성직자의 의례 권한과 시민 의회의 행정 권한이 나뉜다. | 축제 경로를 병원 앞에서 옮길지 협상한다. |
| C11 구호협약국 | 대재난 후 구호 거점들이 만든 정치체 | 임시 기구가 영구 정부가 되며 대표성 문제가 생긴다. | 첫 구조대의 후손과 새 시민이 참정권을 논의한다. |
| C12 다언어 변경국 | 여러 교역 언어와 지역법이 공존 | 공문 번역·법률 조정 비용이 크지만 중개 능력이 강하다. | 같은 혼인 계약이 두 법원에서 다르게 해석된다. |
| C13 휴전 수로지대 | 적대국 사이 공동 관리 운하 | 수입은 나눠도 군함 통과 기준은 다툰다. | 민간 구조선이 군용 화물을 싣고 있다는 의심을 받는다. |
| C14 광산 이후의 나라 | 자원 채굴이 줄어 기술·수선·교육으로 전환 | 옛 채굴 도시와 신산업 도시 사이의 자원 배분이 쟁점이다. | 폐광을 학교로 고치며 옛 작업 기록을 발견한다. |
| C15 마물이 줄어든 변경령 | 방어 중심 경제를 농업·관광·관측으로 바꾼다. | 경비 인력의 재교육과 옛 세금의 폐지가 필요하다. | 베테랑 병사가 어린이 길잡이 교육을 맡는다. |
| C16 귀환민 공화국 | 흩어졌던 주민과 기존 거주민이 함께 세운 국가 | 옛 토지 권리와 현재 생활권을 조정한다. | 두 가족이 같은 집의 열쇠를 가지고 있다. |
| C17 비축 연합 | 여러 기후대가 공동 창고망을 만든다. | 지역별 흉작이 완전히 동시 발생하지 않는다는 조건에 기대고 있다. | 예외적 동시 흉작으로 배급 기준을 다시 정한다. |
| C18 공방 협약도시 | 제조·농업 교역·기술 교육, 직능과 거주 대표가 함께 통치 | 공방원이 아닌 시민의 정치적 대표성을 보장해야 한다. | 기술이 없는 돌봄 노동자가 시 예산에 발언한다. |
| C19 얕은성 도시국 | 지하 굴착이 제한된 넓고 낮은 도시 | 토지와 지표 공간이 귀해 이동·하수·주거가 경쟁한다. | 어린이 놀이터 위로 물류 통로를 낼지 결정한다. |
| C20 긴처마 연합 | 추운 계절에 연결 통로를 공유하는 거주권 | 난방비·제설 노동·외곽 접근성이 쟁점이다. | 통로 하나를 고치는 순서가 이웃 관계를 바꾼다. |
| C21 큰정원 왕국 | 농업·종자 교역·원예 기술, 제한 왕정 | 왕실 정원의 상징과 실제 농민의 생산 조건이 다르다. | 왕실 품평회가 흉작 지역의 지원 요구와 겹친다. |
| C22 세항구 자유시 | 서로 다른 세 항구가 공통 상법을 쓴다. | 항만별 조수·시설·세관 관행이 달라 완전한 통합은 아니다. | 선장은 싼 항구와 안전한 항구 중 하나를 고른다. |
| C23 낮은종 탑도시 | 통신탑과 시장망을 중심으로 성장 | 통신은 빠르지만 물자는 느려 가격과 정보가 어긋난다. | 아직 오지 않은 식량의 도착 소식만 먼저 퍼진다. |
| C24 네길 협약권 | 순환 행렬과 고정 거점이 함께 운영하는 정치체 | 계절별 대표와 관할을 명확히 해야 분쟁을 줄인다. | 재판을 기다리는 동안 행렬의 관할이 바뀐다. |
