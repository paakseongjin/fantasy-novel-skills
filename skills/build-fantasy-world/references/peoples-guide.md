# 종족·민족·문화·생활
## 구분
- 종족·종: 세계관에서 정한 생물학적 또는 초자연적 존재 유형.
- 민족·문화권: 역사, 언어, 관습, 자기인식과 연결되는 집단.
- 국적·신앙·직업·계급: 위 구분과 독립적으로 달라질 수 있는 소속.
종족 하나를 국가 하나, 직업 하나, 성격 하나에 자동 대응시키지 않는다.

## 설계 순서
1. 눈에 보이는 외형보다 지각·신체·수명·생식·성장·수면·환경 적응 중 이야기와 관련된 차이를 정한다.
2. 장점과 제약을 같은 조건에서 설명한다. 우월한 능력을 주고 불편은 장면에서 무시하지 않는다.
3. 생물학적 특징이 제도에 어떤 선택지를 주는지 검토한다. 문화를 유전적 필연으로 만들지 않는다.
4. 같은 종족 안에 지역·세대·신앙·도시/농촌 등의 차이를 최소한 필요한 만큼 둔다.
5. 가족·돌봄·교육·노동·음식·주거·의례 중 본편에 필요한 생활을 구체화한다.
6. 다른 종족·문화와 함께 사는 시설과 관습을 설계한다. 갈등뿐 아니라 상호 학습과 정상적인 협력도 만든다.
7. 자칭, 외부의 통칭, 잘못된 편견, 실제 개인을 구분한다.
8. 대표 인물 두 명이 같은 전통을 다르게 받아들이는 장면으로 시험한다.

## 종족·문화 카드
자칭·통칭 / 존재 유형 / 외형·감각 /
수명·성장·돌봄 / 생태·식생활 / 이동·주거 /
마법 접근 / 개인차·예외 /
주요 문화 분화 / 언어·이름 / 가족·교육 /
직업·교역·법적 지위 / 타집단과의 일상 /
내부 논쟁 / 편견과 실제 / 장면 단서

## 주의할 단순화
- 장수한다고 자동으로 현명하거나 출생률이 낮은 것은 아니다. 인구 변화의 조건을 따로 설정한다.
- 야행성이라고 악하고 집단 지능이라고 개성이 없는 것은 아니다.
- 실존 민족의 외형·종교·말투를 묶어 열등하거나 악한 비인간 종족으로 대응시키지 않는다.
- 혼혈이나 개조 개체를 자동으로 더 강하거나 불안정하게 만들지 않는다. 규칙을 명시하고 개인차를 인정한다.
- 신체적 차이가 있어도 접근 가능한 건물·옷·도구·공공 제도를 설계할 수 있다.
- 생물학·유전의 과학적 타당성을 검증하지 않은 허구 규칙은 창작 가정으로 표시한다.
- ‘모두가’, ‘절대로’라는 표현은 실제 보편 규칙인지 인물의 편견인지 확인한다.

## 생활의 깊이
같은 인물이 먹고, 일하고, 씻고, 배우고, 다투고, 쉬는 데 설정이 어떻게 작용하는지 확인한다.
기이함을 보여주기 위해 식사·성장·장례 등을 장황하게 전시하지 않는다.
