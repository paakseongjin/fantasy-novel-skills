# 정합성 점검·장면화 예시 24개
판정은 아래에 제시한 가상의 조건이 모두 확정되었을 때에만 유효하다. 실제 원고에 같은 단어가 나온다는 이유만으로 동일하게 판정하지 않는다.
탐색: A01~A08 마법·물류 / A09~A16 사회·인물 / A17~A24 명칭·문서·장면.

| ID | 검토 대상 조건 | 판정·최소 수정 | 장면에 적용 |
|---|---|---|---|
| A01 이동과 성벽 | 누구나 아무 장소로 무제한 이동할 수 있는데 성벽만으로 침입을 막는다. | 방어 설명이 불충분하다. 이동의 한계를 추가하거나 성벽의 역할을 치안·관측으로 바꾼다. 기존 정본에 적합한 쪽을 고른다. | 문이 아니라 도착 표식을 점검하는 경비를 보여준다. |
| A02 열의 무한 순환 | 열 이동 마법인데 같은 물체를 오가면 열이 늘어난다고 서술한다. | 원천 없는 증가가 확정 규칙과 충돌한다. 증가 표현을 고치거나 별도 에너지 원천을 명시한다. | 따뜻해진 방만큼 차가워진 배출수를 확인한다. |
| A03 완전 치유와 감염 | 치유가 상처를 붙이는 기능뿐인데 모든 감염을 즉시 없앤다. | 새로운 능력이 몰래 추가되었다. 감염 치료를 별도 작업으로 남긴다. | 상처가 닫혀도 의사가 침상을 비우지 못하게 한다. |
| A04 진실과 착각 | 진실 판별은 거짓말 의도만 감지하지만 오류 없는 역사 증명에 사용한다. | 증언과 사실을 혼동했다. 기록·다른 증인을 대조하게 한다. | 진심인 두 증인이 반대되는 일을 말한다. |
| A05 예언과 선택 | 예언은 개입하면 변하는 분기인데 주인공이 행동해도 무조건 동일 결과라고 단정한다. | 확정 예언과 분기 예측 중 하나를 명확히 하거나 인물의 오해로 처리한다. | 예지자가 '내가 본 것은 네가 듣기 전의 길'이라고 한계를 설명한다. |
| A06 식량 도시 | 모든 주민이 전문직이고 식량 수입·자동 생산·주변 농지가 전혀 없다. | 생존 경로 누락이다. 농촌 공급망이나 생산 체계를 필요한 만큼 추가한다. | 새벽 시장의 곡물 입고가 도시의 배경이 된다. |
| A07 원정 군량 | 2,000명이 10일간 하루 1단위씩 먹는데 총량을 2,000단위로 적는다. | 가상 배급 기준상 20,000단위가 맞다. 운송 손실·사료는 별도 계산한다. | 창고 담당자가 부족한 수레 수를 먼저 지적한다. |
| A08 통신과 운송 | 소식은 즉시 전해지지만 물품은 배로 오는데 식량도 즉시 도착한 것처럼 쓴다. | 정보와 물자의 이동을 구분한다. 도착 예정 통보만 먼저 오게 한다. | 배가 온다는 종소리 뒤에도 빈 접시는 그대로다. |
| A09 작위와 관직 | 공작은 의전 작위일 뿐인데 모든 지방관을 즉시 해임한다. | 별도 임명권 근거가 없으면 권한 충돌이다. 해임 요청이나 다른 압력으로 수정한다. | 문서에는 명령이 아니라 청원 형식이 필요하다. |
| A10 선거와 세습 | 임기제 수문관의 자녀가 자동으로 후임이 된다. | 불법 관행, 법 개정, 특별 임명 중 무엇인지 정한다. 설명 없이 정상 승계로 두지 않는다. | 부모의 인장을 받았어도 새 서명을 등록해야 한다. |
| A11 귀환과 상속 | 귀환자는 재산 조정 절차를 거쳐야 하는데 귀환만으로 완료된 거래를 모두 무효로 만든다. | 절차와 효력을 분리한다. 일부 재산의 반환·보상·기각을 검토한다. | 가족 상봉과 등기 분쟁을 서로 다른 장면으로 다룬다. |
| A12 장수와 기억 | 장수종은 기억이 불완전하다고 했는데 오래 산 인물의 말은 모두 정확하다고 판정한다. | 생존 기간과 증언 정확성을 구분한다. 기록 대조나 불확실성을 남긴다. | 가장 오래 산 증인이 날짜를 잘못 기억한다. |
| A13 종족과 문화 | 한 종족이 모두 같은 신앙인데 다른 장에서 개종자 집단이 나온다. | ‘모두’를 다수·공식 통계·편견으로 바꿀지 예외의 기원을 정할지 선택한다. | 이름만 듣고 신앙을 단정한 인물이 정정받는다. |
| A14 기적과 교리 | 신성한 불이 실제로 켜지므로 성직자의 모든 정치 주장이 참이라고 처리한다. | 관측 현상에서 교리·정치적 결론으로 비약했다. 각각의 근거를 분리한다. | 기적을 믿는 신자가 정책에는 반대한다. |
| A15 신탁의 정보 범위 | 신은 현재의 한 장소만 아는데 모든 시대의 비밀을 정확히 답한다. | 존재의 지식 범위를 벗어난다. 신의 추정이나 전해 들은 정보로 조정한다. | 신도 오래된 이름의 의미를 되묻는다. |
| A16 제한 시점 | 인물은 상대의 계획을 모른다고 했는데 제한 시점 서술이 상대의 계획을 사실로 설명한다. | 시점 이탈이다. 관찰·추측으로 바꾸거나 명시적으로 시점을 전환한다. | 문을 잠그는 행동만 보여주고 뜻은 나중에 밝힌다. |
| A17 지명과 별칭 | 리아다와 합류도시는 같은 곳인데 여행 경로에서 다른 두 도시로 계산한다. | 명칭 대장에 별칭 관계를 기록하고 거리 중복을 없앤다. | 낯선 사람이 통칭을 몰라 길을 잘못 묻는다. |
| A18 연호 변환 | 같은 사건이 서로 다른 연호의 같은 숫자 해에 일어났다고 단정한다. | 연호 시작점을 확인한다. 대응표가 없으면 계산 불가로 남긴다. | 문서의 작은 연호 표기가 상속 순서를 바꾼다. |
| A19 의도된 거짓 역사 | 공식 역사는 왕이 혼자 승리했다고 하지만 작가 설정에는 동맹군이 있었다. | 의도된 선전이면 모순 오류가 아니다. 각 자료의 진술 주체를 표시한다. | 지워진 동맹의 이름이 오래된 기념비에 남는다. |
| A20 모호한 신성 | 산의 대답이 신인지 메아리인지 의도적으로 미정이다. | 설명 누락으로 강제 확정하지 않는다. 서사에서 필요한 단서만 일관되게 유지한다. | 같은 메아리를 두 인물이 다르게 해석한다. |
| A21 설정 과잉 소개 | 검문 장면 첫 문단에 나라·종족·작위·화폐·종교 이름이 몰린다. | 행동 이해에 필요한 허가증과 직위부터 제시하고 나머지는 분산한다. | '붉은 도장이 없어 다리를 못 건넜다'에서 시작한다. |
| A22 없는 설정의 추가 | 교정 요청인데 원문에 없던 피를 소모하는 마법 비용을 삽입한다. | 작업 범위 이탈이다. 기존 비용으로 긴장을 만들거나 새 비용을 제안란에 분리한다. | 행동은 그대로 두고 문장만 다듬는다. |
| A23 후보의 정본화 | 이름 후보 10개를 만들었을 뿐인데 다음 답변에서 전부 실제 도시로 사용한다. | 제안과 확정을 혼동했다. 선택된 항목만 정본 대장에 반영한다. | 인계 문서에 채택·미채택을 명확히 나눈다. |
| A24 전체 검증 과장 | 소설 한 장만 읽고 전체 세계관에 모순이 없다고 말한다. | 확인 범위를 넘어선 주장이다. 읽은 장과 교차 확인한 설정만 보고한다. | 결과를 '제공된 1장과 설정표에서 발견한 문제'로 한정한다. |

## 설정을 자연스럽게 드러내는 짧은 변환
설명: 이 나라에서는 물 사용권을 공동으로 배분하고 관리관의 권한에 제한이 있다.
장면: 관리관은 인장을 꺼냈다가 다시 넣었다. “이 수문은 열 수 있습니다. 아래 마을의 몫까지 끌어올 권한은 없고요.”
이 예문은 이 팩에서 새로 쓴 것이다. 모든 제도 소개를 거절 대사로 처리하는 공식으로 사용하지 않는다.
