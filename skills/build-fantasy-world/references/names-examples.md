# 명칭 예시 48개
여섯 가상 문화권마다 인명·국가·도시·조직·마법·직위·유물·신앙의 8개 항목을 제공한다. 실제 언어의 어원이나 특정 민족의 관습을 설명한 자료가 아니다. 통칭에는 독자의 언어로 번역한 이름을 사용할 수 있다.
탐색: N01~N08 물길 / N09~N16 암반 / N17~N24 군도 / N25~N32 문서 도시 / N33~N40 겨울 공동체 / N41~N48 순환 유랑.

## A. 물길권: 같은 어근을 쓰되 정식명과 생활어를 구분
가상 어근: 세르=강, 리아=합류, 벨=사람, 다=터, 온=맡음.
결합은 앞말이 뒤말을 한정한다. 아래 예시에서는 생략·음운 변화를 적용하지 않는다.
인명은 개인명+필요할 때만 출신지를 덧붙인다. 모든 주민에게 가문명이 있는 것은 아니다.

| ID | 종류·명칭 | 조어·유래 | 사용 상황과 변형 가능성 |
|---|---|---|---|
| N01 | 인명: 리아벨 | 리아+벨, 합류의 사람이라는 가상 의미 | 공문에는 '리아다 출신 리아벨', 친지에게는 리아벨. 출신지가 혈통을 뜻하지 않는다. |
| N02 | 국가: 세르리아 연맹 | 세르+리아, 강의 합류를 정치적 상징으로 사용 | 외부인은 강연맹이라 부른다. 강 전체를 지배한다는 뜻은 아니다. |
| N03 | 도시: 리아다 | 리아+다, 합류하는 터 | 강이 옮겨가도 옛 이름을 유지할 수 있다. 지명과 현재 지형이 다르면 역사로 설명한다. |
| N04 | 조직: 세르온단 | 세르+온+한국어 번역 접미 단 | 강 관리 단체. 왕실 기사단 같은 군사 조직이라고 자동 해석하지 않는다. |
| N05 | 마법: 물길잇기 | 기술 기능을 독자 언어로 번역한 생활 명칭 | 세르 계열 학술명과 병존 가능하나 학술명은 별도 확정한다. 순간이동 효과를 이름만 보고 부여하지 않는다. |
| N06 | 직위: 리아온 | 리아+온, 합류 지점의 관리 책임 | 사람이 바뀌어도 직명은 유지된다. 호칭은 '관리관'으로 번역해 대사를 자연스럽게 쓸 수 있다. |
| N07 | 유물: 세르추 | 세르+번역어 추, 유량을 재던 기구에서 유래 | '강의 심판자' 같은 전설적 별칭은 민간의 해석으로 별도 기록한다. |
| N08 | 신앙: 합류의 길 | 여러 삶이 하나의 강으로 모인다는 비유 | 교단 이름인지 개인 수행 전통인지 구분해 사용한다. |

## B. 암반권: 도구·직무가 이름의 비유가 되는 사회
가상 어근: 카르=돌, 둔=받침, 이르=살핌, 에크=손, 하=거처.
자음이 강한 인상은 작명상의 선택일 뿐 주민의 성격이나 도덕성을 뜻하지 않는다.

| ID | 종류·명칭 | 조어·유래 | 사용 상황과 변형 가능성 |
|---|---|---|---|
| N09 | 인명: 이르에크 | 이르+에크, 살피는 손 | 보호자가 지어준 개인명이다. 반드시 검사관이 되는 운명은 아니다. |
| N10 | 국가: 카르둔 공화국 | 카르+둔, 공동의 돌 받침이라는 상징 | 국가 정체가 바뀌면 '공화국'만 바뀔 수도 있다. |
| N11 | 도시: 둔하 | 둔+하, 받침 위의 거처 | 공식 지도명과 달리 항구 사람은 위층마을이라 부른다. |
| N12 | 조직: 이르단 | 이르+번역어 단, 점검자들의 모임 | 회원 자격을 직업으로 정한다. 같은 문화권 출신이라고 자동 가입되지 않는다. |
| N13 | 마법: 하중나눔 | 작용을 설명하는 번역명 | '무게 소멸'과 혼동되지 않게 기능을 이름에 드러낸다. |
| N14 | 직위: 둔지기 | 둔+번역어 지기, 공공 받침 시설 관리자 | '지기님'이라는 생활 호칭은 가능하지만 귀족 작위로 취급하지 않는다. |
| N15 | 유물: 카르판 | 카르+번역어 판, 균열을 기록한 석판 | 재료만 가리키는 통칭이라 여러 개가 있을 수 있다. 고유 유물에는 소장처를 덧붙인다. |
| N16 | 신앙: 받침회 | 서로를 지탱한다는 윤리적 비유 | 마법의 효능과 교리의 진실을 별개로 다룬다. |

## C. 군도권: 모음 연속을 허용하고 출항·귀환에서 이름을 얻음
가상 어근: 아오=물결, 누아=돌아옴, 이아=길, 루=섬, 마=담당자.
이 목록에서는 연속 모음을 줄이지 않는다. 인명에 쓰인 마는 옛 이름 요소이며 현재의 공직을 뜻하지 않는다.

| ID | 종류·명칭 | 조어·유래 | 사용 상황과 변형 가능성 |
|---|---|---|---|
| N17 | 인명: 누아마 | 누아+마, 귀환을 맡은 이라는 오래된 이름 | 성인 뒤 자신의 선호 이름을 고를 수 있는 문화로 확장 가능하다. |
| N18 | 국가: 아오루 연합 | 아오+루, 물결의 섬들을 묶은 통칭 | 섬마다 다른 제도가 있어도 연합에 속할 수 있다. |
| N19 | 도시: 이아루 | 이아+루, 항로의 섬 | 한 섬의 도시 이름이지 모든 항구의 공통 접미사가 아니다. |
| N20 | 조직: 누아회 | 누아+번역어 회, 귀환을 돕는 구조 공동체 | 적국 선원도 구조하는지 여부가 조직의 윤리를 구체화한다. |
| N21 | 마법: 물결고르기 | 파동을 조절하는 기능의 번역명 | 바다 전체를 정지시키는 힘이 있다고 추정하지 않는다. |
| N22 | 직위: 이아마 | 이아+마, 길을 맡는 항로 담당자 | 선장과의 지휘 관계는 별도 설정한다. |
| N23 | 유물: 귀항침 | 돌아가는 방향을 찾는 바늘에서 유래 | 안전한 길까지 알려준다는 전승과 실제 기능을 나눈다. |
| N24 | 신앙: 돌아오는 물결 | 귀환과 이별을 함께 다루는 생활 신앙 | 항해자의 종교라고 전 주민의 국교로 고정하지 않는다. |

## D. 문서 도시권: 번역명과 법적 명칭이 중심
조어는 한국어 의미 조합을 쓴다. 국가·기관에는 법적 기능을, 사람에게는 개인명을 쓴다.
개인명 예시는 실제 한국어 이름과 겹칠 수 있으며 특정 역사 왕조를 재현한 것이 아니다.

| ID | 종류·명칭 | 조어·유래 | 사용 상황과 변형 가능성 |
|---|---|---|---|
| N25 | 인명: 윤서 | 짧고 부르기 쉬운 개인명 | 동명이인은 '서쪽 기록방 윤서'처럼 소속으로 구분한다. 소속은 성씨가 아니다. |
| N26 | 국가: 세문헌 동맹 | 세 개의 기본 문헌을 공동 승인한 역사 | 실제 문헌이 세 권인지 세 종류인지 확정한다. |
| N27 | 도시: 열린서고 | 학술 시설에서 커진 도시의 번역명 | 서고 자체는 '중앙서고'라 불러 도시와 구분한다. |
| N28 | 조직: 이본대조원 | 서로 다른 판본을 대조하는 기관 | 이름에 '원'이 있어도 국가 기관인지 민간 단체인지는 별도다. |
| N29 | 마법: 잉크되비침 | 지워진 잉크 흔적을 읽는 기술의 통칭 | 모든 과거를 재생하는 능력으로 확대하지 않는다. |
| N30 | 직위: 합본관 | 자료를 통합하되 원본을 보존하는 관직 | '합본관님'으로 호칭한다. 검열권은 자동 포함되지 않는다. |
| N31 | 유물: 빈줄인장 | 비어 있는 항목을 표시하는 옛 공증 도구 | 기록되지 않은 사실을 알아내는 신비는 별도 제안으로 남긴다. |
| N32 | 신앙: 마지막 여백 | 사람의 기록은 완결될 수 없다는 신앙 | 교리의 시적 이름과 실제 조직명을 분리할 수 있다. |

## E. 겨울 공동체: 집과 돌봄의 경험에서 얻는 번역명
개인 이름과 공동 주거의 별칭을 구분한다. 따뜻한 이미지가 주민 전체의 성품을 결정하지 않는다.

| ID | 종류·명칭 | 조어·유래 | 사용 상황과 변형 가능성 |
|---|---|---|---|
| N33 | 인명: 새벽 | 태어난 시간에서 얻은 개인명 | 계절마다 같은 이름이 생기면 집 이름을 덧붙여 구별한다. |
| N34 | 국가: 일곱화로 연합 | 일곱 공동 난방소의 협약에서 유래 | 현재 회원 수가 늘어도 이름이 유지되는 역사적 이유가 있다. |
| N35 | 도시: 긴처마 | 눈을 피하는 연결 지붕에서 생긴 지명 | 행정명과 주민의 통칭이 같은 사례다. |
| N36 | 조직: 불씨나눔회 | 공동 난방을 돕는 자원 조직 | 소방대나 종교 조직과 겸하는지는 따로 정한다. |
| N37 | 마법: 온기묶음 | 열을 일정 시간 붙잡는 기술의 생활명 | 온기를 새로 만드는지 보존만 하는지 기능에서 구분한다. |
| N38 | 직위: 겨울지기 | 겨울 비축과 교대 일정을 담당 | 임기가 계절에 묶이는지 연중직인지 정한다. |
| N39 | 유물: 첫불그릇 | 건국기의 첫 공동 불씨를 담았다는 그릇 | 역사적 그릇과 복제 의례용 그릇을 같은 유물로 세지 않는다. |
| N40 | 신앙: 남겨둔 자리 | 식탁에 늦는 이를 위한 자리를 두는 의례에서 유래 | 빈자리가 누구를 뜻하는지 분파마다 다를 수 있다. |

## F. 순환 유랑권: 경로와 역할을 붙이는 가변 이름
출생명은 유지하며 노정명·직무명을 상황에 따라 덧붙인다. 이동민을 한 민족이나 성격으로 묶지 않는다.

| ID | 종류·명칭 | 조어·유래 | 사용 상황과 변형 가능성 |
|---|---|---|---|
| N41 | 인명: 다온, 북길의 기록꾼 | 다온은 개인명, 뒤는 현재 역할 | 역할이 바뀌어도 별개의 인물로 기록하지 않는다. |
| N42 | 국가: 네길 협약권 | 네 주요 경로의 공동 법을 따르는 정치체 | 영토가 없다는 뜻이 아니다. 거점과 관할 범위를 별도 정의한다. |
| N43 | 도시: 돌아앉은 장터 | 계절별로 출입 방향이 바뀌는 시장에서 유래 | 이동 시장인지 고정 도시인지 지도와 함께 확정한다. |
| N44 | 조직: 빈바퀴 조합 | 빈 수레의 귀환 운송을 공동 중개 | 상업적 효율에서 출발한 이름으로 신비성을 억지로 더하지 않는다. |
| N45 | 마법: 길흔읽기 | 지나온 경로의 흔적을 읽는 기술 | 여행자의 의도나 미래를 알 수 있다는 뜻은 아니다. |
| N46 | 직위: 노정조정자 | 여러 행렬의 통행 시기를 조정 | 군 지휘관과 권한이 겹치는 지점을 따로 정한다. |
| N47 | 유물: 돌아온 바퀴못 | 오래된 원정 수레에서 회수된 물건 | 명칭이 길면 대사에서는 '바퀴못'으로 줄인다. |
| N48 | 신앙: 멈춤의 날 | 이동 중에도 쉬는 날을 함께 지키는 전통 | 정착민도 참여할 수 있어 민족과 신앙이 일치하지 않는 예다. |
