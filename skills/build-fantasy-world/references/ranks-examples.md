# 신분·직위·조직 예시 24개
아래 항목은 하나의 서열을 이루지 않는다. 유형을 확인하고 서로 다른 제도를 조합할 때 관할 충돌을 검토한다.
탐색: H01~H06 정치·영지 / H07~H12 전문직·군사 / H13~H18 공동체 / H19~H24 승계·예외.

## 완성된 권한 충돌 예
가상 왕국에서 리아는 세습 공작이자 개인 마법사다. 항만관 토렌은 평민 출신 임명직이다.
항만관은 검역과 통행을 지휘하고 공작은 의전상 먼저 인사받는다. 공작의 사적 경비도 항만 규정을 따른다.
전쟁 시에는 왕의 동원령이 군사 지휘권을 별도로 부여하지만 검역 면제는 부여하지 않는다.
따라서 '공작이 더 높다'와 '항만관이 여기서는 명령한다'는 서로 모순이 아니다.
