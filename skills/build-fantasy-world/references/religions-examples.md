# 종교·신앙 예시 24개
각 종교는 독립적인 제안이다. ‘신의 실재’는 별도로 명시한 경우에만 확정한다. 같은 신앙 안의 분파 차이는 서로 다른 악역 조직을 뜻하지 않는다.
탐색: R01~R06 삶의 의미 / R07~R12 신성의 형태 / R13~R18 조직·논쟁 / R19~R24 정치·일상.

| ID·이름 | 핵심 믿음·우주론 상태 | 의례·조직·재원 | 내부 논쟁과 장면 |
|---|---|---|---|
| R01 남겨둔 자리 | 부재한 이를 위한 자리를 남기면 공동체가 닫히지 않는다고 믿는다. 사후세계는 미정이다. | 식탁 한 자리를 비우고 공동 식사를 운영한다. 자발적 곡물 기부를 받는다. | 빈자리를 실제 손님에게 내줘도 되는지 세대가 다르게 생각한다. |
| R02 합류의 길 | 삶은 서로 영향을 주는 흐름이라는 가르침이다. 인격신을 필수로 두지 않는다. | 다리·우물 관리와 화해 의례를 수행한다. | 관계를 회복하라는 가르침이 해로운 관계의 강요가 되지 않도록 논쟁한다. |
| R03 마지막 여백 | 어떤 생애도 기록만으로 완전히 설명할 수 없다고 믿는다. | 장례문 끝에 빈 줄을 남기고 기록을 보존한다. | 범죄자의 기록에도 여백을 남길지 다룬다. |
| R04 첫불의 증언 | 처음 서로를 살린 불의 이야기를 전한다. 기원 신화는 여러 판본이다. | 공동 난방과 겨울 구호를 지원한다. | 기원 장소를 둘러싼 논쟁보다 현재 구호를 우선할 사람이 나온다. |
| R05 돌려주는 손 | 받은 것을 다른 이에게 전하는 일이 성스러움이라고 본다. | 기술 교육과 대여 창고를 운영하며 반납을 강제 징벌로 연결하지 않는다. | 돌려줄 능력이 없는 사람도 존중받을 수 있는지 시험한다. |
| R06 쉼의 약속 | 노동을 멈추는 시간이 인간과 세계의 관계를 회복한다고 믿는다. | 정기 휴식과 공동 돌봄을 운영한다. | 응급 노동자의 쉼을 누가 대신 보장할지 결정한다. |
| R07 서로 다른 신의 계절 | 여러 신의 현상이 관측되지만 각 신의 도덕적 우위는 증명되지 않는다. | 계절별 신전을 방문하며 복수 신앙을 허용한다. | 같은 해 두 신의 의례 시기가 겹친다. |
| R08 침묵한 창조자 | 창조자를 믿으나 현재 계시는 없다는 교리다. 실재는 미정이다. | 경전 해석과 토론을 중시하며 단독 신탁 권력을 제한한다. | 갑자기 계시를 받았다는 사람을 어떻게 대할지 논쟁한다. |
| R09 꿈의 방문자 | 꿈속 존재의 출현은 관측되나 신인지 다른 생명인지 모른다. | 꿈 기록은 본인의 동의를 받아 보관한다. | 경험이 없는 신자를 덜 경건하다고 보는 관행에 반대한다. |
| R10 땅의 기억 | 특정 장소의 반복 현상을 조상의 흔적으로 해석한다. | 장소 돌봄과 구전 교육을 실천한다. | 재난으로 장소를 옮겨야 할 때 신앙을 어떻게 이어갈지 결정한다. |
| R11 이름 없는 원리 | 신을 인격으로 부르지 않고 관계와 변화의 원리를 숭상한다. | 명상·논증·공공 봉사를 결합한다. | 원리를 쉽게 설명하려 만든 상징이 우상 논쟁을 낳는다. |
| R12 가까운 작은 신들 | 집·우물·숲의 제한된 초자연 존재가 실제로 있다. 전지전능하지 않다. | 각각의 존재와 지역 협약을 맺는다. | 우물의 신도 가뭄을 해결하지 못해 인간과 함께 대책을 찾는다. |
| R13 열린경전회 | 새 경험을 반영해 주석을 갱신할 수 있다고 본다. | 원문·주석·개정 기록을 분리한다. | 주석 변경을 원전 위조로 보는 반대파와 토론한다. |
| R14 두등불 교단 | 내적 수행과 사회 봉사를 모두 중시한다. | 수행원과 구호원이 서로 예산을 감사한다. | 재난 때 수행 예산을 얼마나 돌릴지 협상한다. |
| R15 걷는 성직 | 성직자가 일정 기간 거주지를 바꾸며 봉사한다. | 지역 공동체가 숙식을 제공하고 중앙은 교육을 맡는다. | 돌봄 관계가 깊어진 성직자가 떠날 의무와 갈등한다. |
| R16 재가 의례공동체 | 전문 성직 없이 교육받은 주민이 의례를 번갈아 맡는다. | 회비와 공동 노동으로 운영한다. | 특정 인물에게 비공식 권력이 집중되어 순환 규칙을 보완한다. |
| R17 치유와 구원의 분리 | 치료 성공을 영혼의 우열과 연결하지 않는 교리다. | 의료 협력과 장례 돌봄을 별개로 운영한다. | 기적이 일어나지 않은 환자를 탓하는 설교를 바로잡는다. |
| R18 낮은문 수도회 | 생활에 필요한 최소 재산을 공동 관리한다. | 농업·제본·기부로 유지하며 노동 불가능자도 보호한다. | 재산 최소화와 노인 돌봄 시설 확충이 충돌한다. |
| R19 왕관 밖의 축복 | 통치자를 축복하되 즉위의 정당성을 독점 심판하지 않는다. | 성직과 국정 관직의 겸임을 제한한다. | 왕이 군사 정책에 대한 종교적 지지를 요구한다. |
| R20 국교 안의 여러 길 | 국교가 있지만 지역 의례와 소수 신앙에 법적 공간이 있다. | 국고 지원과 자발적 기부의 회계를 구분한다. | 비신자의 세금으로 의례를 지원하는 범위를 논의한다. |
| R21 물러난 신의 후예 | 신의 개입이 끝났다고 믿지만 남은 유물은 작동한다. | 유물 관리와 기원 해석을 다른 기관이 맡는다. | 유물의 고장이 곧 신의 분노라는 주장에 기술자가 반론한다. |
| R22 두번의 장례 | 육체의 죽음과 마지막 기억자의 죽음을 다른 사건으로 기린다. | 첫 장례는 가족, 두 번째는 기록 공동체가 맡는다. | 기록에서 이름을 지우려는 사람과 기억할 의무가 충돌한다. |
| R23 용서의 문턱 | 용서는 가능하지만 피해 회복의 책임을 없애지 않는다고 가르친다. | 화해 중재는 당사자의 동의로만 진행한다. | 가해자의 회심과 피해자의 거절이 동시에 존중될 수 있다. |
| R24 이웃의 축일 | 서로 다른 종교가 이웃의 축제를 돕는 도시 관습이다. | 신앙 혼합이 아니라 공동 생활 협약으로 운영한다. | 축일이 겹쳐 같은 광장을 나누어 쓰는 방법을 찾는다. |
