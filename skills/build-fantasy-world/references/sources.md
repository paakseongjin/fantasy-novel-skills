# 설계 참고와 확인 범위
확인일: 2026-11-14.

## 배포 형식과 확인 범위
- Google: https://support.google.com/gemini/answer/17094296?hl=en
- Anthropic: https://support.claude.com/en/articles/12512198-how-to-create-custom-skills
- OpenAI: https://help.openai.com/en/articles/20001066-skills-in-chatgpt

공통 원본은 SKILL.md와 Markdown 참고 파일이다. Gemini용 ZIP은 최상위에 SKILL.md를, Claude용 ZIP은 최상위 스킬명 폴더 안에 SKILL.md를 둔다. ChatGPT용은 표준 스킬 폴더를 묶어 제공하며 메뉴·계정별 수용 형식은 설치 시 확인한다. 스킬 메뉴가 없는 경우 프로젝트용 단일 문서를 사용할 수 있다.
실행 스크립트나 외부 연결에 의존하지 않는다. 실제 사용자 계정에 설치하거나 세 서비스 모델로 실행한 결과를 주장하지 않는다.

## 창작 설계 참고
Patricia C. Wrede, Fantasy Worldbuilding Questions, SFWA:
https://sfwa.org/2009/08/04/fantasy-worldbuilding-questions/
세계의 요소가 서로 어떻게 맞물리는지 질문하되 집필 전에 모든 질문에 답할 필요는 없다는 취지를 참고했다.
원문 질문집을 복제하거나 번역하여 싣지 않았다. 이 팩의 분야별 절차·표·질문·예시는 별도로 작성했다.

Brandon Sanderson, Sanderson's First Law:
https://www.brandonsanderson.com/blogs/blog/sandersons-first-law
마법을 통한 갈등 해결과 독자의 이해 사이의 관계를 검토하는 관점을 참고했다.
이를 모든 판타지가 따라야 하는 법칙으로 제시하지 않는다. 설명되지 않는 신비와 소프트 매직도 허용한다.

Brandon Sanderson, Sanderson's Second Law:
https://www.brandonsanderson.com/blogs/blog/sandersons-second-law
마법의 제약을 서사적으로 검토하는 방향을 참고했다. 이 팩의 세부 구현은 별도 설계이며 작가의 직접적인 문구로 제시하지 않는다.

## 창작 예시의 성격
216개 번호 항목은 이 요청을 위해 작성한 허구 예시다. 실제 역사·종교·언어·생물학 자료가 아니다.
명칭의 전 세계적 신규성이나 상표·출판 권리의 사용 가능성을 검증하지 않았다.
고유한 상업 작품의 설정을 그대로 옮긴 예시가 아니지만 흔한 장르 관습·단어와 우연히 겹칠 수 있다.
예시를 많이 포함했다는 사실 자체가 문학적 완성도나 특정 모델에서의 성능을 보장하지 않는다.
