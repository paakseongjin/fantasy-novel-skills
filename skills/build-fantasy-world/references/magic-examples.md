# 마법·기술 예시 24개
각 항목은 독립 체계다. ‘가격’과 ‘보급’은 별도 세계의 경제를 정한 뒤 연결한다. 수치가 없는 것은 미정이지 무한이라는 뜻이 아니다.
탐색: M01~M06 물질·환경 / M07~M12 정보·생명 / M13~M18 협업·의례 / M19~M24 유물·신비.

| ID·명칭 | 효과·발동 | 한계·비용·방해 | 사회적 결과와 이야기 |
|---|---|---|---|
| M01 열매듭 | 두 물체를 짝지은 실로 연결해 열을 한쪽에서 다른 쪽으로 옮긴다. | 열을 생성하지 못하고 실의 내열 한계를 넘으면 끊어진다. | 냉장고와 난방이 연결된다. 주인공은 난방을 끄지 않고 약품을 보관할 열 배출처를 찾는다. |
| M02 무게나눔 | 같은 문양의 받침 사이에 물체의 하중을 분배한다. | 전체 무게는 줄지 않으며 받침 하나가 무너지면 나머지에 하중이 몰린다. | 교량 공사와 사고 책임 기준이 바뀐다. 싸움에서 받침을 빼는 행동이 위험한 선택이 된다. |
| M03 소리접기 | 고정된 두 표면 사이에서 소리의 진행 방향을 꺾는다. | 벽을 뚫지 않고 새 소리를 만들지 않는다. 표면이 움직이면 깨진다. | 극장과 경보에 사용된다. 비밀 대화를 지키려는 사람이 흡음 천을 건다. |
| M04 빛저장 | 빛을 특정 유리에 저장해 천천히 방출한다. | 용량과 누설이 있고 햇빛을 저장한 유리가 언제나 같은 밝기를 내지 않는다. | 야간 조명이 충전 노동과 연결된다. 흐린 주간 뒤 야간 작업 순서를 조정한다. |
| M05 균열듣기 | 도구를 대고 물체 내부의 응력 변화를 소리로 듣는다. | 구조를 이해해야 해석할 수 있고 작은 흠집과 위험 균열이 비슷하게 들릴 수 있다. | 숙련 검사와 기록이 필요하다. 마법사가 건축가의 판단을 대신하지 못한다. |
| M06 염분가르기 | 막을 통과하는 물에서 소금을 분리한다. | 막의 세척과 배출 염수 처리가 필요하며 물 자체는 만들지 않는다. | 식수 시설을 유지하는 노동과 해안 생태 문제가 생긴다. |
| M07 잔상읽기 | 특정 표면에 남은 강한 빛의 흔적을 흐릿하게 읽는다. | 시간 순서와 인물의 의도는 알 수 없고 세척·재노출로 흔적이 변한다. | 단독 유죄 증거가 되기 어렵다. 수사자는 다른 기록을 대조한다. |
| M08 사실울림 | 말하는 사람이 자신이 거짓이라고 믿는 말을 할 때 공명기가 흔들린다. | 착각·기억 오류·진심으로 믿는 거짓은 판별하지 못한다. | 법정은 진술의 진실성과 객관적 사실을 구별해야 한다. |
| M09 길표이동 | 사전에 설치하고 현재 상태를 확인한 두 표식 사이로 이동한다. | 개수·통과량·재충전 시간이 제한되며 미등록 목적지로 갈 수 없다. | 성벽보다 표식 관리가 중요하다. 홍수로 도착지가 잠겨 이동을 중지한다. |
| M10 상처봉합 | 살아 있는 조직의 가장자리를 붙여 출혈을 줄인다. | 감염 제거, 잃은 혈액 복구, 재생은 별개다. | 치료 후 관찰·위생·돌봄이 남는다. 즉시 전투 복귀가 정답이 아니다. |
| M11 씨앗깨우기 | 휴면 중인 씨앗의 발아 조건을 앞당긴다. | 영양분·물·성장 시간은 따로 필요하고 부적절한 계절에는 죽을 수 있다. | 종자 보관과 농업 지식이 중요하다. 성급한 시전이 수확을 보장하지 않는다. |
| M12 증인기억 | 동의한 두 사람이 특정 기억의 감각 일부를 공유한다. | 기억의 정확성을 보장하지 않으며 동의 없이 접근할 수 없다. | 교육·돌봄에 쓰이나 재판에서는 한계가 있다. 같은 경험을 다르게 기억하는 가족이 나온다. |
| M13 합창방벽 | 일정한 간격의 합창이 유지되는 동안 충격을 분산한다. | 가사보다 호흡·박자·자리 간격이 중요하다. 피로와 소음이 약점이다. | 음악 교육과 방재가 연결된다. 한 명의 영웅보다 교대조의 협력이 중요하다. |
| M14 매듭계약 | 당사자가 이해하고 동의한 물리적 행동 조건에 반응하는 끈을 만든다. | '행복하게 해라' 같은 모호한 마음 상태는 구속하지 못한다. | 계약 해석자가 필요하다. 폭넓은 복종 명령을 기술적으로 구현할 수 없다. |
| M15 그림자재봉 | 실물의 형태를 그림자에 고정해 잠시 자세를 유지한다. | 빛의 각도가 크게 바뀌면 풀리고 신체의 힘을 새로 만들지 않는다. | 작업 보조와 재활에 쓰인다. 일식 중 보조 장치가 멈출 수 있다. |
| M16 빗소리주소 | 특정 지붕의 빗소리 패턴을 매개로 짧은 신호를 보낸다. | 두 곳에 비가 와야 하고 복잡한 언어는 별도 부호로 정한다. | 우기에 강한 통신망이 생긴다. 맑은 날에는 전령이 필요하다. |
| M17 공유초점 | 여러 사람이 하나의 정밀 작업에 주의를 합친다. | 각 참여자는 작업을 이해해야 하며 실수한 책임을 자동 식별하지 못한다. | 협동 공방과 책임 보험이 생긴다. 가장 유명한 장인이 혼자서는 일을 못 한다. |
| M18 의례의 여백 | 정해진 예식에서 일부를 의도적으로 비우면 작은 우연이 유리하게 흐를 수 있다. | 결과는 확정할 수 없고 반복 시 같은 효력이 보장되지 않는다. | 소프트 매직 사례다. 경이를 만들되 핵심 문제의 확실한 해결책으로 사용하지 않는다. |
| M19 귀환바늘 | 주인이 설정한 한 방향을 가리키는 나침반형 유물이다. | 경로의 안전이나 거리, 목적지의 존속은 알려주지 않는다. | 사라진 집을 여전히 가리키는 물건이 정서적 장치가 된다. |
| M20 수선판 | 저장된 구조 도면에 맞춰 무생물을 정렬한다. | 재료를 새로 만들지 못하고 잘못 저장한 도면도 그대로 따른다. | 부품 공급과 도면 권리가 중요하다. 고장 난 원본을 기준으로 수리해 실패한다. |
| M21 잠금종 | 정해진 물리적 열쇠의 진동 패턴에 반응한다. | 허가받은 사람의 도덕성을 판정하지 않으며 패턴 복제가 가능하다. | 열쇠 교체와 관리 절차가 필요하다. 도둑이 아닌 내부자가 문제일 수 있다. |
| M22 별길예감 | 별을 보는 동안 앞으로 생길 가능성 높은 분기 몇 개를 감지한다. | 개입하면 분기가 바뀌고 먼 미래일수록 모호하다. | 예지자는 보장을 판매할 수 없다. 예언을 믿은 행동이 결과를 바꾸는 구조를 쓴다. |
| M23 이름을 듣는 산 | 일부 여행자는 산에 말을 걸면 답처럼 느껴지는 메아리를 듣는다. | 신·지형·착각 중 무엇인지 확정하지 않는다. 정확한 명령 수행 능력은 없다. | 신비와 종교 해석에 쓰며 숨겨진 만능 구조 장치로 만들지 않는다. |
| M24 기억하지 않는 문 | 오래 쓰인 문은 반복된 출입 순서에 익숙해져 열림을 보조한다. | 사람의 정체나 비밀을 알지 못하고 사용 패턴이 바뀌면 재학습이 필요하다. | 노약자 보조 설비가 된다. 새 입주자는 이전 주민의 생활 흔적과 마주친다. |
