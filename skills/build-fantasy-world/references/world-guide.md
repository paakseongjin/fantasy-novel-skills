# 세계관 골격·지리·역사
## 설계 순서
1. 이야기의 약속을 한 문장으로 정한다. 어떤 인물의 어떤 선택을 어렵게 만드는 세계인가.
2. 현실과 다른 핵심 전제와 바뀌지 않은 조건을 분리한다. 신기한 요소를 추가할 때마다 무관한 새 법칙을 만들지 않는다.
3. 본편 무대를 먼저 정한다. 동네·도시·국가·대륙 중 필요한 범위를 선택하고 외부 세계는 영향이 있는 만큼만 만든다.
4. 생존 조건을 확인한다. 먹거리, 물, 거처, 에너지, 교통, 통신 중 핵심 병목을 잡고 정상적인 공급 경로를 둔다.
5. 환경과 선택의 상호작용을 설계한다. 지리가 사회를 강제로 한 형태로 결정한다고 보지 않는다. 같은 환경에서 다른 제도가 가능한 이유를 만든다.
6. 현재를 만든 사건 3~5개를 골라 원인·승자·패자·남은 시설·지금의 오해를 연결한다. 나열식 만년 연대기는 요청받았을 때만 만든다.
7. 역사적 사실, 국가의 공식 역사, 민간 전승, 작가의 미공개 진실을 분리한다. 불일치가 의도된 경우 ‘오류’로 통합하지 않는다.
8. 오늘의 평범한 생활 하나와 주인공이 부딪힐 갈등 하나로 설정을 시험한다.

## 지리와 시간
- 지도 없는 설계도 방향·연결·장벽·경로를 말로 일관되게 표현할 수 있어야 한다.
- 강, 산, 바람, 계절은 실제 자연을 따르는지 초자연적 예외인지 구분한다. 예외에는 범위와 생활상의 적응을 둔다.
- 거리와 속도를 제시하면 이동 시간 = 거리/실효 이동 속도 + 대기·휴식으로 확인한다. 경로, 계절, 짐, 운송수단이 다른 여행을 같은 시간으로 처리하지 않는다.
- 달력은 하루·달·해의 길이, 윤일, 날짜 표기, 공용 달력과 종교력의 관계를 필요한 만큼 정한다.
- 여러 태양·달이 있을 때 기후와 조석을 검증했다고 주장하지 않는다. 과학적 계산이 필요하면 별도 검증 대상으로 남긴다.

## 선택과 검증
처음부터 세부가 전부 정해져야 집필할 수 있는 것은 아니다. 요청한 장면에 필요한 수준에서 멈춘다.
핵심 전제를 지웠을 때도 모든 국가·직업·일상이 그대로면 전제의 파급을 보완한다.
자원 고갈이나 재앙이 수백 년 지속되었다면 인구와 제도가 어떻게 존속했는지 검토한다.
모든 문명을 몰락 직전으로 만들 필요는 없다. 성장, 협력, 복구, 평온한 지방도 다룬다.
