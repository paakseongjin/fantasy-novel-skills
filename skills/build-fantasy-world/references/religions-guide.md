# 신·종교·교리·의례
## 세 층을 분리하라
1. 객관적 우주 규칙: 신이나 사후세계가 실제로 어떻게 존재하는가. 미정 또는 끝까지 모호할 수 있다.
2. 교리와 해석: 각 집단이 무엇을 참이라고 믿고 어떻게 설명하는가.
3. 제도와 생활: 누가 의례를 수행하고 자원을 모으며 신자가 하루를 살아가는가.
기적이 일어난다고 특정 교단의 모든 역사·도덕·교리가 증명되는 것은 아니다.

## 설계 순서
1. 신앙이 응답하는 삶의 문제를 정한다. 죽음, 죄, 풍요, 기억, 소속, 변화, 자유 등.
2. 신성한 존재·원리와 세계의 관계를 정한다. 인격신만을 기본으로 삼지 않는다.
3. 신화, 경전, 구전, 계시의 전달·해석 권한을 구별한다.
4. 평신도의 일상 의례와 위기 시 의례를 하나씩 만든다.
5. 성직·재가 조직의 가입, 교육, 임명, 재정, 감사, 파면을 정한다.
6. 교단 내부의 실제 쟁점을 만든다. 교리, 재산, 의례, 구제, 정치 참여가 다를 수 있다.
7. 다른 신앙과 공존·혼합·경쟁하는 방식과 비신자의 자리를 정한다.
8. 인물이 신앙 때문에 얻는 위로와 부담, 선택의 어려움을 장면에 연결한다.

## 권력과 믿음
- 종교를 모두 사기나 지배 도구로 처리하지 않는다. 의미, 공동체, 예술, 교육, 구호, 진실한 신앙도 다룬다.
- 반대로 신자가 진실하게 믿는다는 이유로 기관의 권력과 피해를 지우지 않는다.
- 이단은 누가 어떤 기준으로 부르는 명칭인지 밝힌다. 서술자의 객관적 분류로 자동 사용하지 않는다.
- 한 신을 섬기는 여러 교단, 여러 신을 함께 섬기는 사람, 무신론적 의례 공동체도 가능하다.
- ‘성직자=치유 마법사’로 고정하지 않는다. 의례·행정·교육·해석·돌봄의 직무를 나눌 수 있다.
- 실제 종교를 참고한다면 특정 의례를 무맥락으로 이름만 바꾸지 않는다. 역사적 사실과 창작 변형을 구별한다.
- 신성력과 일반 마법의 차이가 객관적인지 종교적 주장인지 명시한다.

## 출력과 점검
종교 설계는 신의 목록뿐 아니라 신자의 하루와 기관의 작동을 포함한다.
검토에서는 신의 실재, 교리의 정당성, 기관의 정당성을 혼동한 지점을 먼저 찾는다.
