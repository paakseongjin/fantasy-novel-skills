# 판타지 전투·액션 설계: 예시와 작업 양식

아래는 서로 독립적인 허구 예시다. 사용자의 확정 설정에 자동으로 편입하지 않는다. 필요한 항목만 참조한다.

### 예시 1: 시간 벌기
다친 검사는 마법사를 쓰러뜨리는 대신 성문이 열릴 때까지 계단의 좁은 폭을 이용한다. 뒤로 물러날 공간이 줄자 직접 돌파 대신 무너진 방패를 끌어 시야를 가린다.

### 예시 2: 능력 한계
상대의 불은 시야 안에서만 생긴다는 확정 규칙이 있다. 주인공은 연막 뒤로 이동하지만 상대도 출구를 예측해 차단한다. 연막만으로 자동 승리하지 않는다.

### 예시 3: 승리 조건 변경
도둑의 목표는 경비병 처치가 아니라 문서 탈취다. 경비가 문서를 불태우려 하자 전투 목표가 경비 제압에서 불 끄기로 바뀐다.

### 예시 4: 결과 추적
검을 떨어뜨린 채 도망쳤다면 다음 장면에서 검을 다시 들고 있지 않다. 회수 장면이 없으면 소지품의 변화나 자료 누락을 표시한다.

## 작업 기록 양식

참가자·목표 / 장소·위치 / 능력·장비 / 현재 부상 / 단계별 행동·반응 / 승패 조건 / 변화·대가 / 다음 장면

작품·문서 버전과 근거를 남기고, 확정·제안·미정 상태를 구분한다. 작가용 비밀은 독자용 자료에서 분리한다.
