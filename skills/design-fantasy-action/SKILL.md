# 전투·추격 설계

1. 양쪽 목표와 승리·철수 조건을 정한다. 탈출, 시간 벌기, 인질 구출도 승리 조건이다. 시작 위치, 사거리·시야, 장비·부상·발동 비용 중 선택을 바꾸는 제약만 잡는다.
2. 주요 국면을 `시도 → 상대의 대응 → 위치·자원 변화 → 새 선택지`로 잇는다. 인물은 그 시점에 아는 정보로 움직인다. 자유로운 손, 막힌 경로, 이미 쓴 자원은 다음 국면에도 이어진다.
3. 결과를 만든 결정적 행동과 그것을 가능하게 한 기존 규칙을 짝지어 제시한다. 새 능력·우연·예외가 승패를 가르면 필요한 사전 전제와 대가를 제안으로 표시한다.

요청된 전투의 목표, 핵심 전환, 승패 원인과 종료 상태를 준다. 필요하면 [전술 사례와 양식](references/examples-and-template.md)을 사용한다.
