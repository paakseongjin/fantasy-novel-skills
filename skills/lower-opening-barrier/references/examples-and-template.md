# 초반 진입장벽 낮추기: 예시와 작업 양식

아래는 서로 독립적인 허구 예시다. 사용자의 확정 설정에 자동으로 편입하지 않는다. 필요한 항목만 참조한다.

### 예시 1: 설정 투척형 도입
종족 연대기 세 쪽을 먼저 읽게 하는 대신, 주인공이 통행증에 찍힌 인장 때문에 다리에서 막히는 장면으로 시작한다. 연대기는 나중 회차의 필요 지점으로 미룬다.

### 예시 2: 1화에서 흥미가 안 생기는 경우
첫 화가 출근 준비 서술만으로 끝나면 동기가 약하다. 최소 수정안: 같은 출근 안에서 ‘오늘만은 피하고 싶은 업무’와 그 업무가 왜 위험한지 한 가지를 보여 준다.

### 예시 3: 의도된 높은 장벽
작가가 독자를 세계 속에 바로 던져 넣는 문체를 원할 수 있다. 이 경우 장벽을 없애기보다, 낯선 이름 옆에 행동으로 이해 가능한 단서 한두 개를 보강하는 안을 제시한다.

### 예시 4: 프롤로그 과다
과거 전쟁 프롤로그가 현재 이야기와 50화 뒤에야 연결되면 초반 이탈 위험이 커진다. 선택지: 프롤로그를 짧게 줄이거나, 현재 회차에 같은 갈등의 작은 흔적을 먼저 배치한다.

## 작업 기록 양식

초반 범위 / 최소 질문(누가·무엇·장애) / 과잉 정보 / 1화 끝의 동기 / 취향 vs 이해 문제 / 최소 수정안 / 정본 영향

작품·문서 버전과 근거를 남기고, 확정·제안·미정 상태를 구분한다. 작가용 비밀은 독자용 자료에서 분리한다.
