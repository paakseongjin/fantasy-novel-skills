# 인물 성장·관계 변화: 예시와 작업 양식

아래는 서로 독립적인 허구 예시다. 사용자의 확정 설정에 자동으로 편입하지 않는다. 필요한 항목만 참조한다.

### 예시 1: 불신에서 협력으로
혼자 기록을 훔친다 → 동료가 누명을 쓴다 → 증거를 혼자 감추려다 구출 기회를 놓친다 → 위험을 설명하고 선택권을 돌려준다. 동료가 즉시 신뢰하는 것은 별개다.

### 예시 2: 신념을 지키되 전략이 바뀜
치유사는 생명을 살린다는 가치는 유지한다. 전장 치료소를 혼자 지키는 방법이 실패하자 마을 주민에게 처치를 가르친다. 변화가 반드시 신념의 폐기는 아니다.

### 예시 3: 타락
왕자는 기근을 막으려 식량을 징발한다 → 실패를 숨기기 위해 통계를 조작한다 → 자신을 반대하는 사람을 굶주림의 원인으로 지목한다. 목적과 수단의 이동을 각 단계의 선택으로 보인다.

### 예시 4: 화해 없는 관계 변화
배신당한 기사는 스승과 함께 피란민을 구하지만 과거를 용서하지 않는다. 공동 행동과 정서적 화해는 서로 다른 변화다.

## 작업 기록 양식

인물 / 현재 목표 / 믿음 / 두려움 / 관계·권력 / 전환 사건 / 선택 / 대가 / 후속 행동 / 근거 / 미확정

작품·문서 버전과 근거를 남기고, 확정·제안·미정 상태를 구분한다. 작가용 비밀은 독자용 자료에서 분리한다.
