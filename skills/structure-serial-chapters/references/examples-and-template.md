# 회차 구성·연재 리듬: 예시와 작업 양식

아래는 서로 독립적인 허구 예시다. 사용자의 확정 설정에 자동으로 편입하지 않는다. 필요한 항목만 참조한다.

### 예시 1: 휴식 회차
피란민과 식사를 나누며 주인공이 희생자의 이름을 기억하기로 결심한다. 큰 전투가 없어도 관계와 목표가 달라진다.

### 예시 2: 반복 회차
세 회차 모두 문지기를 설득하고 입장 거절로 끝난다. 대안: 두 번째에는 허가를 얻되 조건이 붙고, 세 번째에는 그 조건을 지킬지 선택하게 한다.

### 예시 3: 정보 분할
회의에서 종교사 전체를 설명하는 대신, 이번 재판에서 필요한 금기만 보여 주고 나머지는 후속 사건에서 필요할 때 제공한다. 필수적인 짧은 설명은 남긴다.

### 예시 4: 회차 끝
절벽 끝의 생사 위기 대신 동료가 오래 숨긴 편지를 건네며 “네 이름은 여기 없어”라고 말한다. 작은 장면을 마무리하고 새로운 질문을 남긴다.

## 작업 기록 양식

회차 / 시작 상태 / 목표 / 장애 / 선택 / 끝의 변화·만족 / 다음 연결 / 정보·분량 / 반복 / 정본 영향

작품·문서 버전과 근거를 남기고, 확정·제안·미정 상태를 구분한다. 작가용 비밀은 독자용 자료에서 분리한다.
