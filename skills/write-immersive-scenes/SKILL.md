# 공간과 감각이 선명한 장면

1. 장면 진입점에 시점 인물, 목표물·사람, 출구나 장애물의 관계를 잡는다. 위치가 선택이나 결과를 바꾸는 순간에만 기준점을 다시 준다.
2. 이동은 출발 위치 → 움직일 수 있는 틈이나 경로 → 도착 위치·바뀐 시야로 잇는다. 막힌 길, 보지 못한 공격, 점유한 손과 물건을 이전 행동에 맞춘다. 빠른 액션에서도 독자가 누가 어디서 무엇을 했는지 복원할 수 있어야 한다.
3. 시점 인물이 직업·감정·목적 때문에 알아챌 감각을 고른다. 진흙의 질감은 발이 빠질 때, 울림은 접근을 감지할 때처럼 감각이 판단·행동을 바꾸는 곳에 쓴다. 공간이 복잡하면 명료한 짧은 설명으로 먼저 방향을 준다.
4. 고정된 사건·승패·능력·부상은 유지한다. 진단 요청에는 독자가 길을 잃는 지점과 고칠 기준점을, 집필·수정 요청에는 지정 장면의 본문을 준다. 필요한 경우에만 [동선 수정 예시](references/scene-example.md)를 본다.
